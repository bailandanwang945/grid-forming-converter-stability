# 分析变换自动搜索：探索性试验计划

日期：2026-10-03。在本次候选结果产生前保存。已有Fig.8基准和F零点结果曾被查看，因此不是确认性预注册。

## 问题与失败条件

在不改变物理模型的条件下，自动选择 Rv、Xv、fc，能否提高稳定Fig.8算例在有限频率网格上的最小混合判据余量？若不优于同预算随机搜索，不宣称搜索策略有优势。

作者已经提出混合坐标变换、虚拟导纳权重及降低保守性的思路。此处只是带逆稳定筛选的自动参数搜索，不把这些已有内容算作我们的创新。

## 固定设计

- 固定作者两工况原始导纳及闭环极点夹具；拟合单RL网络仅用于明确范围的前提检查，不改变导纳数据。
- 目标工况固定为D=0.5；D=0.05仅作选择后的失稳对照，不进入适应度。
- 目标：最大化每频点增益、相位两类归一化不等式余量的较大者，再取频率网格最小值；不可解相位不提供正余量。该指标不是物理稳定裕度。
- 正参数域：Rv为[0.002,0.08]，Xv为[0.03,0.3]，fc为[0.03,8] Hz；F全部零点和单RL网络G全部零点须严格左半平面，N首项矩阵不能近奇异，有限频率代数残差不能过大。
- 固定种子20261003；原设置(.01,.1,.5)为基准。进化搜索：6个初始随机候选，3代每代6个由前3名对数参数扰动产生的候选；24次预算。同预算随机搜索24项。保留所有拒绝原因。
- 开发频点：1000点夹具中80个等索引分布点；冻结选择后检查全部其余920点及完整1000点。频率留出不是独立电网或跨场景泛化验证。
- 在选择完成后报告失稳工况的判据覆盖，任何全覆盖仍不能解释为稳定，必须记录与闭环极点矛盾。
- 运行有240秒计算预算，每项完成立即保存并输出进展；超时或依赖文件变化非零退出，保存未完成状态。输出目录拒绝覆盖既有运行。
- 验证：原参数的1000点分类必须与生产内核完全一致；N多项式值与直接矩阵行列式相符；边界、错误输入、确定性生成和拒绝原因单元测试。
