# v0.5 平均值 dq 研究验证任务聚焦界面

## 变更目的

平均值 `dq` 的六项固定研究任务使用各自冻结的参数锚点，不读取“模型分析”中的临时输入。旧界面在研究视图仍显示参数检查器，并同时展开六张任务卡，容易混淆参数作用域，也使结果区离首屏过远。

## 交互变更

- “研究验证”占用完整工作画布，隐藏只属于“模型分析”的参数检查器；
- 六项任务保留统一导航、运行状态和完成状态，仅当前任务展开说明与操作；
- 宽屏三列、900 px 两列、620 px 以下单列；
- 参数计算、冻结锚点、结果接口、导出内容与学术结论边界均未改变。

## 验证结果

| 检查 | 结果 |
|---|---|
| React / TypeScript 生产构建 | 通过 |
| 真实 Chromium 全流程 | `BROWSER_E2E_SMOKE_OK` |
| 研究视图参数作用域 | 参数检查器不可见，恰有一项任务操作区展开 |
| 900 px 自适应布局 | 无横向溢出，任务导航两列 |
| 既有六项任务 | 运行、结果切换、JSON导出及报告流程通过 |

## 结论边界

本次变更改善任务组织与参数作用域表达，不构成新的模型、算法或稳定性结论，也不替代异机发布包验收。
