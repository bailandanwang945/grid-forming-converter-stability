## 找到并修正的问题

1. 嵌套数组中的布尔／复数可能在类型合并前被转换，现于转换前拒绝；对象数组不遍历、输入递归深度受限。
2. 极小正滞后常数可使除法生成非有限矩阵，现给出明确计算错误，不返回稳定分类。
3. 非标准JSON的NaN／Infinity能使验证错误本身在序列化时产生500，现仅在新路由中提前拒绝；同时核查浮点溢出、32层深度和2 MiB请求体上限。没有替换全局错误处理或改变原接口协议。
4. 内核定理状态与接口统一为`not-evaluated-by-sampled-api`；原固定Tmod与随Ts变化的近似tau各自返回，不能混用。

接口资源上限只是计算约束，不是设备安全值。特征对残差和步长比较属于数值诊断，不是严格特征根误差界。无第二模型时明确未提供步长检查；HTTP接口实际重新建立两种步长模型。全部计算保留额外缓存乘子。
