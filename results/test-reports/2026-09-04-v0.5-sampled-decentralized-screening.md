# 多设备分散式判据有限网格筛查核验记录

## 核验结论

状态：**多设备代数筛查核心通过内部软件验证；论文全频域定理仍未评价。**

本轮实现接收已经整形的多台变流器 `2×2` 全局同步 `dq` 端口导纳及对应 `2n×2n` 网络导纳，在有限频率网格上计算分散式小增益裕量、网络—设备上下相位裕量、设备间总相位跨度裕量及数值待定分类。它没有构造多设备工作点、设备端口导纳或 `E/C/F/W` 回路整形，也没有核验论文定理的动力学前提。

## 依据与反例

| 核验项 | 依据或反例 | 结果 |
|---|---|---|
| 单设备回归 | 论文 Fig. 8 固定的 `D=0.05、0.5` 两组1000点频响 | 增益、相位、覆盖状态、裕量与计数逐点一致 |
| 多设备相位跨度 | 两台设备分别取 `+0.75π` 与 `−0.75π` 的标量相位块，网络逆相位为0 | 每台设备分别满足网络上下界，但总跨度为 `1.5π`，第三项约束明确未通过 |
| 设备置换 | 交换两台设备的数组顺序与标识 | 聚合裕量、状态和计数不变 |
| 非扇形响应 | 数值域含原点于内部的非正规 `2×2` 矩阵 | 相位条件记为未通过；说明文字不外推为闭环失稳 |
| 数值域边界 | 数值域恰好穿过原点的对角矩阵 | 不强制判为非扇形，保留为数值待定 |
| 病态网络 | 条件数超过 `10^12`，但增益裕量可可靠计算 | 保留增益通过证据，相位记为数值待定 |
| 输入契约 | 频率顺序、矩阵维数、标识、有限值与条件数门限 | 非法输入均被拒绝 |

作者 `dec_conditions_multibus.m` 已用于核对多设备奇异值和网络逆相位的计算结构。论文 v2 `sec2_Preliminary.tex` 第63–79行是三项相位约束的直接依据；其中设备间总相位跨度在作者绘图脚本中没有形成完整的自动判定，因此本项目按论文公式补入并以反例单独验证。

## 结论上限与下一接口

本轮证明的是：当已经取得维数和端口次序一致的整形频响时，程序能在离散网格上按论文公式一致地筛查多设备增益与相位约束，并把病态、边界和相位分支问题保留为待定。

当前仍不能声称“任意编辑拓扑已经完整实现论文定理”，因为从网络编辑器到本内核之间尚缺：

1. 多设备交流工作点及局部—全局坐标基准；
2. 各控制结构在该工作点的端口导纳；
3. 每台设备的 `E_i/C_i/F_i/W_i` 及网络侧一致整形；
4. 开环稳定、网络逆稳定、无右半平面相消、端点与连续全频覆盖等定理前提；
5. 闭环特征根或时域响应的同工作点交叉验证。

接口规范见 `docs/specs/algorithms/sampled-decentralized-screening.md`。下一步应优先定义多设备工作点—设备端口导纳—整形矩阵的数据契约，而不是把未整形的网络导纳直接送入本模块。
