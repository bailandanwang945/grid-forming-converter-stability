# v0.5 任务导向总览与 ECharts 分析交互

## 变更目的

将前端从项目模块目录改为面向稳定性核查人员、系统规划人员和变流器控制设计人员的任务入口，并提高频率图用于频段定位和证据解释的能力。

## 变更范围

- 新增默认任务总览和四项任务入口；
- 工作区改称“判据核查、参数域评估、网络分析、设备与控制”；
- 总览逐项声明实际模型能力，并保留“不是正式并网认证系统”的边界；
- 论文基线图增加 ECharts 缩放、恢复、图像导出、未覆盖频带、主导模态和双图交互组；
- 不改变后端接口、数值结果、模型假设或导出数据。

## 验证结果

| 检查 | 结果 |
|---|---|
| React / TypeScript 生产构建 | 通过 |
| 真实 Chromium 全流程 | 连续三次 `BROWSER_E2E_SMOKE_OK` |
| 默认入口 | 任务总览可见，三类用户和认证边界可见 |
| 总览自适应布局 | 900 px两列、620 px单列，均无横向溢出 |
| 四项入口 | 均进入对应既有工作区 |
| 原有计算与导出 | 全流程通过 |
| 图表视觉复核 | 缩放条、未覆盖频带、主导模态和工具栏可见 |

## 已知代价与边界

- ECharts交互组件使主包增至约 `793.83 kB`（gzip约 `266.76 kB`），后续宜将论文判据工作区继续按需加载；
- 图表交互改善证据阅读，不提高稳定性结论的理论等级；
- 当前仍不是厂商模型接入平台或正式并网认证系统。
