# 共有 VSM/Q–V 外环与功率测量端口核查报告

## 总体判断

M3.2 已完成。团队有功测量和调制延迟取理想极限、Sienna PLL 阻尼关闭后，两套实现的共有 VSM、Q–V 与内环方程可以在加载平衡点闭合；但原始功率测量位置不同，必须作为结构契约单列，不能用参数调节掩盖。

## 已验证事实

- 功能提交：`93ea3d489eb9e8b486e34923bf9a43350c38267c`。
- “双方都在滤波电容端测量”与“双方都在 PCC 测量”两个13状态中间算例均通过平衡点和状态矩阵门。
- 平衡点残差分别为 `2.220×10^-13` 与 `2.487×10^-13`；矩阵最大差分别为 `6.724×10^-7 s^-1` 与 `4.018×10^-7 s^-1`。
- 两个算例都出现约 `3.4 Hz` 的低频支路，并保留约 `112 Hz` 的宽频右半平面支路；谱横坐标分别为 `+195.1454` 与 `+200.0131 s^-1`。
- 混用滤波电容端与 PCC 功率时，矩阵最大差约为 `500 s^-1`，反例门拒绝该结构错配。
- 固定 JSON SHA-256：`FA9FC2907D05AA748B7AC04E866B45B80198C398BD1EA0F65A80A6A97C454821`。

## 适用范围

- 两个算例均为共同结构中间模型，不是原始 Sienna Test 08 或团队16状态完整模型。
- 团队有功测量与调制延迟在本层取理想极限；PLL 阻尼、有源阻尼和外部网络动态尚未比较。
- 结果说明功率测量端口会移动极点，但不证明该端口是唯一失稳机理。
- 结果不确认 Julia/PSCAD、EMT、硬件或论文稳定性充分条件。
