# 全局同步 dq 网络导纳编译器核验记录

## 核验结论

状态：**首版网络编译链通过软件验证；论文判据接口尚未完成。**

当前实现能够将可编辑拓扑中的投运串联 RL 线路装配为全局同步 dq 节点导纳，在无限大母线接地后对无源内部母线实施带数值条件门的 Kron 约简，并把端口奇异值显示在网页中。这一结论不包含多变流器工作点、设备导纳、闭环稳定性或论文定理前提。

## 反例与交叉核对

| 核验项 | 参照或反例 | 结果 |
|---|---|---|
| 单支路解析式 | 与 `average_dq_model.external_line_admittance` 在 `0、0.2、2、20 Hz` 对照 | 一致 |
| 接地单线路 | 两母线、一端为无限大母线 | 端口矩阵等于线路导纳 |
| 串联网络 | 两条 RL 线路，中间母线作 Kron 消元 | 等于阻抗相加后求逆 |
| 并联网络 | 两条投运支路与一条停运支路 | 投运导纳相加；停运支路无贡献 |
| 母线置换 | 改变 `buses` 存储顺序 | 端口 ID 对齐后结果不变 |
| 电流守恒 | 无并联支路时全网施加同一 dq 电压 | 节点注入为零 |
| 奇异内部块 | `Yee=0` | 拒绝约简并报告数值待定 |
| 未建模负荷 | 拓扑含静态恒功率负荷 | 明确拒绝，不静默忽略 |
| 作者代码结构 | `kron_reduction_dq.m`、`dec_conditions_multibus.m` | dq 对分块与 Schur 补次序一致 |

## 结论上限

本轮证明的是“图结构—线路局部方程—节点导纳—接地—Kron 约简—端口频响”这一软件与数学链条在规定反例下保持一致。它尚未证明：

- 任意类型电网元件均已支持；
- 任意负荷可被忽略或等效；
- 多台 GFM 的工作点与端口导纳已正确形成；
- 网页曲线本身能够推出闭环稳定或论文充分条件成立；
- 采样频率结果等价于连续全频定理验证。

因此，下一步应先建立多设备工作点与端口导纳契约，再把本网络矩阵接入经修正的功率—极坐标整形和有限频率网格筛查；在七项定理前提未核验前，`theorem_status` 仍应保持未评价。
