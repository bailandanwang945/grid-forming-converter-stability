# v0.5 MathWorks 外部验证证据接入测试记录

## 接入范围

- 三份固定产物：三点 SCR、有功阶跃 2×4 阻尼因子、SCR=5 阻尼分类过渡区。
- 后端只读接口：`GET /api/evidence/mathworks-gfm`。
- 前端入口：平均值 `dq` 科研画布第五张“MathWorks 固定模型参照”任务卡。
- 发布范围：仅打包三份结果 JSON，不打包上游 Simscape 模型或 MATLAB 运行时。

## 失败门

- 任一结果文件缺失或 SHA-256 改变时，接口拒绝返回。
- 三份证据的上游提交不一致时，接口拒绝聚合。
- 页面必须同时展示供应商分类区间与项目跟踪门区间，不得合并为“临界阻尼”。
- 页面必须说明不构成特征根边界、连续稳定性证明、硬件确认或论文稳定性充分条件验证。

## 验证结果

- 新增后端定向测试：`2/2` 通过。
- TypeScript 与 Vite 生产构建：通过；主包体积告警沿用既有记录，不作为功能失败。
- 真实 Chromium 端到端流程：通过，输出 `BROWSER_E2E_SMOKE_OK`；覆盖任务卡点击、四项摘要、研究边界和 JSON 下载。
- 首轮后端全量回归：`152/153`，唯一失败为发布启动冒烟的一次 Windows `10053` 连接中止；相同用例随即单独重跑通过并输出 `GFM_RELEASE_SMOKE_OK`。
- 最终后端全量回归：`153/153` 通过，耗时 `288.342 s`；发布入口返回 `GFM_RELEASE_SMOKE_OK` 并正常退出。

## 研究边界

软件接入没有提高原始证据等级。网页读取的是固定版本外部模型的离散时域结果，不会在没有 MATLAB 的电脑上重新运行 Simulink，也不能据此声称得到临界阻尼、闭环特征根边界、唯一机理或实物验证。本轮未制作或修改 PPT/PDF。
