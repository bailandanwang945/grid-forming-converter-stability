## 3. 16状态正序平均值 dq 模型

首版范围固定为一台 VSM 构网型变流器、LCL 滤波器、单条外部 RL 线路和无限大母线。默认校核工况的主要结果为：

| 项目 | 数值或结论 |
|---|---:|
| 稳定性分类 | stable |
| 主导极点 | `-2.791023 ± j10.302688 s^-1` |
| 主导振荡频率 | `1.639724 Hz` |
| 工作点闭环动态残差 | `5.95e-14` |
| 稳态有功平衡残差 | `7.76e-17 p.u.` |
| 直接闭合与端口重组矩阵最大误差 | `5.74e-9` |
| 工作点同步刚度 | `2.458787 p.u./rad` |
| 三状态近似振荡频率相对误差 | `0.844%` |
| 三状态近似衰减率相对误差 | `2.413%` |

自动测试还覆盖空载解析工作点、坐标整体旋转不变性、外部 RL 导纳解析式、中心差分步长收敛、非线性—线性小扰动响应、自由衰减辨识、阻尼变化下的稳定—失稳跨越和非法模型范围拒绝。上述检查共同支持“当前方程与软件实现自洽”，但不支持“已经拟合某台硬件”或“已经替代 EMT/实物试验”。
