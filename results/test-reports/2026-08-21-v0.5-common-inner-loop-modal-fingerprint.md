# 共有内环约100 Hz模态指纹核查报告

## 总体判断

M3.1 已完成。在四个固定输入共有内环中间模型中，约 `100–104 Hz` 的命名支路均通过左右特征向量、特征值距离、条件数与残差门连续追踪。冻结团队坐标基下的参与度和单因素灵敏度共同支持“LCL—电压控制相互作用”候选解释，但不构成唯一因果归因。

## 已验证事实

- 功能提交：`4f852c0e`。
- 10状态两条路径的命名支路频率为 `103.861 Hz` 与 `104.102 Hz`；12状态两条路径为 `99.949 Hz` 与 `100.151 Hz`。

- 四个变体的局部实部灵敏度首项均为 `X2`，最大绝对实部位移约为 `29.48–32.89 s^-1`。
- `X2` 是 LCL 网侧滤波电抗，不是外部电网电抗或 SCR；本实验没有扫描电网强度。
- `X2` 从1倍直接跳到5倍时匹配门拒绝直接续接；插入几何中点后恢复支路，反例有效。

- 结论只针对两条10状态和两条12状态固定输入共有内环中间模型，以及预先固定的 `0.8/1.2` 单因素端点。

- 当前是命名支路的局部追踪，不是全谱全局连续化，也没有给出连续稳定边界。
