# 项目会话档案

本目录按负责人明确要求保存本项目会话的用户正文和助手可见回复，用于队友接续开发、回查研究决策与整理结项材料。不是原始 Codex 日志备份，也不收录其他会话、隐藏推理、工具原始记录或账号资料。

- [会话正文（隐私脱敏版）](2026-10-11-project-conversation.md)：按时间排列，不以摘要代替原文。
- [完整性清单](2026-10-11-project-conversation.manifest.json)：记录消息数、快照边界、脱敏统计及正文文件的 SHA-256。
- [项目开发日志](../PROJECT_LOG.md)：接续工作时优先阅读；历史会话很长，不宜每次全部载入。
- [项目计划](../../docs/PROJECT_PLAN.md)与[网络编辑器说明](../../docs/software/NETWORK_EDITOR.md)：当前范围和操作说明。
- [本次推送检查](../../results/test-reports/2026-10-11-pre-push-check.md)：本次实际复核范围，不代替历史实验的独立验证。

## 保存边界

导出只读取指定会话的固定大小快照，并核对会话标识。正文中的个人用户目录、微信标识、疑似凭据及手机号进行脱敏；非文本附件只保留提示，不复制图片、PDF等原件。运行环境附加块和内部压缩摘要不作为用户发言。

这里的“完整”仅指该快照中可恢复的可见正文。记录本身已经省略或截断的文字无法还原；本次导出之后新增的回复也不在该版正文内。历史消息原样保留，并不意味着其中所有旧判断仍然成立。数值结论、研究贡献和软件完成度以带范围说明的实验记录与当前文档为准。

生成工具为 `scripts/export_visible_conversation.mjs`，必须显式提供单一来源、预期会话标识和输出位置；不扫描账户内其他会话。其范围与脱敏测试为 `scripts/test_export_visible_conversation.mjs`。原始来源保持本地，不进入 Git。
