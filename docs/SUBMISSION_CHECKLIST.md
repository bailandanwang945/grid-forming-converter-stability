### 软件交付 M0—M5

- [x] M0：计划、治理、Git/远程现状、证据等级和旁路问题对齐；
- [x] M1：便携数值内核对 Fig. 8 `D=0.05/0.5` 重现 75/0 个未覆盖点，且 API 移除人工预览公式；
- [x] M2：透明低频 GFM 降阶模型完成稳定/临界/失稳、状态矩阵、极点和线性响应交叉测试；

- [ ] M5：无 Python、Node.js、MATLAB 开发环境的 Windows 发布包完成异机复现，并与最终材料和校验值一致。

M5 当前状态：Windows `v0.3.0-rc3` 从当前材料与代码冻结提交，包内提供 `VERIFY_THIS_PC.cmd`；自动验收覆盖逐文件哈希、静态前端/API、Fig. 8 固定 1000 点（75 个未覆盖点）、同域对照 176 点（45/96/35）、独立模型、打印报告和端口释放，并输出 JSON 与控制台日志。另一台无 Python、Node.js、MATLAB 的电脑仍须人工断网执行该入口并回传证据。

`0.578 Hz` 与论文正文 `1.2 Hz` 的差异、以及 Simplus 自动生成非线性模型的近奇异与异常初始化现象，必须在报告中说明，但不阻断软件主线。该 Simplus 现象尚未建立完整因果解释，不直接定性为工具缺陷；结项前仍应补充可信的非线性时域参照。
