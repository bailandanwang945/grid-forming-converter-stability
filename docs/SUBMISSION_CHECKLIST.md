# 中期检查与结项验收材料清单

> 状态：待学院正式通知校准  
> 最后更新：2026-07-16

本清单依据教育部大创管理办法、天津大学公开答辩案例及历史结题通知整理。具体表格、截止时间、系统入口和文件命名，必须以电气自动化与信息工程学院针对本项目发布的最新通知为准。

## 1. 中期检查前

### 行政材料

- [ ] 中期检查通知、评分表和学院模板；
- [ ] 项目编号、级别、负责人、成员和指导教师信息；
- [ ] 项目内容或成员如有实质变化，确认是否需要变更备案；
- [ ] 指导教师审核意见；
- [ ] 经费使用记录及票据目录（如适用）。

### 研究材料

- [ ] 研究问题、理论依据和当前技术路线；
- [ ] 作者仓库、论文版本、Simplus 版本与许可证记录；
- [ ] 已完成工作和原始实验记录；
- [ ] MATLAB 测试报告；
- [ ] 论文基线复现图及输入参数；
- [ ] 与原计划的差异、原因和调整方案；
- [ ] 下一阶段任务、风险和预期成果。

### 答辩材料

- [ ] 5 分钟汇报 PPT；
- [ ] 3 分钟问答准备；
- [ ] 两分钟内可运行的演示脚本；
- [ ] 备用 PDF、静态图和测试结果，避免现场环境故障；
- [ ] 团队成员均能说明本人实际完成的工作。

建议中期汇报按照“研究问题—理论依据—已完成工作—阶段结果—存在问题—后续计划”的顺序组织，不把尚未验证的设想写成已经取得的成果。

## 2. 结项验收前

### 必备文本

- [ ] 天津大学大创项目结题验收表；
- [ ] 项目总结或研究报告；
- [ ] 项目申报书和经批准的变更材料；
- [ ] 成果一览表及支撑材料；
- [ ] 团队分工、研究过程和学生收获说明；
- [ ] 指导教师审核意见。

### 技术成果

- [ ] 可复现的 MATLAB 源码；
- [ ] 类式单元测试及最终测试报告；
- [ ] 论文无限大母线基线实验；
- [ ] 数值域扇形性临界情形实验；
- [ ] 独立构网型变流器模型实验；
- [ ] 闭环特征根和时域响应结果；
- [ ] 关键结果的输入、参数、版本和生成命令；
- [ ] 已知局限和未完成工作说明。

### 归档与提交

- [ ] `references/SOURCES.md` 与实际外部资源一致；
- [ ] 不包含第三方 `.git`、密钥、缓存和无关大文件；
- [ ] 论文和代码引用准确，团队新增工作边界清楚；
- [ ] 在干净 MATLAB 会话或另一台电脑完成最终复现；
- [ ] 按学院规则命名文件并上传管理系统；
- [ ] 保存系统提交成功截图或回执；
- [ ] 保存答辩最终版 PPT、PDF 和支撑材料包的 SHA-256。

## 3. 版本管理状态

当前项目根目录不是 Git 工作树，尚不能创建 commit。开始正式提交前必须明确以下二选一方案：

1. 经项目负责人授权，在当前目录初始化独立 Git 仓库；
2. 将当前目录纳入已经存在的上级仓库管理。

不得未经授权初始化仓库、创建远端、提交或推送。
