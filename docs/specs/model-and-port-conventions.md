# 模型、坐标与端口约定

日期：2026-08-04
状态：作者适配器约定冻结；通用 Park 变换定义待独立模型阶段补全。

## 1. 适用范围

本文档约束从作者 Cifelli–Anta 算例导入的频率响应、功率—极坐标环路整形以及混合小增益—小相位评价器。它不把作者模型中的隐含缩放推广为所有构网型变流器的通用约定。

## 2. 端口与坐标

- 单台变流器频率响应采用 `delta_v_dq -> delta_i_dq` 的 2×2 导纳形式；
- 各装置和 Kron 约简网络必须先旋转到同一个全局同步 `dq` 坐标；
- 作者模型输出为 `[i_d,i_q]`，其功率方程采用负载约定；网络端口电流与变流器端口电流方向相反；
- 因上述电流方向差异，变流器和网络的整形分别使用 `+C` 与 `-C`；不得通过试算稳定性来反推符号；
- 软件输入必须提供 `frameConventionId`。作者适配器固定为可回归的矩阵快照，不使用含混的“标准 Park 变换”标签。

作者论文和代码没有完整给出 abc/dq 的变换矩阵、幅值不变或功率不变缩放，也没有解释功率式中省略的 `3/2` 是否已吸收到标幺值。因此这些内容当前记为“未由来源确认”，不能写成长期事实。

## 3. 基值

作者无限大母线工作簿采用：

- `f_base = 50 Hz`；
- `S_base = 1 VA`；
- `V_base = 1 V`；
- 电气参数和工作点按标幺值解释。

通用接口不得依赖这些默认值。每个输入案例必须显式给出 `S_base`、`V_base`、`f_base`、原始矩阵类型（导纳或阻抗）以及坐标对齐信息。

## 4. 功率—极坐标一阶变换

令工作点为

\[
v_0=v_{d0}+\mathrm{j}v_{q0},\qquad
i_0=i_{d0}+\mathrm{j}i_{q0},\qquad
V_0=\sqrt{v_{d0}^2+v_{q0}^2}>0.
\]

由功率与极坐标关系的一阶线性化，作者适配器使用

\[
E=\begin{bmatrix}
v_{d0}&v_{q0}\\
v_{q0}&-v_{d0}
\end{bmatrix},\qquad
C=\begin{bmatrix}
i_{d0}&i_{q0}\\
-i_{q0}&i_{d0}
\end{bmatrix},
\]

\[
F=\begin{bmatrix}
-v_{q0}&v_{d0}/V_0\\
v_{d0}&v_{q0}/V_0
\end{bmatrix},
\qquad
F^{-1}=\begin{bmatrix}
-v_{q0}/V_0^2&v_{d0}/V_0^2\\
v_{d0}/V_0&v_{q0}/V_0
\end{bmatrix}.
\]

相应整形矩阵为

\[
J_{C,i}=(E_iY_{C,i}+C_i)F_i,
\qquad
\mathbf J_{\mathrm{net}}
=(\mathbf E\mathbf Y_{\mathrm{net}}-\mathbf C)\mathbf F.
\]

因此必须满足恒等式

\[
\mathbf J_C+\mathbf J_{\mathrm{net}}
=\mathbf E(\mathbf Y_C+\mathbf Y_{\mathrm{net}})\mathbf F.
\]

## 5. 论文 v2 勘误

v2 TeX 的式(10)和式(11)不能直接作为实现依据：

- 排印的 `F^{-1}` 缺少若干 `V_0` 归一化项，第二行首项也误写；
- `C` 的 `(1,2)` 元素写成了 `v_{q0}`，量纲不成立，应为 `i_{q0}`；
- 项目旧计划把完整混合变换称为“v2式(19)”，实际应为式(17)。

本项目采用一阶微分、矩阵互逆检查和作者多机代码三者一致的修正版。任何后续论文复现均应保留这项勘误，不得悄然改式。

## 6. 混合动态整形

\[
H_{\mathrm{LPF}}(s)=\frac{\omega_c}{s+\omega_c},\qquad
H_{\mathrm{HPF}}(s)=1-H_{\mathrm{LPF}}(s),
\]

\[
E_i(s)=E_{J,i},\qquad
C_i(s)=H_{\mathrm{LPF}}(s)C_{J,i},
\]

\[
F_i(s)=H_{\mathrm{LPF}}(s)F_{J,i}
+H_{\mathrm{HPF}}(s)W_i(s)E_{J,i}^{-1}.
\]

作者算例取 `f_c=0.5 Hz`，即 `omega_c=2*pi*f_c`，且 `W_i=Y_v^{-1}`。作者代码还按 `abs(R_v+j*omega_0*L_v)` 归一化虚拟阻抗矩阵；该值必须进入案例配置和追溯信息。

## 7. 实现验收门

1. 非单位工作点用有限差分验证 `E,C,F`；
2. 数值验证上述互联恒等式；把网络侧误写成 `+C` 时测试必须失败；
3. 直角坐标模式 `E=F=I,C=0` 必须严格退化为原始导纳；
4. 动态 `F(jw)` 必须报告全频条件数和奇异点；
5. 作者适配器必须通过固定输入—输出矩阵快照回归；
6. 在以上条件满足前，不得把通用软件标为“支持任意 dq/Park 约定”。
