# Sectoriality Classifier：实现与测试计划

> 版本：0.2
> 最后更新：2026-07-16

## 1. 实现顺序

1. 冻结 `classifyNumericalRange(A, options)` 接口；
2. 编写解析矩阵的类式单元测试；
3. 实现输入验证和默认选项；
4. 实现 Hermitian 投影最小特征值计算；
5. 实现角网格粗搜索和局部细化；
6. 实现尺度化分类和结果结构体；
7. 运行测试并记录 MATLAB 版本和结果；
8. 在 Phase 2 增加论文频点回归测试。

自适应增量采用独立接口 `classifyNumericalRangeAdaptive`，不替换均匀网格基线。实现顺序为：先固定解析包络和预算停止测试，再实现归一化、周期区间初始化、最大上界区间二分、分类停止条件及结果元数据。

## 2. 单元测试计划

测试类：`tests/classifyNumericalRangeTest.m`。

| 测试 | 输入 | 预期 |
|---|---|---|
| 严格扇形 | `diag([1,2])` | `strict-sectorial`，正裕度 |
| 旋转严格扇形 | `exp(1j*0.317)*diag([1,2])` | 分类不变，最佳角随旋转 |
| 边界 | `diag([0,2])` | 候选 `boundary`；证据不足时为 `indeterminate` |
| 非扇形 | `[0,1;0,0]` | `non-sectorial`，负裕度 |
| 退化 | `zeros(2)` | `degenerate` |
| 尺度不变性 | `A`、`1e8*A`、`1e-8*A` | 分类相同，归一化裕度一致 |
| 非方阵 | `ones(2,3)` | 指定错误 ID |
| 非有限值 | 含 NaN 的方阵 | 指定错误 ID |
| 非法选项 | `NumAngles < 16` | 指定错误 ID |
| off-grid 非正规族 | `exp(jα)[1,k;0,1]` | 与解析裕度 `1-|k|/2` 一致 |
| 无细化漏检反例 | `α=π/16,k=1.99,N=16` | 不得误报非扇形，应为 `indeterminate` |
| 复数选项 | 复数角点数/容差 | 稳定错误 ID |
| 酉相似变换 | `U^*AU` | 分类和归一化裕度不变 |

自适应测试类：`tests/classifyNumericalRangeAdaptiveTest.m`。

| 测试 | 预期 |
|---|---|
| Jordan 严格/边界/非扇形解析族 | 解析裕度位于返回包络内 |
| 近边界非扇形 Jordan 矩阵 | 在给定预算内由负的全局上界确认 |
| 边界带 | 包络全部进入配置容差带后输出 `boundary` |
| 评价预算耗尽 | 输出 `indeterminate` 和 `evaluation-budget` |
| 不同评价预算 | 下界单调不减，上界单调不增 |
| 正比例缩放 | 分类和归一化包络保持一致 |
| 非法预算 | 产生稳定错误 ID |

## 3. 测试规范

- 所有测试继承 `matlab.unittest.TestCase`；
- 使用 Arrange–Act–Assert；
- 测试方法内不使用条件语句或循环；
- 浮点值使用 `AbsTol` 或不等式验证；
- 通过 `PathFixture` 添加 `src/`；
- 测试相互独立，可在干净 MATLAB 会话运行。
