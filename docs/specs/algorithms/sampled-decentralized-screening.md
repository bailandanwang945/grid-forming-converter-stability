# 多设备分散式判据的有限网格筛查规范

## 1. 用途与边界

本模块接收已经完成回路整形的频率响应，并在给定频率网格上筛查论文所述的分散式小增益条件与分散式小相位条件。输入包括：

- 第 `i` 台构网型变流器的全局同步 `dq` 端口导纳 `J_Ci(jω)`，每台设备为 `2×2`；
- 与设备端口顺序一致的网络导纳 `J_net(jω)`，`n` 台设备对应 `2n×2n`；
- 严格递增的非负频率网格。

这里的“已经整形”具有严格含义：本模块不自行构造 `E_i(s)`、`C_i(s)`、`F_i(s)` 或 `W_i(s)`，也不核验这些变换是否适定。未整形的网络 `dq` 导纳不能直接作为论文统一判据的完整输入。

## 2. 有限网格上的增益筛查

每个频点计算

```text
g_C(ω)   = max_i σ_max(J_Ci(jω))
g_net(ω) = σ_min(J_net(jω))
m_g(ω)   = g_net(ω) - g_C(ω)
```

当 `m_g` 严格为正时，记为增益条件通过；严格为负时，记为未通过；落入相对容差带时，记为数值待定。该实现与论文分散式增益条件一致，也与作者代码 `dec_conditions_multibus.m` 中逐设备最大奇异值和网络最小奇异值的计算结构一致。

## 3. 有限网格上的相位筛查

对于能够确认严格扇形性的矩阵，先求规范相位区间，再依据首个可解析频点建立相位分支，并采用最近邻连续展开。令网络阻抗矩阵为

```text
Z_net(jω) = J_net(jω)^(-1)。
```

每个频点同时检查三类裕量：

```text
m_u,i = π - upper_phi(Z_net) - upper_phi(J_Ci)
m_l,i = lower_phi(J_Ci) + π + lower_phi(Z_net)
m_s   = π - [max_i upper_phi(J_Ci) - min_i lower_phi(J_Ci)]
```

只有全部设备的 `m_u,i`、`m_l,i` 以及设备间总相位跨度裕量 `m_s` 均严格为正，才记为相位条件通过。第三项不能省略：即使每台设备分别处于网络给出的上下相位界限之内，不同设备的相位区间合并后仍可能跨越超过 `π` 的范围。

当前数值域算法只为**严格扇形矩阵**返回相位区间。论文允许变流器为准扇形矩阵，因此本实现是偏保守的可执行子集；遇到原点位于数值域边界附近、网络矩阵病态或相位分支无法连续追踪时，结果记为数值待定，不强制并入通过或未通过。

## 4. 组合覆盖状态

每个频点依次归入：

- `both-pass`：增益条件和相位条件均通过；
- `gain-pass`：仅增益条件通过；
- `phase-pass`：仅相位条件通过；
- `uncovered`：两项条件均明确未通过；
- `indeterminate`：至少一项无法可靠分类，且另一项没有通过。

即使所有离散频点均被覆盖，返回值仍固定为

```text
theorem_status = not-evaluated-by-sampled-api
```

原因是接口尚未核验开环系统是否为实系数有理、稳定且正则（proper）的传递函数矩阵，也未核验回路变换适定性、整形网络逆的稳定性、右半平面零极点相消、零频与无穷远端点以及连续全频域覆盖。反之，`uncovered` 也只说明该充分判据在相应频点未得到满足，不能据此断言闭环系统必然失稳。

## 5. 与项目其他模块的关系

```text
可编辑拓扑与参数
        ↓
网络 dq 端口编译器（未整形 J_net）
        ↓
多设备潮流/工作点 + 各设备端口导纳 + E/C/F/W 回路整形（尚待实现）
        ↓
本模块：有限频率网格上的分散式判据筛查
        ↓
闭环特征根或时域响应交叉验证
```

因此，本模块补齐了判据计算的多设备代数核心，但没有绕过工作点、设备模型和定理前提三个研究问题。
