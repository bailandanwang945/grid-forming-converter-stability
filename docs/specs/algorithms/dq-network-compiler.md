# 全局同步 dq 网络导纳编译器

日期：2026-09-04
状态：无源串联 RL 网络首版已实现；多变流器判据接口待完成。

## 1. 目的与边界

本编译器把 `NetworkTopology/1.0` 中的投运交流线路转换为采样频率上的全局同步 dq 节点导纳矩阵，并把无源内部母线约简到构网型变流器接入母线。它只回答“给定无源网络在这些端口和频率上的增量导纳是什么”，不求解潮流，不计算工作点，不叠加变流器导纳，也不直接评价闭环稳定性或论文充分条件。

端口电流正方向规定为“由端口注入网络为正”，每个母线的分量顺序固定为 `[d,q]`。所有母线必须处于同一全局同步 dq 坐标；不得把局部转子坐标下的设备导纳未经旋转直接装入本矩阵。

## 2. 串联 RL 支路

设线路标幺电阻、电抗分别为 `R`、`X`，系统基频角速度为 `ω_b`，小信号复频率为 `s`。从首端到末端的支路阻抗为

\[
Z_e(s)=\left(R+\frac{X}{\omega_b}s\right)I_2+XJ,
\qquad
J=\begin{bmatrix}0&-1\\1&0\end{bmatrix},
\]

支路导纳为 `Y_e(s)=Z_e(s)^{-1}`。该式与项目16状态平均值 dq 模型的外部线路解析导纳一致，也与 Simplus 动态线路的同步 dq KVL 符号相符。

若线路给出非负总并联电纳 `B_c`，首版按对称 π 型电容支路处理，两端各装配

\[
Y_{c,e}^{\mathrm{half}}(s)=\frac{B_c}{2}
\left(\frac{s}{\omega_b}I_2+J\right).
\]

负并联电纳可能代表与电容不同的元件机理，当前契约未标明元件类型，故编译器拒绝自行推断。

## 3. 节点装配

对连接母线 `i,j` 的每条投运线路，串联导纳按

\[
\begin{bmatrix}I_2\\-I_2\end{bmatrix}
Y_e(s)
\begin{bmatrix}I_2&-I_2\end{bmatrix}
\]

加入相应四个节点块，并把 π 型并联电纳的一半分别加入两端对角块。停运线路仍保留为领域实体，但其局部贡献为零。

此过程等价于块关联矩阵表达

\[
Y_{\mathrm{bus}}(s)=\sum_e S_e^{\mathsf T}\widehat Y_e(s)S_e.
\]

因此，并联支路自然执行导纳相加；在无并联接地支路时，全网施加相同 dq 电压应得到零节点注入电流，可作为电流守恒反例门。

## 4. 接地与 Kron 约简

无限大母线的小信号电压固定为零，故先删除其对应的完整 dq 行列，得到未接地母线子矩阵。将构网型变流器接入母线记为保留集合 `r`，其余无源内部母线记为消去集合 `e`，则

\[
Y_{\mathrm{port}}(s)
=Y_{rr}(s)-Y_{re}(s)Y_{ee}(s)^{-1}Y_{er}(s).
\]

实现采用线性方程求解 `Yre·solve(Yee,Yer)`，不显式构造逆矩阵。每个频率点均计算 `cond(Yee)`；条件数非有限或大于声明上限时，将结果标为数值待定并终止该次编译。保留母线与消去母线必须完整、互斥地覆盖未接地母线，且只能按完整 dq 对进行处理。

## 5. 与作者代码的关系

作者仓库 `kron_reduction_dq.m` 同样按完整 dq 母线对重排 `Yrr,Yre,Yer,Yee` 并计算 Schur 补；`dec_conditions_multibus.m` 在将无限大母线等效接地、消去空母线后，才对约简网络导纳作功率—极坐标整形。当前 Python 实现复用了这一数学结构，但作了两项数值与接口强化：

1. 无限大母线采用明确的 Dirichlet 小信号接地，不用 `1e14` 大导纳近似；
2. 对内部块设置条件数门限，并用求解线性方程代替显式求逆。

这只建立网络约简层的一致性，不表示作者多机判据已经在本软件中完整复现。

## 6. 验收门

1. 单条接地线路的端口导纳必须等于其解析 RL 导纳；
2. 两条串联线路经约简后必须等于阻抗相加再求逆；
3. 并联线路必须满足导纳相加，停运线路不得产生贡献；
4. 母线存储顺序改变后，将结果按端口 ID 对齐，端口导纳不得改变；
5. 无并联支路时，统一母线电压必须满足节点电流守恒；
6. 奇异或病态内部块必须返回数值待定；
7. 未定义的静态负荷增量导纳不得被静默忽略；
8. API 必须同时返回频率、端口顺序、接地与消去母线、条件数和模型范围。

进入论文判据接口之前，还必须补齐：多台变流器各自的工作点求解、全局坐标下端口导纳、功率—极坐标变换、网络逆稳定性、无右半平面消去及连续全频覆盖等前提。
