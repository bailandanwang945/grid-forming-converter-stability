# 工程主接线输入功能：最小实施方案

日期：2026-10-06。状态：最小实施方案；接线检查分离与局部连接试验先行，其余能力为后续规划。

## 1. 任务与范围

用户希望借助工程主接线图，编辑母线、设备连接和开关状态，并判断能否正常分析。
本方案服务于大创结项：先让输入、模型适用范围和计算结果对应，不开发完整电气 CAD。
本轮整理方案与图纸小系统，并实施接线检查与分析适用性分离、局部开关连接检查。
不安装分析库，不承诺工程接线编辑、通用潮流或短路计算已完成。
两张火电厂接线图不含构网型变流器，不能直接交给现有 GFM 稳定性内核。
后续若在图纸派生的小系统中添加变流器，必须明确它属于自建算例，不属于原图复现。

目标用户：学习或研究构网型变流器并网的本科生、教师及工程研究人员。
典型任务：改变设备参数或接线状态，重新计算，比较运行点或振荡模态，并导出对应报告。
一次演示以一个小规模网络完成上述任务为准，不以设备数量和界面按钮数量作为成果依据。

## 2. 目前已有与尚未具备的能力

下表依据 2026-10-06 当前工作树中的实现，而非历史规划或 README 的概括。

| 内容 | 当前实际情况 | 对工程主接线的影响 |
|---|---|---|
| 母线、线路、GFM、无限大母线 | 有数据契约、图形编辑和部分参数输入 | 可表达研究用母线—支路网络 |
| 静态负荷 | 有数据契约，当前图形编辑器未生成负荷图节点 | 不能据此宣称已有完整负荷建模流程 |
| 线路投退 | 整条线路 `in_service` 开关 | 不等同于各端断路器、隔离开关 |
| 变压器、同步发电机 | 没有相应工程设备模型 | 无法直接表达火电厂多电压等级网络 |
| 接线检查 | 本轮已拆分前端接线检查与低频模型适用性 | 无 GFM、缺参考和不连通不等于接线引用错误；后端完整契约未改 |
| 低频降阶模型 | 使用平坦工作点的线路 `1/X` 同步刚度 | 不能给出通用潮流或短路结果 |
| 平均值 dq 模型 | 限单台 VSM、单条 RL 线路、一个无限大母线且无负荷 | 不能分析任意工程主接线 |
| 通用潮流、短路服务 | 尚未形成已接入的公开功能 | 不展示虚构计算结果或原型结果作为正式功能 |

低频降阶内核还忽略线路电阻、并联电纳、无功—电压耦合、负荷及其动态、内环和电磁暂态。
其中 P/Q 设定值、负荷 P/Q、无限大母线幅值与相角目前仅用于契约校验和留痕。
源码中的 `backend/core/network_power_flow.py` 是独立原型；目前未发现其他服务对它的调用。
不能将该原型等同于已完成潮流页面、工程元件适配和交叉验证。

## 3. 三层数据与计算关系

建议采用“设备端子—开关状态—计算母线”三层关系，避免图形与计算概念混用。

1. **设备与端子层**：记录母线段、接线点、设备、端子及固定连接；保留图纸编号。
2. **运行接线层**：记录每个断路器、隔离开关的当前分合状态及设备是否投运。
3. **计算模型层**：由运行接线生成所选分析方法所需的母线、支路、边界与参数。

图形位置、走线折点、标注位置属于版面数据，不参与电气方程，也不触发结果失效。
连接关系、开关状态和电气参数属于计算输入；修改后将旧结果明确标为“输入已变更”。
端子必须有唯一 ID、所属设备、端子类型和电压等级；连接不能只依赖图上相交或贴近。
线路和变压器的两个端子保持独立；在图上接近不代表在电气上短接。

### 3.1 理想开关与连接编译

- 固定导线与闭合的理想开关可合并等电位接线点，生成计算母线。
- 开断的开关不产生导通连接，但设备及其端子仍保留在工程接线数据中。
- 线路阻抗、变压器阻抗及设备本体不能作为导线合并。
- 每个计算母线保留对应接线点清单；每条计算支路保留对应设备和开关编号。
- 不同电压等级只能通过合适的变压器模型连接，不能借线路或闭合开关绕过检查。
- 单端断开的线路不一定等于整条线路停运；有并联电纳时，应由分析模型处理其剩余连接。
- 编译发现理想电源约束冲突或不支持的设备短接时，返回具体设备编号，不能静默删去。

### 3.2 开关状态约定

分合状态使用 `closed=true/false`；设备投退单独使用 `in_service=true/false`。
“正常合闸/正常断开”属于缺省运行方式，不覆盖用户保存的当前状态。
检修标记不自动等同于断开所有相关开关；应保存具体分合状态和检修说明。
初版仅检查连接和供电路径，不模拟保护动作、开关动作时间、操作票或防误闭锁。
接地开关可保留图纸标记，但初版不接入故障分析；出现接地投入时明确提示模型不适用。

## 4. 最小实施内容

### 必做 A：先修正检查与结果边界

- 将检查分为“接线检查”“参数检查”“分析适用性”，分别显示结果和设备编号。
- 接线检查负责 ID、端子引用、非法跨电压连接、连通分量和电源所在区域。
- 接线检查允许保存停运、断开及无电源区域，不把这些状态一概判为数据无效。
- 用“有电源连接区域/无电源连接区域”描述拓扑判断；不能仅凭连接判断真实电压或带电状态。
- 分析适用性逐个说明：是否有 GFM、控制方式、外部参考、负荷和网络规模是否受支持。
- 无 GFM 的接线可保存与检查，但不能运行当前 GFM 降阶或平均值 dq 稳定性分析。
- 不将无 GFM、孤岛或缺参数分别压缩成含混的“结构错误”或“分析失败”。

### 必做 B：最小工程接线编辑与保存

- 支持母线段、固定导线和独立开关；保留现有线路、GFM 和外部参考电源。
- 母线采用易辨识的条形符号；线路采用清晰的正交走线，连接点有明确标记。
- 支持设备参数编辑、端子重接、开关分合、选中设备定位和撤销。
- 展示设备编号、电压等级和开关状态；参数表注明单位，额定值与运行值分别显示。
- 完整保存设备、连接、开关状态、缺失参数、版面、版本和来源；导入后重算而非复用旧结果。
- 未支持的变压器、同步发电机可作为草稿设备登记，但不得伪装成能参与计算的图标。
- 草稿设备进入所选计算区域时，明确列出阻断项；不自动忽略，不转换为 GFM。

本轮先实施 A 中的前端检查分离，以及图纸小系统的独立连接检查；B 仍是后续实施建议。
不因此更改既有网络 API 契约、数学内核或承诺新的设备计算模型已经完成。
不能直接以新草稿数据替换旧 `NetworkTopology/1.0`：应设计新版本并保持现有算例可读取。

2026-10-07实施补记：已接入普通固定导线与阻抗线路的分离、母线图形长度及拖动端点、理想导线等电位节点转换；新外层案例1.2保留原图，转换后仍调用既有NetworkTopology/1.0接口。独立开关、任意母线折弯/接点、变压器及完整工程接线编译仍未完成，不把这一局部进展说成上述B全部实现。操作与测试见[网络接线说明](../software/NETWORK_EDITOR.md)和[本轮记录](../../results/test-reports/2026-10-07-network-connection-semantics.md)。

### 可选：确认任务需要后再增加

- 接入经过验证的两绕组变压器、静态负荷和同步发电机稳态模型，支持有限范围潮流。
- 对变流器明示所用稳态端口模型、运行限值及控制假设，不将 PV/PQ 节点当作完整 GFM 控制。
- 增加含变流器短路计算前，先确定故障类型、序网络、限流与故障期间控制假设。
- 初步优先级为潮流在前；GFM 三相短路电流估算可选，不包含故障恢复稳定性或保护定值。
- 变流器潮流及短路的具体方法、适用性与引用，见同目录的 [专项可行性评估](converter-power-flow-short-circuit-feasibility-2026-10-06.md)。
- 可增加工况复制和开关状态对照，但先保证每份报告对应其保存输入和实际计算结果。

### 本阶段不做

- 不做 DWG/PDF 自动识别接线、完整 CAD 标注、保护整定或设备选型。
- 不做全厂同步发电机、励磁、调速及厂用电动态仿真。
- 不宣称替代 MATLAB/Simulink、作者代码或通用电力系统商业软件。
- 不把图形编辑、常规潮流、短路或参数扫描本身表述为新的稳定性分析方法。

## 5. 参数、基准与缺失信息

工程输入优先使用 SI 单位，并明确：线电压为三相线间有效值，额定容量为三相视在功率。
统一展示电压 kV、功率 MW/Mvar/MVA、频率 Hz、阻抗 Ω 或明确基准的标幺值。
全网容量基准与各电压等级的电压基准必须记录；不同设备自身基准先换算后进入计算。
有功、无功采用统一网络注入符号；负荷的正消耗量在转换时变为负注入，禁止重复反号。
额定功率不自动当作运行功率，额定电流不自动转换为线路阻抗。
线路至少区分 R、X、并联电纳及其来源；变压器区分额定值、短路阻抗、损耗、变比和分接头。
潮流的平衡节点、PV 节点和 PQ 节点定义需在界面首次出现时解释，不从设备名称隐式猜测。
未知参数保持缺失，并指出它阻止哪种分析；为演示另设假定值时必须标注“自建演示参数”。

## 6. 小规模测试场景与通过条件

| 场景 | 应观察到的行为 | 不得出现的行为 |
|---|---|---|
| 仅拖动母线或设备 | 电气输入不变，计算结果与输入版本保持对应 | 因布局改变而重算或改变极点 |
| 两段同电压母线，母联分合 | 闭合时节点合并，断开时保留独立区域及映射 | 用很小线路阻抗冒充开关 |
| 一段母线无电源 | 接线可保存，分析提示该区域缺参考或电源 | 伪造电压或把负荷当电源 |
| 线路单端断开与整条停运 | 状态不同；按模型说明编译或提示不支持 | 两者无条件混同 |
| 变压器连接两电压等级 | 草稿完整保留；有模型和参数才可计算 | 以普通线路替代变压器 |
| 无 GFM 的发电机—母线小系统 | 接线检查独立成立，GFM 分析明确不适用 | 增加假 GFM 让计算通过 |
| 当前支持的单 GFM 并网算例 | 编译后与原母线—支路输入结果一致 | 工程图形转换改变原模型方程 |
| 保存、导入、重算、报告 | 设备、状态、参数和报告输入一致 | 导入后展示另一工况的旧结果 |

测试分为数据校验、连接编译、现有内核回归和浏览器真实操作四类。
潮流或短路若纳入后续工作，应另有标准算例对照与数值容差；不能由连接编译通过代替验证。
结项演示先选择一个小系统；暂不把两张完整火电厂图作为软件能力验收对象。

第四步：依据专项可行性评估，只有在稳态/短路假设与验证方法明确后，决定是否纳入可选计算功能。
每步更新开发日志和功能文档，分别标注“已有、实现中、未实现”；具体实现与测试记录以本轮测试报告为准。
工程输入改进属于软件工程成果；研究贡献仍需独立的问题、对照与证据，不能由本方案推定。

## 8. 当前代码核查入口

- `backend/domain/network_models.py`：设备集合、单位字段、跨电压线路限制及全网连通要求。
- `apps/web/src/NetworkGraphEditor.tsx`：绘图设备集合、线路投退及 `ready` 条件。
- `backend/core/reduced_order_model.py`：`MODEL_ASSUMPTIONS` 与 GFM、无限大母线要求。
- `backend/core/average_dq_model.py`：`_validate_case` 对设备数量、线路及负荷的限制。

拟采用的通用潮流/短路分析库尚未接入；第三方代码的来源、版本、许可证和可复现测试必须在引入时登记。
