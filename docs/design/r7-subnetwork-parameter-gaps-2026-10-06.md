## 3. 简化和人为边界

### 工程连接节点

连续导线上的位置在结构草稿中合并为同一个连接节点，独立开关两端仍分别保留。此操作只是连接关系整理，不是依据开关状态形成最终计算母线；未知开关状态尚未用于合并节点。

### L1 截断边界

L1 图上只给出系统联络线和本侧开关，没有远端网络。草稿在其外端新增 `n-L1-external` 与 `external-L1`，明确标为人为截断边界，而非图纸原有母线或设备编号。

目前不指定边界电压、不指定短路容量、不把远端自动设为无限大母线。后续可以依据真实系统资料建立等值；也可以使用明确注明来源和用途的教学假设，但不得把教学假设反写为图纸事实。

## 4. 计算前必需的公共数据

1. 确定实际工况：每个独立开关的开合状态、各元件投运状态，以及维护/故障退出状态。
2. 确定省略支路和 L1 外部系统的处理方式，记录来源、模型和适用范围。
3. 统一容量、电压、阻抗及功率的单位与基准；若采用标幺值，记录基准及换算。
4. 补充 G1、T1、L1 的元件计算模型和参数；额定值不得代替实际运行值。
5. 使用支持同步发电机、变压器、独立开关和所选分析任务的程序。现有 GFM 稳定性内核不支持此草稿。

所有缺失量在 JSON 中以 `null` 或明确的待补项记录，不采用任意默认值。

## 5. 按分析任务列出的参数缺项

### 潮流计算

| 对象 | 需补参数或选择 | 当前证据 |
|---|---|---|
| G1 | 节点角色；实际有功 MW；电压设定 p.u. 或实际无功 Mvar；无功上下限 | 只读到 60 MW 额定有功，不能确定运行点 |
| T1 | 高低压绕组额定电压 kV；短路电压百分数；铜耗/电阻分量；空载损耗和电流；分接头位置与步长；接线组别相移 | 只读到 80 MVA 和 Delta/Y 绕组符号 |
| L1 | 正序 R、X 与充电参数；单位和总量/单位长度定义；投运状态；若检查负载率，还需持续载流限值 | 只有联络线名称和连接 |
| 外部系统 | 电压参考节点角色、幅值及角度；等值边界的来源和定义 | 未绘出远端网络 |
| 省略支路 | 实际 P/Q，或有依据的网络等值；负荷电压依赖模型 | 未提取运行数据 |

发电机在潮流中可以作为静态电源节点处理，这不意味着已经建立了同步发电机动态模型。控制方式、调压目标、无功限值和参考节点不能由发电机符号自动决定。

### 短路计算

需先确定计算标准、最大/最小故障条件、故障类型、故障位置、接地方式及所需电流量，随后补充：

- G1 的额定视在功率和额定电压、次暂态电抗，以及所选短路方法要求的电阻、功率因数等参数。
- 外部系统的短路容量或等值序阻抗；不能把联络线名称当作无限短路容量。
- T1 的短路阻抗与电阻分量、接线组别、中性点接地及必要的零序模型。
- L1 的正序阻抗；计算非对称故障时还需对应的零序路径和参数。
- 对采用故障前运行点的方法，先取得可信的潮流结果和初始化条件。

设备额定开断电流用于结果校核时，也须另行收集。现有草稿没有这些数据，不能生成“符合设备要求”的结论。

### 动态稳定性分析

需要同步机惯性、相应电抗及时间常数、励磁与调速模型、必要的稳定器模型、负荷动态和外部网络动态等值，并先完成一致的运行点初始化。还要明确扰动类型和开关操作序列。G1 的 60 MW 和 T1 的 80 MVA 不足以建立这些动态模型。

原图不含变流器。本草稿既不能用于原论文的 GFM 分散式判据，也不能据此评价含变流器系统的短路电流特性。

## 6. 可先验证什么，尚不能验证什么

**可以先核对**：设备编号、端子连接、母线等级、独立开关的位置，以及已明确标注的正常状态。后续在给定完整开关工况后，可检查连接分量和供电路径。

**尚不能计算**：可信潮流、故障电流、设备开断能力合格性、同步机动态稳定性或全厂安全性。上述结果必须等到参数、边界、元件模型和计算程序齐备，并经过适当的交叉验证。
