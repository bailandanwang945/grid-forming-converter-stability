# 前端用语规范

本规范适用于网页界面、图表标题、按钮、状态提示和导出报告入口。目标是让电力电子与电力系统专业的使用者迅速看懂研究对象、操作和结果，同时保持必要的学术边界。

## 基本原则

1. **先写对象，再写动作。** 标题使用“判据核查”“闭环极点分布”“编辑网络”等明确表达，不写“构建证据闭环”“赋能分析决策”等空泛措辞。
2. **一句只承担一层意思。** 操作说明以一句为宜；模型假设、数据来源和结论限制分别列示，不在卡片中堆叠多个并列概念。
3. **按钮只写动作。** 使用“运行分析”“导出 JSON”“生成分析报告”，不写“进入……工作区”“生成打印式……”等迂回表达。
4. **面向用户，不描述实现过程。** 用户界面写“作者公开数据”或“基准数据”；“测试夹具”“接口契约”等实现术语只出现在开发文档中。
5. **必要的限制集中说明。** 普通界面保留简短的“适用范围”；详细假设、来源和限制置于专门区域，不在每项结果后重复辩解。

## 术语口径

- `grid-forming converter`：构网型变流器。
- `decentralized stability criterion`：分散式稳定判据。
- `sufficient condition`：稳定性充分条件或充分判据。
- `closed-loop eigenvalue reference region`：闭环特征根参考稳定域。
- `indeterminate`：数值待定。
- `uncovered`：判据未覆盖；不得据此写成“系统失稳”。
- `stability certificate`：依语境写“稳定性充分条件”“判据确认结果”或“由充分判据确认的参数区域”，不写“稳定性证书”。
- `fixture`：开发文档可写“测试夹具”；用户界面按内容写“基准数据”或“公开数据”。
- `dq`、`VSM`、`LCL`、`SCR`、`PCC` 等通行缩写首次出现在长篇说明时应给出中文名称；图表与紧凑控件中可保留缩写。

## 版式与文字细节

- 中文与英文缩写、阿拉伯数字之间留一个半角空格，如“16 状态模型”“VSM 阻尼”。
- 量与单位之间留空格，如“50 Hz”“0.3 p.u.”；坐标轴可写“频率 / Hz”。
- 中文正文使用全角标点；范围统一使用连接号“–”，如“0.1–1.0 p.u.”。
- 避免连续使用“当前能力”“证据边界”“模型身份”“闭环参考”“交叉核查”等抽象名词。
- 不用宣传语、拟人语和没有信息增量的形容词。

## 发布前检查

- 用户能否仅凭标题判断研究对象？
- 按钮是否明确说明点击后的动作？
- 稳定、失稳、判据未覆盖和数值待定是否严格区分？
- 是否把开发实现术语误放进了用户界面？
- 删除一句话后若不损失信息，应当删除。
