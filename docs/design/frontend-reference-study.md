# 科研软件前端参照与本项目取舍

日期：2026-08-20

## 结论

本项目采用“工程工作台”而非“科研落地页”作为产品形态。界面同时借鉴 MathWorks 的模型画布—上下文属性关系、NHERI SimCenter 的任务分区、Open MCT 的稳定对象导航，以及 AutoFigure-Edit、DeepScientist 对留白和主次操作的处理。不使用水墨山景、装饰插画或大面积营销式首屏，也不复制任何项目的品牌资产。

## 已实施的信息架构

第一阶段将全局与平均值 dq 工作区改为“对象导航—上下文输入—主结果—独立验证”的层级：

1. 四个工作区使用固定产品导航；宽屏为左侧栏，窄屏自动折叠为顶部导航，不让标题、版本和工作区按钮挤在一行；
2. 平均值 dq 参数按“运行点与成形控制”“线路、滤波器与下垂”“仿真设置”分组，默认只展开当前最常用的一组；
3. “模型分析”是默认视图，只呈现参数、模型链路、运行状态和本次结果；
4. 42点层级对照、19点消融、临界边界、端口辨识及外部参照统一进入“研究验证”视图，不再占用常规分析首屏；
5. 网络拓扑、极点、响应、导纳与研究表格继续使用原有可追溯数据，视觉重构不改变计算路径。

第二阶段进一步收紧任务—结果关系：

1. 六项研究任务分别显示“未运行、计算中、已完成”，点击任务只切换相应结果，不重复计算，也不把六组长结果同时铺开；
2. 已完成数量与当前结果焦点固定显示，便于演示时说明“做了哪些验证、正在看哪一项证据”；
3. 低频模型改为“编辑模型—查看结果”双视图，计算完成自动进入结果；任何模型参数、仿真时长、步长或初始扰动变化都会立即使旧结果失效；
4. 母线、线路和 VSM 参数默认折叠，只保留系统与参考设置展开，避免网络编辑器与结果图在同一屏争夺空间。
5. 同域对照、低频模型和平均值 dq 按工作区延迟载入；默认论文页保持立即可用，首个 JavaScript 包由约 `831 kB` 降至 `710 kB`（gzip 约 `273→239 kB`），工作区切换时提供明确加载状态。

在1078 px浏览器视口下，产品导航折叠为顶部栏，参数栏和结果区仍保持双列；参数控件不越出左栏，页面无横向溢出。更窄屏幕继续退化为单列。

## 人机交互准则

- **渐进披露**：首屏只显示完成当前任务所需的参数和主操作；高级参数、固定实验与证据详情按需展开。
- **对象恒常**：导航名称、模型身份和结果来源保持稳定；图表切换不得暗中改变所分析模型。
- **运行前后可辨**：未运行、计算中、结果可追溯和计算失败采用不同状态，不以空白图表冒充结果。
- **参数—结果一致**：参数变化立即使旧结果失效；报告与导出只能使用已完成请求的输入快照。
- **结论就近解释**：稳定性分类、数值待定和模型适用范围与对应结果同屏出现，不埋在独立“免责声明”页面。
- **密度服从任务**：数值表格允许高密度，主流程页面不同时平铺所有研究任务。

## 借鉴边界

- AutoFigure-Edit 的视觉令牌来源于其公开 MIT 许可源码；本项目没有复制其图片、Logo、文案或业务组件。
- DeepScientist 仅作为布局参照，不采用其水彩素材。
- MathWorks、Open MCT 与 NHERI SimCenter 只提供交互方法参照；没有复制其源码或受保护视觉资产。
- 外观一致性不构成科研证据；模型、单位、端口方向、数值验证和结论边界仍以本项目后端、测试与结果文件为准。
