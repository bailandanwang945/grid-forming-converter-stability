## 1. 项目目标

本项目不以完成申报书中的全部扩展性设想为目标，而以形成研究问题明确、理论依据可靠、计算过程可复现、结论能够相互印证的研究成果为目标：

1. 固定并复现 Cifelli–Anta 论文的单机无穷大母线基线；
2. 解释并复现复矩阵数值域在扇形边界附近的数值判定问题；
3. 研究有限精度和离散采样对扇形性判别的影响，并实现带有误差界的数值判别方法；
4. 用解析矩阵、论文算例和至少一个独立模型验证判定结果；
5. 通过闭环特征根和时域响应检验频域充分条件与系统实际稳定性之间的一致性；
6. 形成中期答辩、结项答辩和结项材料所需的全过程证据。
7. 在预先声明的阻尼—电网强度参数域内，比较闭环特征根参考稳定域与小增益—小相位充分判据所能确认的参数区域，定量分析判据的适用范围、保守性来源和数值待定区域。

### 1.1 最小可结项成果

- 一套可运行的 MATLAB 源码与类式单元测试；
- 三组实验：论文基线、边界判定、独立模型；
- 数值域、相位/增益判据、闭环极点三类交叉证据；
- 不依赖 MATLAB 运行环境的便携式计算内核与本地网页工作台；

- 明确说明复用代码、团队新增代码、已知局限和未完成工作。

## 4. 技术原理与安全边界

### 4.1 数值域与分类

对复矩阵 `A`，数值域定义为：

`W(A) = {x^* A x : x ∈ C^n, ||x|| = 1}`。

论文 v2 采用的定义是：

- 严格扇形：`W(A)` 位于角宽小于 `π` 的扇形内，且 `0 ∉ W(A)`；
- quasi-sectorial / semi-sectorial：涉及 `0 ∈ ∂W(A)` 及相位宽度条件；
- 数值域包含原点内部时，小相位边界不能直接使用。

第一阶段输出以下保守工程分类：

- `strict-sectorial`：存在旋转角 `θ`，使 `Re(e^{-jθ}A)` 的最小特征值严格大于尺度容差；
- `boundary`：上下界证书均落入尺度容差带；
- `non-sectorial`：所有旋转方向的最大分离裕度均为负，原点无法与数值域严格分离；
- `indeterminate`：有限角网格和局部细化尚不足以认证以上类别；
- `degenerate`：零矩阵或尺度低于用户给定的绝对阈值。

`boundary` 不自动等同于 `semi-sectorial` 或 `quasi-sectorial`；只有在理论定义和相位宽度证据完整后才细分。

### 4.2 数值判定依据与误差界

定义 Hermitian 矩阵：

`H_θ(A) = (e^{-jθ}A + e^{jθ}A^*)/2`。

若存在 `θ` 使 `λ_min(H_θ(A)) > 0`，则存在一条过原点的直线，将原点与 `W(A)` 严格分离，由此可判定矩阵为严格扇形矩阵。实现中需要计算下式的最大值：

`m(A) = max_θ λ_min(H_θ(A))`。

判定使用 `tol = max(absTol, relTol * ||A||₂)`，不得只使用与矩阵尺度无关的固定容差。有限角网格只给出最大裕度下界，必须同时给出基于 Lipschitz 性的上界；不能证明时输出 `indeterminate`，不得强行分类。

### 4.3 稳定性结论约束

- 扇形性只是小相位判据的前提之一，不等于闭环稳定；
- 小增益或小相位结论是充分条件时，不满足条件不能直接推出系统不稳定；
- 任一主要稳定性结论至少应由闭环特征根或时域仿真结果加以检验；
- 频率离散采样得到的边界应报告采样范围、密度和容差。

## 6. 测试策略

### 6.1 测试层次

1. 单元测试：MATLAB/Python 解析矩阵、错误输入、尺度、旋转不变性和领域契约；
2. 回归测试：固定论文频点、作者结果快照及稳定/临界/失稳解析预设；
3. 集成测试：从拓扑输入、模型构造和判据计算到 API 与报告输出的完整链路；
4. 交叉验证：数值域、有限网格判据、闭环极点和线性响应；同一状态矩阵的极点—响应一致性只算内部核查；
5. 演示测试：前端生产构建、启动器冒烟、案例往返、报告、D–X 扫描和浏览器端到端流程；
6. 发布验收：本机整包功能链已经通过；无开发环境异机离线启动、计算、导出及退出清理尚未完成。

### 6.2 测试规范

- 使用 `matlab.unittest.TestCase` 类式测试；
- Python 使用标准库 `unittest`，当前记录为 107 项；
- 浮点比较必须使用容差；
- 测试不依赖执行顺序和工作区残留；
- 测试方法内部不写 `if/switch/for/try-catch`；
- 每个修复先增加失败测试，再修改实现；
- 测试结果保存到 `results/test-reports/`，但临时缓存不提交。
