# 构网型变流器稳定性分析平台：两分钟演示脚本

## 演示目标

在两分钟内证明平台具备“输入可追溯—内核可重算—结果可导出”的完整链路。演示不承担讲清全部理论的任务；理论边界由答辩 PPT 和问答环节说明。

## 演示前准备

1. 解压 Windows 发布包并启动程序，提前确认浏览器已打开。
2. 关闭无关窗口；浏览器缩放保持 100%。
3. 准备一个空目录用于接收 CSV 和 HTML 报告。
4. 若现场程序无法启动，立即切换到 PPT 第 4、6、7 页及随包静态截图，不在台上排查环境。

## 操作与讲述

### 0:00—0:20　说明三个工作区

操作：在顶部依次指出“论文复现”“独立模型”“同域对照”。

讲述：

> 平台包含三条彼此区分的证据链：第一条复现论文固定算例；第二条允许编辑小型网络和 VSM 参数；第三条在同一论文模型、同一参数域内比较充分判据覆盖与闭环特征根参考分类。

### 0:20—0:45　复现论文固定算例

操作：进入“论文复现”，选择阻尼系数 \(D=0.05\)，点击计算；再切换至 \(D=0.50\)。

讲述：

> 在论文固定的 1000 个频点上，\(D=0.05\) 有 75 个频点未被充分判据覆盖，闭环参考为失稳；\(D=0.50\) 未覆盖点为 0，闭环参考为稳定。这里的“未覆盖”不能单独解释成失稳。

### 0:45—1:15　编辑独立模型并重算

操作：进入“独立模型”，加载稳定预设；把 VSM 阻尼由稳定值改为较小值，点击“重新分析”，观察主导极点实部和稳定性分类变化。

讲述：

> 这一工作区使用团队定义的低频 VSM 模型。修改阻尼后，后台重新组装状态矩阵并计算极点，而不是在界面上插值。模型明确忽略内环、电磁暂态、负荷动态和限流，因此只用于解释低频同步模态与参数趋势。

### 1:15—1:50　展示同域对照

操作：进入“同域对照”，点击热图中绿色、黄色和红色各一个参数点，展示详情；点击导出 CSV 或生成报告。

讲述：

> 该图扫描 11 个线路阻抗缩放系数和 16 个阻尼值，共 176 个参数点。其中 45 点被充分判据确认且闭环参考稳定，96 点闭环参考稳定但判据未覆盖，35 点闭环参考失稳。96 个黄色点量化了该扫描域内观察到的保守性，但不表示判据错误。

### 1:50—2:00　收束

讲述：

> 因而，本项目的主要增量不是重新提出稳定性定理，而是把论文复现、同域对照和便携软件封装为一条可复算、可解释、可交付的证据链。

## 现场止损规则

- 程序启动超过 15 秒仍无页面：使用静态截图继续讲述。
- 计算按钮出现错误：不刷新、不改代码，直接说明“本次现场运行未完成”，切换至冻结报告。
- 评委追问 0.578 Hz 与 1.2 Hz：回答“稳定性判断已经交叉核对，频率差异尚未闭合，未作为项目结论使用”。
- 评委追问“是否支持任意 GFM”：回答“当前为接口可扩展的小型网络 VSM 分析工作台，不宣称任意控制器和任意电网元件均已实现”。
