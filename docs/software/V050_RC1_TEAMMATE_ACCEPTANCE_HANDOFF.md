# v0.5.0-rc1 队友异机验收任务书

## 1. 验收对象

- 文件：`GFM-Stability-Platform-0.5.0-rc1-windows-x64.zip`
- 字节数：`71,728,417`
- SHA-256：`40c3248ac8acfb208d1119ba9bc9b7ce2043a3691a30962a8b9799e22c329e1a`
- 源代码提交：`6ca0b757bda1972284a7282118a12e18bfe1d6a4`
- 包内清单：1024个受约束文件，`workingTreeDirty=false`

收到文件后先核对字节数和SHA-256；任一项不一致都停止验收并重新传输，不要运行来源不一致的包。

## 2. 合格电脑条件

- 64位Windows 10或Windows 11；
- 未安装Python、Node.js和MATLAB，且命令搜索路径中检测不到三者；
- 没有本项目源码、旧解压目录或开发缓存；
- 执行自动与人工检查期间保持断网。

如果电脑已经安装开发环境，不要卸载。它仍可检查功能，但不能形成M5异机资格证据。验收人员可以解压、运行、截图、录屏和导出结果；不得修改ZIP、解压目录、清单或固定数据，不得为了运行而安装依赖，也不得全局关闭安全软件。

## 3. 自动验收

1. 将原始ZIP放到较短的普通可写路径，例如 `D:\GFM-Acceptance\`，不要重命名或删除；
2. 断开网络后，将ZIP解压到同一目录旁边；
3. 双击解压目录中的 `VERIFY_THIS_PC.cmd`；
4. 按真实情况确认断网且未安装三类开发环境；
5. 等待脚本完成，不要提前关闭窗口。

自动验收应同时出现：

```text
GFM_CROSS_MACHINE_FUNCTIONAL_OK
GFM_M5_QUALIFIED
```

若只出现 `GFM_M5_QUALIFICATION_INCOMPLETE`，只能报告“功能通过但M5资格不足”。脚本会核对逐文件哈希、Fig. 8、采样敏感性、176点同域对照、低频模型、16状态平均值dq模型、42点层级扫描、三频点端口辨识、MathWorks与Sienna冻结证据、报告、原始ZIP哈希和端口释放。

## 4. 人工浏览器检查

在仍然断网时双击 `GFM-Stability-Platform.exe`，检查四个工作区能正常切换、中文无乱码、布局无重叠，并至少完成：

1. Fig. 8失稳工况重算并导出JSON与HTML；
2. 同域对照打开一个参数点并导出CSV；
3. 低频模型修改一个参数，完成案例导出—导入—重算；
4. 平均值dq模型运行主分析、42点扫描和一个研究验证任务；
5. 正常退出，确认网页失去连接且没有残留服务窗口。

每个工作区至少保留一张截图；同时保留导出的JSON、CSV和HTML。不要制作或修改PPT/PDF。

## 5. 失败纪律与回传

失败时不得修改包内文件或安装依赖。保存完整错误、Windows版本、解压路径、安全软件信息、断网声明、运行时检测结果和 `acceptance-results`。只允许复核一次完整解压、原始ZIP位置和旧进程占用；同一错误再次出现后停止并回传。

回传以下材料：

- 完整 `acceptance-results` 文件夹；
- ZIP哈希、字节数和自动验收结束截图；
- Windows版本与断网状态说明；
- 四个工作区截图；
- 实际导出的JSON、CSV和HTML；
- 正常退出或失败现场截图。

只有自动功能、M5机器资格、人工浏览器与导出、候选包未修改四项证据全部闭合，项目负责人才能关闭异机验收门。
