# 网络接线编辑操作说明

更新：2026-10-07。本文适用于当前开发源码，不代表旧便携运行包已包含这些改动。

## 1. 编辑什么

进入“网络建模”工作区，在网络图上选择母线、普通导线、阻抗线路、构网型变流器或等值电源，修改右侧参数。
构网型变流器（Grid-Forming Converter，GFM）目前按虚拟同步机（Virtual Synchronous Machine，VSM）低频模型分析；等值电源表示无限大电网的等值电压源。

母线采用粗横线，变流器采用简化的直流—交流转换符号，等值电源采用带正弦标记的圆形符号。这些是本项目绘制的单线图简化符号，不声明整张图符合某一 GB/IEC 制图标准。
图形不是新增计算模型：当前图形入口没有变压器、同步发电机、独立断路器或隔离开关。

## 2. 推荐操作顺序

1. 载入预设或导入案例，先查看接线检查与低频模型适用性。
2. 用“选择”模式点击元件或线路；图元被遮住时，使用参数栏上方的“选择元件”列表。
   新增元件可从“元件库”拖入；也可先点击库中的元件，再点击画布放置。原工具栏的“＋”也采用点击放置，不再默认选择第一条空闲母线。
3. 修改计算参数。线路电阻 R、电抗 X 使用标幺值（per unit，p.u.）；母线标称电压使用伏特（V）。不要把不同单位的工程参数直接填入标幺字段。
4. “接线”默认使用普通导线，只表示直接电气连接。需要实际线路阻抗时，明确选择“阻抗线路 R–X”，再依次点击两端母线或拖动端子。按 Esc 或点击“取消接线”放弃未完成操作。
5. 在“选择”或“接线”模式拖动符号、名称调整位置。“网格吸附”默认开启；需要细调时可关闭。平移模式不移动元件，按 V 可返回选择模式。
6. 保存案例，再点击“验证拓扑并分析”。修改参数或接线后，需要重新计算才能得到对应工况的结果。

新增线路的 R=0.01 p.u.、X=0.2 p.u. 仅为编辑用示例初值，必须按实际研究算例核对。普通线路不能直接连接不同电压等级；跨电压连接需要变压器模型，当前入口不支持。

### 元件库的接入规则

- 母线：拖到空白处，按落点创建；不会自动添加线路。
- 构网型变流器或等值电源：拖到已有空闲母线上，直接接入该母线，图形摆在母线附近；不会改选其他空闲母线。
- 电源拖到空白处：在落点放置设备，同时新建接入母线；这两项作为同一步编辑，可一起撤销。新接入母线不会自动接到其他母线，须自行接线。
- 母线已经接入另一个 VSM 或理想等值电源时，会拒绝放置，并保持原案例与撤销历史。这是当前低频模型的端口限制，不是拖放故障。
- 接线：元件库提供普通导线工具。阻抗线路不作为悬空摆放的元件，须通过接线类型选择或“＋阻抗线路”指定两端。两种连接不会相互替代。

修改已有设备的接入关系，仍可选择设备后在参数栏修改“接入母线”。元件位置和电气接入关系是不同操作，不因图形移动自动重接。

## 3. 画布与参数操作

| 操作 | 用途 | 是否改变计算输入 |
|---|---|---|
| 选择并拖动元件 | 调整版面位置 | 否，只保存图形坐标 |
| 拖动母线右端 ↔ 手柄、修改“图形长度 / px” | 延长或缩短母线图形 | 否，长度不是实际导体米数，不改变线路阻抗 |
| 普通导线连接、重接、删除 | 改变等电位连接关系 | 是，分析前重新合并计算节点 |
| 接线、重接、删除线路 | 修改端点或支路集合 | 是 |
| 修改参数、设备接入母线 | 修改研究工况 | 是 |
| 线路投运/停运 | 保留支路数据并改变运行拓扑 | 是，不等同独立开关分合 |
| 平移、缩放、适配画布 | 改变观察范围 | 否 |
| 网格吸附、缩略图开关 | 辅助定位与观察 | 否 |
| 扩大画布 | 隐藏分析侧栏，增加编辑空间 | 否 |

“扩大画布”后，工具栏仍提供保存案例、导入案例和验证拓扑并分析。点击“恢复布局”可回到原工作区。
撤销：Ctrl+Z；重做：Ctrl+Y 或 Ctrl+Shift+Z。文本框内保留浏览器的文字撤销。线路删除可通过撤销恢复。
选中元件后，可点击画布工具栏“删除”或按 Delete/Backspace；母线的关联删除会先确认。至少保留两条母线和一个无限大母线的现有编辑限制不变。删除和关联图形坐标清理可整体撤销。
元件名称在确认或离开输入框时保存；空名称会被拒绝。

并联线路各自保留编号和电气参数，画面上分开显示。线路端子的绘图方向随母线位置调整，不改变首、末端母线编号。线条相交不会自动形成电气连接。
这不是完整自动布线系统：任意图元重叠或线路穿越仍需手动调整版面；参数栏列表可选中被遮住的线路。

### 快捷键

默认键：V 选择、C 接线、H 平移、B 放置母线、G 放置构网型变流器、E 放置等值电源、F 适配画布。按住空格可临时平移，松开后回到原模式；Esc 取消放置或接线。
“快捷键”按钮可修改上述七项字母键，冲突会被拒绝。设置仅保存在本机浏览器，不进入案例文件或团队仓库；存储失败时，当前页面仍可使用设置，但刷新后不会保留此次更改。表单保留文字编辑，按钮保留标准的空格/回车激活。
快捷键只在模型编辑区域生效；网页刷新或切换案例后，待放置工具会取消，不影响已保存案例。

### 打开当前版本

本机当前源码前端为 `http://127.0.0.1:5173/`，8000 端口是 API 服务，不是网页入口。该地址于 2026-10-07 实际核对；其他机器的端口以启动器显示为准。
看到“元件库”和“快捷键”按钮才是本次更新的界面；旧便携包未重打包。若标签页仍显示旧界面，请刷新源码版页面，不要仅重开旧 ZIP 中的程序。

## 4. 检查和分析边界

- 接线关系有效，不等于网络带电，也不等于系统稳定。
- 保存草稿不要求当前工况能够计算；不能分析时，界面会列出适用性问题。
- 无效或未完成的重接保留原线路，不删除原线，也不写入新的撤销记录。
- 图形和参数表的线路端点修改共用校验，拒绝自环、缺失母线和跨电压线路。
- 当前低频模型不支持多个 GFM 共用一条母线，或 GFM 与理想等值电源共用一条母线；参数下拉与适用性预检对应这一限制。
- R7 工程图局部草稿及独立开关连接试验是单独的数据与试验，目前不能直接导入此画布。
- 本次改进没有新增潮流、短路或故障穿越计算，也不改变论文夹具、作者代码与稳定性判据。

案例格式与方案对照见 [案例保存与方案对照](CASE_WORKFLOW.md)。验证见 [本轮测试记录](../../results/test-reports/2026-10-07-network-editor-usability.md)。

## 5. 交互依据与复用说明

沿用仓库已有的 React Flow，不增加新依赖；SVG 电气符号由本项目绘制，没有使用付费示例的图形代码。
参照 [React Flow 端子文档](https://reactflow.dev/learn/customization/handles)、[组件接口](https://reactflow.dev/api-reference/react-flow)及 [MathWorks 的 Simulink 鼠标与键盘操作说明](https://www.mathworks.com/help/simulink/ug/summary-of-mouse-and-keyboard-actions.html)。参考的是操作组织方式，不声称实现 Simulink 全部能力。
元件库采用 [React Flow 官方 Pointer Events 拖放方案](https://reactflow.dev/examples/interaction/drag-and-drop)的指针捕获与屏幕坐标转换思路，不引入新的拖拽库。坐标转换关闭内部吸附，只对最终图元位置吸附一次；点击放置保留为键盘及触屏的替代入口。

## 6. 母线、线路与接入线

- 物理母线与输电导线都属于导体，但在本软件的集中参数网络模型中作用不同。母线表示设备汇接的电气节点，其连接端口采用同一节点电压；它也可以代表设备端口或公共耦合点，不一定对应现场独立安装的一段母排。
- 交流线路是连接两条母线的支路，具有电阻 R、电抗 X 等参数。增加母线不等于增加线路；仅有母线或电源而未接线的草稿可能形成多个不相连的部分，不能因此认定为可分析的完整网络。
- GFM 或等值电源与其接入母线之间的短线只表示理想接入关系，不另设线路阻抗。若实际存在外接线路，须增加对应的交流线路；不能把画面中的任意细线都当作线路模型。
- 电源放在空白处时新增的母线是接入节点，不是软件自动推定工程上新增了母线设备。以上说明不等于物理母线在所有工况下均可忽略阻抗。

## 7. 画布显示与恢复

2026-10-07 修正受控图元更新时丢失已测尺寸的问题：处理 React Flow 的 dimensions 事件并保留 measured，避免拖动重建节点后使全部图元和端子临时隐藏。尺寸仅是界面内部状态，不写入电气模型或案例文件。位置更新只合并实际变化的有效坐标，未改变的节点不被全量旧快照覆盖。

工具栏的“恢复显示”重新建立画布并适配视图，不修改拓扑、元件参数、图元位置、分析设置或编辑历史。若画布显示异常，优先使用这一操作，不必立即刷新整个网页。双击缩放已关闭；缩放仍使用工具栏或滚轮，以避免连续短拖被误认作双击时改变视图。

受控延迟尺寸通知测试在修复前复现了“节点全部隐藏、连线消失、视图位置与模型仍保留”，修复后同一条件下保持显示。它证明这条具体失效路径已修正，不代表所有浏览器或环境中的空白现象均已解释。见 [测试记录](../../results/test-reports/2026-10-07-network-source-move.md)；节点更新接口参考 [React Flow NodeChange](https://reactflow.dev/api-reference/types/node-change)。

## 8. 普通接线、母线长度与计算节点

“接线”默认普通导线，不增加 R/X 支路；显式选择“阻抗线路 R–X”才创建线路模型。普通导线可选中、改名、修改端点、拖动端点重接或删除。普通导线类型下，也可依次点击电源与目标母线，修改已有电源的接入关系；不会因此额外添加一条线路，参考电源迁移时同步更新参考母线。

选择母线后，可输入“图形长度 / px”或拖动母线右端 ↔ 手柄，范围128–1200画布像素。符号与端子随长度延伸；这只是版面尺寸，不是现场母线的实际长度，不修改电气参数。一次连续拖动对应一次撤销。当前仍为水平母线和固定方向端子，没有任意折弯母线、任意位置新增接点或完整 CAD 布线。

原图的母线段全部保留；计算前将普通导线连接的同电压母线合并为同一电气节点，显示原编号到计算编号的对应关系。主分析、参数扫描、N−1线路停运和dq网络编译共用这一转换。禁止用 X=0 或极小 X 的线路冒充理想导线。若导线使现有线路两端短接、多个 VSM 共用端口或理想电源约束冲突，原图仍可保存，但明确阻止当前分析，不静默删线或删设备。“接线关系有效”与“所选模型适用”仍是不同结论。

保存含普通导线或母线长度的案例使用 `gfm-reduced-order-case/1.2`，另存 `ideal_connections`；长度版面使用 `gfm-network-diagram-layout/1.1` 的 `bus_widths`，键为原母线ID。旧网络及案例1.0/1.1仍可读取；未使用新数据时仍导出案例1.1。导线、版面和电气参数一起参与编辑历史；无效导入原子拒绝。分析报告保留原始导线和母线—计算节点映射，后端分析仍针对转换后的模型。

采用等电位合并而非极小阻抗的方法，与[pandapower官方理想母线连接说明](https://pandapower.readthedocs.io/en/v3.3.3/elements/switch.html)一致；本次没有安装或接入pandapower，没有增加开关、变压器、潮流或短路分析。该功能是输入表达和模型转换，不作为稳定性理论创新。验证见[本轮记录](../../results/test-reports/2026-10-07-network-connection-semantics.md)。
