# 团队 16 状态模型与 Sienna Test 08 的逐层映射

## 1. 核查目的与结论边界

本文件回答一个具体问题：团队自建平均值 dq 模型与 Sienna
`PowerSimulationsDynamics.jl v0.16.2` 的 Test 08 在哪些方程层次上可比，哪些差异使二者不能直接比较特征值或时域曲线。

当前结论包含两层：其一是源代码级结构核查；其二是依据固定 Julia 方程、初值与期望特征值编写的独立 Python 转写复核。团队机器仍未执行 Julia 求解器，也未重跑 PSCAD；因此该复核确认的是“方程转写能够重现上游固定初值与小信号谱”，不是团队16状态模型已经通过 Sienna/PSCAD 外部确认。

## 2. 固定来源

- 团队模型：`backend/core/average_dq_model.py`，16 个状态，单台 VSM、LCL 滤波器、外部串联 RL 线路和无穷大母线。
- Sienna 参照：`PowerSimulationsDynamics.jl v0.16.2`，Test 08 明确声明为 19 状态 VSM—无穷大母线算例。
- Sienna Test 08 扰动：在 `t=1 s` 将 `P_ref` 从 `0.5 p.u.` 改为 `0.7 p.u.`，仿真至 `4 s`。
- Test 08 的原始验收：初始化误差小于 `1e-3`；小信号稳定；19 个特征值与固定结果的向量范数差小于 `1e-3`；ResidualModel/IDA 与 MassMatrixModel/Rodas5 均完成；两条频率轨迹分别与同一 PSCAD CSV 比较，向量范数不超过 `1e-4`。
- PowerDynamics.jl v5.0.0 只作为第二套透明方程参照；本文件不把它的新构网组件称为已经过 Test 08 或 PSCAD 确认。

### 2.1 独立 Python 转写复核

`backend/core/sienna_test08_reference.py` 按固定来源重建19状态向量场，并使用中心差分生成雅可比矩阵。当前自动核查得到：

- 固定初值的向量场无穷范数残差为 `5.397×10^-11`；
- 两母线网络消元后，端电压与上游固定值的差为机器精度下的 `0`；
- 19个特征值经全局一一匹配后，最大绝对误差为 `1.546×10^-4 s^-1`，二范数误差为 `2.566×10^-4 s^-1`，低于上游 `10^-3` 回归门；
- 重算谱最右实部为 `-4.5137 s^-1`，与固定算例的小信号稳定分类一致。

固定特征值实际对应 `60 Hz` 系统基频；若直接代入旧 RAW 文件头部的 `50 Hz`，最大特征值匹配误差增至约 `1.213×10^3 s^-1`。软件将这一差异作为显式反例保留，不以参数拟合掩盖。该结果仍不等同于运行 Julia 的 ResidualModel/IDA、MassMatrixModel/Rodas5 或 PSCAD 时域轨迹。

### 2.2 共有六状态 LCL—PCC 方程门

同构化中间算例的第一层已经闭合。`backend/core/sienna_team_lcl_isomorphism.py`
将两套模型共有的变流器侧电流、电容电压和网侧电流六个状态分离出来，
并把变流器电压与 PCC 电压作为四个外部输入。Sienna 全局实虚坐标方程经
固定相角旋转到团队局部 `dq` 坐标后，得到：

- 状态矩阵最大绝对差：`9.095×10^-13 s^-1`；
- 输入矩阵最大绝对差：`9.095×10^-13 s^-1`；
- 独立探针向量场最大绝对差：`6.821×10^-13 s^-1`。

验收门同时保留一个参数错配反例：仅把团队侧网侧滤波电抗提高 `1%`，
状态矩阵最大差增至 `18.6629 s^-1`。因此该门能够拒绝错误参数映射，
不是由相同输入机械地产生“通过”。Sienna 网络电抗 `0.075 p.u.` 从
`100 MVA` 系统基值换算到 `2.75 MVA` 设备基值后为 `0.0020625 p.u.`，
但未纳入本层方程门：Sienna 将外部网络作为代数网络，团队模型则把外部
RL 线路并入电流微分方程，二者在 PCC 之外仍不等价。

可重复入口为
`python experiments/average-dq/run_sienna_team_common_lcl_audit.py`，固定产物为
`results/sienna-team-isomorphism/common_lcl_isomorphism.json`，当前 SHA-256 为
`0316B046FDEDF9D08206A2CED4D736A3348B50B9C46582D62A187B2CC1304F17`。
这一结果只确认共有 LCL 物理层及坐标变换，不确认两套整机状态维数、外环、
PLL、有源阻尼、调制动态、网络动态或整机特征值等价。

### 2.3 双 PI 状态换元与补偿通道缺口

第二层先拆开“PI 状态定义”和“完整内环补偿”两个问题。Sienna 的 PI 块采用
`ξ̇=e, y=Kp·e+Ki·ξ`，团队模型把积分增益吸收到状态中，采用
`η̇=Ki·e, y=Kp·e+η`。以
`η=diag(Kiv,Kiv,Kic,Kic)·ξ` 作坐标变换后，四个积分状态的输入矩阵差为零，
输出矩阵残差为 `1.110×10^-16`，比例通道差为零；因此双 PI 状态定义本身可
严格对应。

完整内环尚不能据此称为同构。Test 08 使用 `kffi=0、kffv=0、kad=0.2`，
团队控制器相应采用单位电流前馈、单位电压前馈且无有源阻尼，两套补偿矩阵
最大系数差为 `1.2`。把 Sienna 暴露的三个开关对齐为 `1、1、0` 后，电流
参考补偿闭合，但变流器电压参考仍留下 `0.003` 的系数残差，恰为团队模型
保留的 `Rf·if` 电阻压降前馈。Test 08 的 `VoltageModeControl` 没有对应增益；
只有在非原始 Test 08 的结构反事实中补入该项，矩阵差才归零。

可重复入口为
`python experiments/average-dq/run_sienna_team_inner_control_mapping.py`，固定产物
为 `results/sienna-team-isomorphism/inner_control_mapping.json`，当前 SHA-256
为 `1FDF1FFF83FA37B3BD27207A659CEE07D0E2AA68F3ED99D0B6896DEBDFDC54BE`。
该结果把“PI 可换元”与“完整内环未同构”同时作为证据保留，结构反事实不是
Sienna Test 08 源模型，也不能用于整机特征值比较。

### 2.4 两条共有内环中间路径

为避免凭偏好选择 `Rf·if` 的处理方式，软件保持两套原始基线不变，建立两个
并列的10状态中间算例：四个 PI 状态加六个 LCL 状态；电压参考与 PCC 电压
作为四个外部输入。一条路径让双方同时关闭电阻压降前馈，另一条路径让双方
同时加入该项。两条路径都固定电流/电压前馈为1、有源阻尼为0。

经过 PI 状态缩放和 LCL 坐标旋转，两条路径的状态矩阵、输入矩阵及探针向量场
最大差均不超过 `9.095×10^-13 s^-1`，通过 `1×10^-10 s^-1` 方程门。把来源侧
电流前馈由1故意改为0.99后，状态矩阵差增至 `59.8473 s^-1`，说明10状态方程门
能够拒绝错误映射。

在参考电压与 PCC 电压固定的这一有界内环模型中，两条路径都由特征根判为
失稳：关闭 `Rf·if` 时谱横坐标为 `+117.1371 s^-1`，加入该项后为
`+119.2154 s^-1`。两组谱的一一匹配最大位移为 `8.5988 s^-1`，谱横坐标增加
`2.0782 s^-1`，稳定性分类没有改变。这只说明该补偿选择会移动当前中间模型
的极点，不能推断任何原始整机必然失稳，更不能据此把失稳唯一归因于有源
阻尼、LCL 或某一 PI 参数。

可重复入口为 `python experiments/average-dq/run_sienna_team_common_inner_loop.py`，
固定产物为 `results/sienna-team-isomorphism/common_inner_loop_variants.json`，
当前 SHA-256 为
`DF648FFF9BF17ECD06D335DCAB412AE09FC17CFF21C8DDC61BF6CB40BE1454E5`。
原始基线、外环、PLL、有源阻尼状态、调制、限幅和外部网络均不属于该产物的
确认范围。

### 2.5 共有有源阻尼对照及否定性结果

在两条10状态路径上，双方同时加入 Test 08 的两状态电容电压低通滤波器
`ϕ̇=ωad(vc-ϕ)` 与反馈 `-kad(vc-ϕ)`，形成两个12状态中间算例。取
`ωad=50 rad/s、kad=0.2`，两条路径经相同状态变换后，状态矩阵最大差为
`2.728×10^-12 s^-1`，输入矩阵与探针差不超过 `9.095×10^-13 s^-1`；均通过
`1×10^-10 s^-1` 方程门。把来源侧截止频率故意降低2%后，状态矩阵差为
`1.0000 s^-1`，反例被拒绝。

有源阻尼没有改变这一固定输入中间模型的特征根分类。关闭 `Rf·if` 路径的谱
横坐标由 `+117.1371` 增至 `+122.0138 s^-1`；加入 `Rf·if` 路径由
`+119.2154` 增至 `+123.8932 s^-1`，两条路径仍为失稳。因此，预先写明的
“只要给双方加入 Test 08 有源阻尼，就足以改变固定输入共有内环分类”假设在
这两个算例中不受支持。这个否定性结果不等于有源阻尼一般无效：当前模型没有
外环、PLL、调制、限幅和外部网络闭环，而且有源阻尼加入后状态维数也发生变化。

可重复入口为
`python experiments/average-dq/run_sienna_team_common_active_damping.py`，固定产物
为 `results/sienna-team-isomorphism/common_active_damping_comparison.json`，
当前 SHA-256 为
`5B0798E8B7FDD7CE5D33FF0E7583B20482EF251D94734BF17668FA6C817CE886`。

### 2.6 约100 Hz命名支路的模态指纹

在上述两条10状态与两条12状态中间路径上，软件以各自最右正虚部特征值为
基准命名支路，同时计算成对左右特征向量、特征值条件数、左右残差与冻结
坐标基下的分组参与度。10状态两条路径的频率为 `103.861 Hz` 和
`104.102 Hz`；12状态两条路径为 `99.949 Hz` 和 `100.151 Hz`。四个变体中，
网侧滤波电流状态参与度约为 `65.4%–65.9%`，电压 PI 状态约为
`14.8%–16.1%`，变流器侧电流状态约为 `14.8%–16.3%`。电流 PI 与有源
阻尼滤波器状态的参与度较小，故不能把这一支路简单命名为“有源阻尼模态”。

单因素端点固定为基准值的 `0.8/1.2` 倍。电压 PI 和电流 PI 的比例、积分
增益分别联合缩放；LCL 层分别改变 `X1、Bc、X2`；12状态模型另改变有源阻尼
增益与截止频率。四个变体中，`X2` 都是命名支路实部的最强局部灵敏度项，
最大绝对实部位移约为 `29.48–32.89 s^-1`。`X2` 是网侧 LCL 滤波电抗，不是
外部电网电抗或 SCR，本实验没有扫描电网强度。

追踪门同时要求左右 MAC、归一化特征值距离、特征值条件数、左右残差和局部
候选间隔通过。把 `X2` 从1倍直接跳到5倍时，算法拒绝直接匹配；插入几何
中点后才恢复该支路。该反例说明程序能够对过大的参数跳变保留“待定”，而
不是仅凭最近特征值强行续接。不过当前采用命名支路的局部匹配，并非全谱全局
连续化；参与度也只在冻结团队坐标基下解释，不对未来任意状态缩放保持不变。

可重复入口为
`python experiments/average-dq/run_common_inner_loop_modal_fingerprint.py`，产物为
`results/sienna-team-isomorphism/common_inner_loop_modal_fingerprint.json` 和
同名 CSV，当前 SHA-256 分别为
`8A5318A1C0775F666D4444A1999866AB8203EA757E5350823F16E8932ABC9574` 与
`4482657D5EE492C3633F86C170EA7CA6264F9A9421E66C2AD32EC57BA69A077D`。
这一结果只在四个固定输入中间模型及所列端点内支持“LCL—电压控制相互作用”
候选解释，不建立唯一因果机制、连续稳定边界、原始整机结论或论文充分判据结论。

### 2.7 共有 VSM/Q–V 外环与功率测量端口差异

在线与固定 `v0.16.2` 源码复核确认，若把团队有功测量和调制延迟取理想极限、
令 `M=Ta、D=kω、Tq=1/ωf`，并在双方同时关闭 PLL 阻尼，则 VSM 相角—频率
方程与 Q–V 下垂的三个外环状态可以对应。两套原始实现仍有一个不能用参数名
掩盖的差异：Test 08 以滤波电容电压和网侧滤波电流计算有功、无功，团队模型
则在 PCC 计算功率。

软件保持两套原始模型不变，分别建立“双方都在滤波电容端测量”和“双方都在
PCC 测量”的13状态加载中间算例。两个算例均含相角、频率、无功测量、四个 PI
状态和六个 LCL 状态，PCC 电压固定在全局坐标。平衡点无穷范数残差分别为
`2.220×10^-13` 与 `2.487×10^-13`；经动态旋转与 `η=Kiξ` 换元后，状态矩阵
最大差分别为 `6.724×10^-7 s^-1` 与 `4.018×10^-7 s^-1`，通过预设
`1×10^-5 s^-1` 数值门。该门容纳有限差分雅可比误差，远小于端口混用反例。

两个端口约定都新增约 `3.4 Hz` 的低频支路，同时保留约 `112 Hz` 的宽频
右半平面支路。滤波电容端与 PCC 端的谱横坐标分别为 `+195.1454` 与
`+200.0131 s^-1`，分类均为失稳。该结果说明外环会引入低频动态，功率测量
端口也会移动极点；但在这个固定中间算例中，宽频支路仍决定分类。它不证明
外环无关，也不证明测量端口是唯一机理。

若团队侧使用滤波电容端功率、来源侧仍使用 PCC 功率，加载平衡点处的状态
矩阵最大差约为 `500 s^-1`，反例门明确拒绝该混用。因此，功率测量位置属于
结构契约，而不是可忽略的“实现误差”。可重复入口为
`python experiments/average-dq/run_sienna_team_common_outer_loop.py`，固定产物为
`results/sienna-team-isomorphism/common_outer_loop_power_ports.json`，当前
SHA-256 为 `FA9FC2907D05AA748B7AC04E866B45B80198C398BD1EA0F65A80A6A97C454821`。
本层尚未比较有功测量延迟、调制延迟、PLL 阻尼、有源阻尼或外部网络动态。

## 3. 状态组成

| 动态层 | 团队 16 状态 | Sienna Test 08 相关实现 | 映射判断 |
|---|---:|---:|---|
| 相角与频率 | `δ, Δω`，2 状态 | `θ_oc, ω_oc`，2 状态 | 结构相近；均有 `ω_base` 进入相角方程 |
| 功率测量 | `P_m, Q_m`，2 状态 | 外环只保留 `q_m`，1 状态 | 不等价；团队额外引入有功测量低通 |
| VSM 有功环 | 直接使用 `P_m`、惯量 `M`、阻尼 `D` | 使用瞬时端口有功、`Ta, kd, kω`，且 `kd` 作用于 `ω_oc-ω_pll` | 不等价；阻尼通道和有功测量不同 |
| 电压/电流 PI | 两组 dq 积分器，4 状态 | 两组 dq 积分器，4 状态 | 主结构相近，前馈、解耦和坐标约定需逐项换算 |
| 有源阻尼 | 无独立状态 | `ϕ_d, ϕ_q`，2 状态 | 团队缺失 |
| LCL 滤波器 | 变流器侧电流、电容电压、网侧电流，6 状态 | 同三组物理量，6 状态 | 可建立参数与符号映射 |
| 调制/平均变流器 | 内部电压一阶环节，2 状态 | AverageConverter 在本算例的电压指令路径未形成同样的两状态一阶环节 | 团队额外动态 |
| 频率估计器 | 无 PLL 状态 | Test 08 的阻尼输入允许来自 `ω_pll`；19 状态总数还包含频率估计动态 | 团队缺失，不能把两套最右模态直接视为同一模态 |

状态数量的差别不是简单的“16 对 19”精度差别，而是动态结构不同：团队增加了有功测量与调制环节，Sienna 增加了有源阻尼和频率估计环节。因此，未经同构化之前，特征值差异不能解释为某一方实现错误。

## 4. 方程层映射

### 4.1 相角与 VSM 有功—频率环

团队模型采用

\[
\dot\delta=\omega_b\Delta\omega,
\qquad
M\dot{\Delta\omega}=P^\star-P_m-D\Delta\omega,
\qquad
T_p\dot P_m=P-P_m.
\]

Sienna `outer_control_models.jl:615-617` 采用

\[
\dot\theta_{oc}=\omega_b(\omega_{oc}-\omega_{sys}),
\]

\[
T_a\dot\omega_{oc}=P^\star-P_e-k_d(\omega_{oc}-\omega_{pll})
-k_\omega(\omega_{oc}-\omega^\star).
\]

可比部分是惯量型频率动态；不可直接等同的部分有三项：Sienna 使用瞬时 `P_e`，具有单独的频率下垂项 `kω`，并通过 `ω_pll` 构成阻尼反馈。团队当前只有 `DΔω` 和独立有功测量低通。

### 4.2 无功—电压外环

团队模型与 Sienna 都先对无功进行一阶低通，再以
`V*=V_ref+k_q(Q_ref-Q_m)` 形成电压幅值参考。两者在这一层结构相近；时间常数换算为
`T_q=1/ω_f`。Test 08 使用 `kq=0.2, ωf=1000 rad/s`，不能直接替换团队默认参数后就称作同一算例，还必须同步其余控制与网络参数。

### 4.3 电压—电流双闭环

两套实现都包含：虚拟阻抗、电压 PI、电容电流前馈/解耦、电流 PI和电感压降解耦。Sienna 还保留两个有源阻尼低通状态，并允许电压、电流前馈开关；团队模型没有这两个状态，且当前前馈结构是固定的。因而只能逐项比较传递路径，不能只比较 PI 增益名称。

### 4.4 LCL 滤波器

团队模型和两套 Julia 方程均可写为

\[
\frac{X_f}{\omega_b}\dot i_f=v_i-v_c-R_f i_f+\text{旋转耦合项},
\]

\[
\frac{B_c}{\omega_b}\dot v_c=i_f-i_g+\text{旋转耦合项},
\]

\[
\frac{X_g}{\omega_b}\dot i_g=v_c-v_t-R_g i_g+\text{旋转耦合项}.
\]

PowerDynamics v5.0.0 的 `ComposableInverter.jl:160-170` 直接以标幺电抗/电纳和 `ωbase` 写出这组六状态方程，可用于核对量纲。Sienna 在质量矩阵中使用 `X/ωb`、`B/ωb`，在残差右端保留交叉耦合。团队模型的同类项已经显式含 `ω_base`。

但坐标系不同：Sienna 滤波器状态位于网络实虚坐标，内环再用 `θ_oc+π/2` 变换到控制 dq 坐标；团队状态直接位于变流器局部 dq 坐标。因此，核对符号时必须先写出旋转矩阵，不能逐字符比较 `J` 项正负号。

### 4.5 外部线路与功率测量位置

团队模型把网侧滤波电感与外部线路串联写入同一电流微分方程，但显式重构 PCC 电压，并在 PCC 计算有功、无功。Sienna Test 08 的网络线路由系统网络方程承担。后续构造同构算例时，必须冻结：线路是否并入 `X_g/R_g`、PCC 定义、端口电流正方向和功率测量位置。

## 5. 参数映射规则

| 团队字段 | Sienna/PowerDynamics 字段 | 处理方式 |
|---|---|---|
| `converter_side_reactance_pu` | `lf` / `Xf` | 同一基值下按额定频率电抗对应 |
| `filter_capacitor_susceptance_pu` | `cf` / `Bc` | 按额定频率电纳对应，不把它当物理电容值 |
| `grid_side_reactance_pu` | `lg` / `Xg` | 只对应滤波器网侧电感；外部线路另列 |
| `virtual_reactance_pu` | `lv` / `X_virt` | 先统一 dq 方向和频率倍率 |
| `reactive_power_measurement_time_constant_s` | `1/ωf` / `τ_q` | 单位换算后对应 |
| `virtual_inertia_s` | `Ta` | 只作为候选对应；需结合功率和频率标幺定义核验 |
| `damping_coefficient_pu` | `kd, kω` 及 PLL 路径 | 不能一对一映射 |
| `active_power_measurement_time_constant_s` | 无直接 Test 08 对应 | 同构化时需关闭或在参照模型中补入 |
| `modulation_time_constant_s` | 无直接 Test 08 对应 | 同构化时需趋近代数环节或在参照模型中补入 |

## 6. 下一项可执行验证

同构化中间算例已完成共有 LCL—PCC、双 PI、两条10状态内环及12状态有源阻尼
路径。有源阻尼没有改变固定输入内环分类，最右模态仍位于约 `100 Hz`。结合
2026-08-21 的[在线调研](next-stage-online-review-2026-08-21.md)，执行顺序调整为：

1. 已完成10/12状态共有模型的内环/LCL模态指纹；外部电网强度未在固定 PCC 输入模型中冒充为 `X2` 扫描；
2. 已完成共有 VSM/Q–V 外环、固定全局 PCC 坐标和两个共同功率测量端口的13状态加载中间模型；
3. 下一步分别加入团队有功测量、调制动态、Sienna PLL阻尼与有源阻尼，并保持功率端口约定不变，避免一次混入多个机制；
4. 最后接入静态外部网络与团队动态 RL 线路的明确对照；
5. 明确选择“无 PLL 阻尼”或“带 PLL 阻尼”，不得把两种结构混合；

通过标准应依次为：平衡点残差、状态矩阵逐块差异、特征值集合差异、时域输出差异。任何一级未通过，都不得用下一级曲线相似掩盖结构差异。

## 7. 当前能够与不能够支持的表述

能够支持：两套 Julia 源码为团队模型提供了透明的方程和独立测试设计参照；Sienna Test 08 具有固定特征值与 PSCAD 频率轨迹验收；团队模型与 Test 08 存在明确、可定位的动态结构差异。

不能支持：团队模型已经通过 Sienna 或 PSCAD 外部确认；16 状态模型与 19 状态模型的某个特征值必然代表同一物理模态；当前强网分歧已归因于 PLL、有源阻尼、调制器或某一个控制环节。
