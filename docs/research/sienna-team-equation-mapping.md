# 团队 16 状态模型与 Sienna Test 08 的逐层映射

## 1. 核查目的与结论边界

本文件回答一个具体问题：团队自建平均值 dq 模型与 Sienna
`PowerSimulationsDynamics.jl v0.16.2` 的 Test 08 在哪些方程层次上可比，哪些差异使二者不能直接比较特征值或时域曲线。

当前结论属于**源代码级结构核查**，不是 Sienna 算例复现。团队机器尚未安装 Julia，本轮没有执行 Sienna 求解器，也没有把 Sienna/PSCAD 结果当作团队模型的外部确认结果。

## 2. 固定来源

- 团队模型：`backend/core/average_dq_model.py`，16 个状态，单台 VSM、LCL 滤波器、外部串联 RL 线路和无穷大母线。
- Sienna 参照：`PowerSimulationsDynamics.jl v0.16.2`，Test 08 明确声明为 19 状态 VSM—无穷大母线算例。
- Sienna Test 08 扰动：在 `t=1 s` 将 `P_ref` 从 `0.5 p.u.` 改为 `0.7 p.u.`，仿真至 `4 s`。
- Test 08 的原始验收：初始化误差小于 `1e-3`；小信号稳定；19 个特征值与固定结果的向量范数差小于 `1e-3`；ResidualModel/IDA 与 MassMatrixModel/Rodas5 均完成；两条频率轨迹分别与同一 PSCAD CSV 比较，向量范数不超过 `1e-4`。
- PowerDynamics.jl v5.0.0 只作为第二套透明方程参照；本文件不把它的新构网组件称为已经过 Test 08 或 PSCAD 确认。

## 3. 状态组成

| 动态层 | 团队 16 状态 | Sienna Test 08 相关实现 | 映射判断 |
|---|---:|---:|---|
| 相角与频率 | `δ, Δω`，2 状态 | `θ_oc, ω_oc`，2 状态 | 结构相近；均有 `ω_base` 进入相角方程 |
| 功率测量 | `P_m, Q_m`，2 状态 | 外环只保留 `q_m`，1 状态 | 不等价；团队额外引入有功测量低通 |
| VSM 有功环 | 直接使用 `P_m`、惯量 `M`、阻尼 `D` | 使用瞬时端口有功、`Ta, kd, kω`，且 `kd` 作用于 `ω_oc-ω_pll` | 不等价；阻尼通道和有功测量不同 |
| 电压/电流 PI | 两组 dq 积分器，4 状态 | 两组 dq 积分器，4 状态 | 主结构相近，前馈、解耦和坐标约定需逐项换算 |
| 有源阻尼 | 无独立状态 | `ϕ_d, ϕ_q`，2 状态 | 团队缺失 |
| LCL 滤波器 | 变流器侧电流、电容电压、网侧电流，6 状态 | 同三组物理量，6 状态 | 可建立参数与符号映射 |
| 调制/平均变流器 | 内部电压一阶环节，2 状态 | AverageConverter 在本算例的电压指令路径未形成同样的两状态一阶环节 | 团队额外动态 |
| 频率估计器 | 无 PLL 状态 | Test 08 的阻尼输入允许来自 `ω_pll`；19 状态总数还包含频率估计动态 | 团队缺失，不能把两套最右模态直接视为同一模态 |

状态数量的差别不是简单的“16 对 19”精度差别，而是动态结构不同：团队增加了有功测量与调制环节，Sienna 增加了有源阻尼和频率估计环节。因此，未经同构化之前，特征值差异不能解释为某一方实现错误。

## 4. 方程层映射

### 4.1 相角与 VSM 有功—频率环

团队模型采用

\[
\dot\delta=\omega_b\Delta\omega,
\qquad
M\dot{\Delta\omega}=P^\star-P_m-D\Delta\omega,
\qquad
T_p\dot P_m=P-P_m.
\]

Sienna `outer_control_models.jl:615-617` 采用

\[
\dot\theta_{oc}=\omega_b(\omega_{oc}-\omega_{sys}),
\]

\[
T_a\dot\omega_{oc}=P^\star-P_e-k_d(\omega_{oc}-\omega_{pll})
-k_\omega(\omega_{oc}-\omega^\star).
\]

可比部分是惯量型频率动态；不可直接等同的部分有三项：Sienna 使用瞬时 `P_e`，具有单独的频率下垂项 `kω`，并通过 `ω_pll` 构成阻尼反馈。团队当前只有 `DΔω` 和独立有功测量低通。

### 4.2 无功—电压外环

团队模型与 Sienna 都先对无功进行一阶低通，再以
`V*=V_ref+k_q(Q_ref-Q_m)` 形成电压幅值参考。两者在这一层结构相近；时间常数换算为
`T_q=1/ω_f`。Test 08 使用 `kq=0.2, ωf=1000 rad/s`，不能直接替换团队默认参数后就称作同一算例，还必须同步其余控制与网络参数。

### 4.3 电压—电流双闭环

两套实现都包含：虚拟阻抗、电压 PI、电容电流前馈/解耦、电流 PI和电感压降解耦。Sienna 还保留两个有源阻尼低通状态，并允许电压、电流前馈开关；团队模型没有这两个状态，且当前前馈结构是固定的。因而只能逐项比较传递路径，不能只比较 PI 增益名称。

### 4.4 LCL 滤波器

团队模型和两套 Julia 方程均可写为

\[
\frac{X_f}{\omega_b}\dot i_f=v_i-v_c-R_f i_f+\text{旋转耦合项},
\]

\[
\frac{B_c}{\omega_b}\dot v_c=i_f-i_g+\text{旋转耦合项},
\]

\[
\frac{X_g}{\omega_b}\dot i_g=v_c-v_t-R_g i_g+\text{旋转耦合项}.
\]

PowerDynamics v5.0.0 的 `ComposableInverter.jl:160-170` 直接以标幺电抗/电纳和 `ωbase` 写出这组六状态方程，可用于核对量纲。Sienna 在质量矩阵中使用 `X/ωb`、`B/ωb`，在残差右端保留交叉耦合。团队模型的同类项已经显式含 `ω_base`。

但坐标系不同：Sienna 滤波器状态位于网络实虚坐标，内环再用 `θ_oc+π/2` 变换到控制 dq 坐标；团队状态直接位于变流器局部 dq 坐标。因此，核对符号时必须先写出旋转矩阵，不能逐字符比较 `J` 项正负号。

### 4.5 外部线路与功率测量位置

团队模型把网侧滤波电感与外部线路串联写入同一电流微分方程，但显式重构 PCC 电压，并在 PCC 计算有功、无功。Sienna Test 08 的网络线路由系统网络方程承担。后续构造同构算例时，必须冻结：线路是否并入 `X_g/R_g`、PCC 定义、端口电流正方向和功率测量位置。

## 5. 参数映射规则

| 团队字段 | Sienna/PowerDynamics 字段 | 处理方式 |
|---|---|---|
| `converter_side_reactance_pu` | `lf` / `Xf` | 同一基值下按额定频率电抗对应 |
| `filter_capacitor_susceptance_pu` | `cf` / `Bc` | 按额定频率电纳对应，不把它当物理电容值 |
| `grid_side_reactance_pu` | `lg` / `Xg` | 只对应滤波器网侧电感；外部线路另列 |
| `virtual_reactance_pu` | `lv` / `X_virt` | 先统一 dq 方向和频率倍率 |
| `reactive_power_measurement_time_constant_s` | `1/ωf` / `τ_q` | 单位换算后对应 |
| `virtual_inertia_s` | `Ta` | 只作为候选对应；需结合功率和频率标幺定义核验 |
| `damping_coefficient_pu` | `kd, kω` 及 PLL 路径 | 不能一对一映射 |
| `active_power_measurement_time_constant_s` | 无直接 Test 08 对应 | 同构化时需关闭或在参照模型中补入 |
| `modulation_time_constant_s` | 无直接 Test 08 对应 | 同构化时需趋近代数环节或在参照模型中补入 |

## 6. 下一项可执行验证

下一步不是立即安装 Julia，而是建立一个**同构化中间算例**：

1. 冻结同一标幺基值、无穷大母线、PCC、线路和功率方向；
2. 在团队模型中分别关闭有功测量延迟和调制延迟，或在 Sienna 侧补入同样动态；
3. 明确选择“无 PLL 阻尼”或“带 PLL 阻尼”，不得把两种结构混合；
4. 对齐 LCL、PI、虚拟阻抗、Q–V 下垂和有源阻尼；
5. 先比较平衡点残差与状态矩阵，再比较特征值；只有状态定义和维数一致后才进行逐根匹配；
6. 最后才复跑 `P_ref=0.5→0.7`，同时保留 Sienna 自带 PSCAD 轨迹作为第三方参照。

通过标准应依次为：平衡点残差、状态矩阵逐块差异、特征值集合差异、时域输出差异。任何一级未通过，都不得用下一级曲线相似掩盖结构差异。

## 7. 当前能够与不能够支持的表述

能够支持：两套 Julia 源码为团队模型提供了透明的方程和独立测试设计参照；Sienna Test 08 具有固定特征值与 PSCAD 频率轨迹验收；团队模型与 Test 08 存在明确、可定位的动态结构差异。

不能支持：团队模型已经通过 Sienna 或 PSCAD 外部确认；16 状态模型与 19 状态模型的某个特征值必然代表同一物理模态；当前强网分歧已归因于 PLL、有源阻尼、调制器或某一个控制环节。
