# 平均值 dq 模型的单因素临界边界追踪

## 研究问题

固定团队自建的单机 16 状态正序平均值 dq 模型、阻尼系数 `D=60` 与外部线路电抗 `X=0.1 p.u.`，考察固定 19 点模态消融中四个能够改变整体稳定性分类的单因素方向：电压环 PI、电流环 PI、变流器侧滤波电抗与电网侧滤波电抗。研究问题是：沿这些冻结路径变化时，此前识别的附加振荡模态是否在完整模型稳定边界处穿越虚轴。

这是一项团队模型内部的数值验证，不是论文 Fig. 8 的复现，也不评价论文的小增益—小相位稳定性充分条件。

## 可检验假设与失败条件

- 假设：被连续追踪的附加模态实部过零点，与完整 16 状态矩阵谱横坐标 `α(A)=max Re(λ)` 的过零点在既定数值容差内一致。
- 备择解释：整体稳定边界由另一模态先行穿越，或模态身份在路径中无法可靠保持。
- 失败条件：端点不能构成异号区间、模态追踪门槛不满足、工作点残差超限、达到最大迭代次数仍不收敛，或两种边界区间不相交且相对差超过容差。
- 失败点保留为 `pending`、`unbracketed` 或 `maximum-iterations`，不得强制归入收敛结果。

## 数值方法

每个试探点均重新求解稳态工作点并重新线性化，不对端点结果作显示层插值。附加模态身份沿参数路径采用左右特征向量 MAC、归一化特征值距离、简单特征值条件数、左右特征对残差及局部候选间隔共同约束；门槛不满足时自适应插入中间点。临界倍率采用几何中点二分，以适应乘法尺度：

`f_mid = sqrt(f_left × f_right)`。

冻结数值契约如下：倍率相对容差 `1e-5`，极点实部容差 `1e-5 s^-1`，最大迭代次数 40。附加模态实部与完整模型谱横坐标分别独立求根，随后才比较两类边界。

## 结果

| 单因素路径 | 稳定化筛查端点倍率 | 附加模态过零倍率 | 完整模型稳定边界倍率 | 两类边界一致 | 边界后观察到最右模态交接 |
|---|---:|---:|---:|:---:|:---:|
| 电压环 PI | 2.0 | 1.629745921 | 1.629745921 | 是 | 是 |
| 电流环 PI | 2.0 | 1.601644524 | 1.601644524 | 是 | 是 |
| 变流器侧滤波电抗 | 0.5 | 0.693169050 | 0.693169050 | 是 | 是 |
| 电网侧滤波电抗 | 2.0 | 1.994560468 | 1.994560468 | 是 | 否 |

四条路径的全部试探点均完成工作点求解与模态匹配，物理残差低于 `1e-9`；四组附加模态边界与完整模型边界均收敛并一致。前三条路径在越过稳定边界后出现最右模态交接：这说明决定临界穿越的附加模态在稳定区内未必继续保持为最右极点，不能用稳定端点的最右极点反向替代原模态身份。

## 结论边界

结果支持以下有限结论：在团队模型、固定锚点和四条已检验单因素路径内，被追踪附加模态的虚轴穿越与完整 16 状态模型稳定边界一致，因此该模态是这些数值边界的直接决定模态。

结果不支持以下扩张：某一控制环节是失稳的唯一原因；边界在未检验参数域内保持单调；四个参数之间不存在交互；平均值模型结论必然适用于 EMT、实物或多机系统；该结果构成论文定理的反例或替代。参与因子与模态连续性证据用于诊断和身份核对，不是因果识别。
