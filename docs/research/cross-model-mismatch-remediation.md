# 跨模型稳定分类分歧的定位与解决路线

## 1. 当前究竟困在哪里

当前唯一明确的跨模型分歧位于 `SCR=5、D_MW=1.056 p.u./Hz`：MathWorks 固定模型的供应商时域函数判为失稳，团队16状态平均值 `dq` 模型的局部闭环特征根判为稳定；在团队模型中进一步执行 `P*=0.6→0.8 p.u.` 的8秒非线性阶跃，两种积分器均给出收敛结果。

因此，问题已经不再是“Python 积分器是否算错”，也不能再用“局部特征根漏掉了团队模型自身的大扰动失稳”解释。真正缺少的是**模型等价性证据**：现有比较只对齐了基频、SCR、`X/R`、有功工作点和阻尼横轴，没有统一以下结构：

- VSM 或下垂外环的精确定义与功率测量滤波；
- dq 电压环、电流环的拓扑、增益、前馈与解耦项；
- LCL 参数、测量位置、PCC 定义和电流正方向；
- 虚拟阻抗、调制延迟、限流、抗积分饱和与状态切换；
- 初始化方法以及“稳定/失稳”分类器的观测量、尾窗和阈值。

MathWorks 整机的直接线性化又会混入 Simscape 代数状态、无关状态和非光滑环节；在工作点、分析端口和状态约简没有闭合前，其特征值不能作为可信对照。这是当前技术瓶颈。

## 2. 调研得到的可用外部基准

### 2.1 首选：Sienna `PowerSimulationsDynamics.jl v0.16.2`

该项目是面向含变流器现代电力系统的开源动态仿真框架。固定版本 `v0.16.2` 提供：

- 虚拟惯量与下垂外环；
- 电压模式双闭环与 LCL 滤波器；
- 可选输出电流限制器；
- 工作点初始化、残差模型与质量矩阵模型；
- Test 08：19 状态 VSM 接无穷大母线，`P_ref=0.5→0.7`，核对固定初值、19个小信号特征值，并以两种 DAE 形式分别与 PSCAD 频率波形比较；
- Test 23：15 状态下垂型构网变流器接无穷大母线，执行相同类型的有功参考阶跃，并与 PSCAD 相角波形比较。

它的价值不是 stars 数本身，而是“透明组件方程 + 固定初值和特征值 + 两种数值实现 + PSCAD 工程和参考波形”同时存在。Test 08 与本项目的 VSM—无穷大母线研究对象更接近，应作为首要第三方动态基准；Test 23 用于辅助区分外环差异与共同的滤波器、内环和端口实现。

### 2.2 方程审计：`PowerDynamics.jl v5.0.0`

该版本的 `ComposableInverter` 直接公开 L/LC/LCL 滤波器、dq 双闭环、虚拟阻抗、下垂外环和旋转变换。其代码与团队16状态方程在结构上相近，适合建立逐式差异表，尤其可以核对：

- `X/ω_base`、`B/ω_base` 是否正确进入微分项；
- dq 交叉耦合项的符号；
- 端口电流的送端约定；
- `P=u_d i_d+u_q i_q` 与 `Q=u_q i_d-u_d i_q`；
- 电压、电流前馈以及虚拟阻抗注入位置。

它不应直接成为产品运行依赖，也不能据框架论文把新加入的每个变流器组件称为实验确认。当前用途是方程级独立审计。

### 2.3 候选资料：UNIFI GFM 规范第三版

本轮只核验了 UNIFI 第三版的题名、DOI、发布日期和发布机构，因下载端点不可达，尚未阅读正文。根据题名只能判断它可能与构网型变流器资源规范有关，不能进一步声称其中规定了哪些功能、试验项目或判据。在取得并核读原文之前，它不进入本项目的模型方程或统一试验契约；当前解决路线只依赖已经读取的 Sienna 与 PowerDynamics 固定版本源码。

### 2.4 为什么不选择 star 更高的通用项目

PyPSA、pandapower 和 MATPOWER 的社区规模更大，但主线是潮流、优化或准稳态网络分析，不提供当前所需的 GFM 双闭环—LCL 快速动态基准。ANDES 是成熟的动态仿真框架，但本轮对其当前代码树的定向检索未发现可直接复用的 GFM 组件。以 stars 替代模型适用性，会把问题重新带回“软件很成熟，但研究对象不一致”。

## 3. 建议的解决方法

不再要求 MathWorks 与团队模型逐状态同构，而采用三层验证：

1. **方程级核对**：把团队模型与 PowerDynamics/Sienna 的滤波器、双闭环、虚拟阻抗、功率和坐标方程列成映射表；每一项标为相同、等价变换、参数不同、结构缺失或不可比较。
2. **端口级核对**：冻结同一基值、PCC、dq 坐标和电流方向，在同一工作点识别 `2×2` 的 `v_dq→i_dq` 小信号频率响应；比较矩阵元素、奇异值和闭环特征，而不是比较第三方内部状态名称。
3. **行为级核对**：依据本项目预先声明的实验契约，采用相同幅值的 `P_ref`、`Q_ref` 和电压扰动，比较峰值、整定时间、稳态误差、限流触发与结果类别。分类器规则必须公开，求解失败与物理失稳分列。若后续核读 UNIFI 原文，只在确认其具体条款适用于本项目模型后再引用。

## 4. 最小实施顺序

### 阶段 A：第三方方程差异表

只读取固定 tag，不先引入 Julia 运行时。针对以下模块形成一张机器可读映射表：滤波器、功率、外环、Q-V、虚拟阻抗、电压环、电流环、调制延迟、限流和初始化。完成标志是每个团队状态与每条微分方程都能说明外部对应项或明确“无对应项”。

### 阶段 B：复现 Sienna Test 08，并以 Test 23 辅助拆分结构

在隔离环境先运行 `PowerSimulationsDynamics.jl v0.16.2` 的 Test 08，核对固定初值、19个特征值和 PSCAD 频率波形；随后运行 Test 23，核对15状态下垂模型的特征值与 PSCAD 相角。然后在团队 Python 模型中逐步构造相同滤波器和控制参数。若外环不能同构，先只比较固定电压源、双闭环和 LCL 子系统，禁止把不同状态数、不同外环的总机结果命名为预测误差。

### 阶段 C：回到 MathWorks 分歧点

依据阶段 A 找出的结构差异，每次只对齐一类环节，优先级为：

1. 功率测量位置与滤波；
2. 电压/电流前馈和 dq 解耦；
3. LCL 与虚拟阻抗；
4. 调制延迟；
5. 限流、抗积分饱和和初始化。

每次只改变一个结构组，重算 `SCR=5` 的阻尼过渡位置以及分歧点响应。若某项对齐后差距缩小，只能写“支持该结构对边界差异有数值贡献”；在没有完整消融前，不写唯一因果。

## 5. 完成标准与停止条件

本阶段完成后，另一名研究者应能依据固定提交、参数映射表和三组原始结果，复核以下结论之一：

- 分歧主要随某个已明确的结构组对齐而缩小；或
- 即使主要结构已对齐，分歧仍存在，应保留为模型确认缺口。

若 Sienna Test 08 无法在固定版本复现、坐标/端口无法闭合，或为了匹配结果必须同时修改多个环节，则停止参数拟合，不把曲线接近当作验证成功。

## 6. 当前建议

研究状态应评为“可继续研究，但外部定量确认尚未完成”。下一项工作不是扩展网页功能，也不是重复运行现有八点表，而是完成阶段 A 的第三方方程差异表；随后安装隔离的 Julia 环境，只运行 Sienna Test 08 和 Test 23，不启动其全仓库测试。
