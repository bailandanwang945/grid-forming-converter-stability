# 16 状态平均值 dq 模型的 19 点模态消融与连续追踪

更新日期：2026-08-10  
实验标识：`average-dq-hierarchy-disagreement-ablation-v1`

## 1. 研究问题

在团队定义的单机构网型变流器 16 状态平均值 dq 模型中，取阻尼
`D=60`、外部线路电抗 `X=0.1 p.u.` 时，闭环最右特征值约为

\[
\lambda_{\mathrm{extra}}=4.5864+\mathrm{j}35.9344\ \mathrm{s}^{-1},
\]

对应振荡频率约为 5.7191 Hz，因其实部为正，16 状态模型判为失稳。
同一工作点匹配的三状态模型所对应同步模态约为

\[
\lambda_{\mathrm{sync}}=-1.140+\mathrm{j}14.898\ \mathrm{s}^{-1},
\]

仍位于左半平面。这说明三状态模型能够近似同步低频模态，却遗漏了一个
会改变稳定性分类的附加模态。本实验所问的不是“哪个环节已经被证明是
唯一原因”，而是：在固定模型和有限参数端点上，这一附加模态如何迁移，
哪些参数变化与整体稳定性改变同时出现。

本实验不是论文 Fig. 8 的复现，不评价论文小增益—小相位充分条件，也不是
PWM、电磁暂态或实物系统验证。

## 2. 固定实验设计

所有工况固定 `D=60`、外部线路 `X=0.1 p.u.`，并逐点重新求解工作点、
功率平衡和 16 状态线性化矩阵。19 个公开端点为：

- 基准点 1 个；
- 电压 PI、电流 PI、平均调制时间常数、变流器侧电抗 `X1`、滤波电容
  等效电纳 `Bc`、网侧电抗 `X2` 各取 `0.5×` 和 `2×`，共 12 个；
- Q–V 下垂系数取 `0×` 和 `2×`，共 2 个；
- 电压 PI 与电流 PI 的 `0.5×/2×` 两因素四角点，共 4 个。

“PI 乘以某一倍数”表示该环的比例增益与积分增益同时按该倍数变化。
中间加密点仅用于模态连续追踪，不计入 19 个公开消融端点，也不以插值值
代替实际重算结果。

## 3. 模态对应方法

对每个线性化矩阵同时计算成对的左右特征向量。相邻参数点的参考模态
\((\lambda_i,l_i,r_i)\) 与候选模态
\((\lambda_j,l_j,r_j)\) 分别计算右、左特征向量 MAC：

\[
\operatorname{MAC}_{R}
=\frac{|r_i^{\mathrm H}r_j|^2}
{(r_i^{\mathrm H}r_i)(r_j^{\mathrm H}r_j)},\qquad
\operatorname{MAC}_{L}
=\frac{|l_i^{\mathrm H}l_j|^2}
{(l_i^{\mathrm H}l_i)(l_j^{\mathrm H}l_j)}.
\]

同时计算归一化特征值距离

\[
d_{\lambda}
=\frac{|\lambda_j-\lambda_i|}
{\max(1,|\lambda_i|)}
\]

以及项目定义的候选评分

\[
c_{ij}=0.7\sqrt{\operatorname{MAC}_{R}\operatorname{MAC}_{L}}
+0.3\exp(-d_{\lambda}).
\]

完整 16 阶谱使用线性指派算法进行一对一匹配，避免附加模态和同步模态
占用同一候选特征值。评分权重和下列门槛均是项目的可审计工程设定，
不是文献给出的理论最优值：

| 核查量 | 默认门槛 |
|---|---:|
| 左、右 MAC | 分别不小于 0.80 |
| 归一化特征值距离 | 不大于 0.30 |
| 简单特征值条件数 | 不大于 \(10^8\) |
| 左、右特征对相对残差 | 分别不大于 \(10^{-10}\) |
| 本参考模态行内最佳—次佳候选相对间隔 | 不小于 0.20 |

任一门槛不满足时，程序沿当前参数路径二分插入中间点，最多递归四层；
仍不足则把模态身份记为 `pending`，不强制归类。两个 PI 同时变化时，
分别沿“先电压环、后电流环”和“先电流环、后电压环”追踪；两条路径的
终点身份不一致时同样记为 `pending`。接口中的“累计追踪步数”是两条路径
步数之和，不是单一路径长度。

整体稳定、临界或失稳分类始终由各端点自身最右极点确定，不依赖上述
命名模态匹配是否成功。

0.990 和 0.967，最大单步归一化特征值距离约为 0.291。同步模态相应最弱
数值约为 0.915、0.851 和 0.100，仍通过默认门槛。

## 5. 门槛敏感性核查

只改变一项追踪门槛、其余设置保持默认时，19 个端点的两个命名模态均未
出现 `pending`。门槛收紧会增加中间加密步数，但未改变公开端点的模态身份：

| 单项变更 | 附加模态待定点 | 同步模态待定点 | 附加模态累计步数 |
|---|---:|---:|---:|
| 左右 MAC 下限 0.70 | 0 | 0 | 59 |
| 左右 MAC 下限 0.80 | 0 | 0 | 59 |
| 左右 MAC 下限 0.90 | 0 | 0 | 61 |
| 距离上限 0.20 | 0 | 0 | 82 |
| 距离上限 0.30 | 0 | 0 | 59 |
| 距离上限 0.40 | 0 | 0 | 42 |

这只能说明当前有限路径结果对上述门槛扰动具有一定稳健性，不能证明门槛
最优，也不能证明全参数域内存在唯一、光滑且不发生分叉的模态分支。

## 6. 可以支持与不能支持的结论

当前证据可以支持：

1. 在固定团队模型的该锚点上，三状态近似保留的同步模态仍稳定，但
   16 状态模型存在一个被三状态模型遗漏的附加失稳模态。
2. 在所测端点中，电压 PI ×2、电流 PI ×2、X1 ×0.5、X2 ×2，以及两个
   PI 同时 ×2 时，16 状态模型整体稳定；其余 14 个端点失稳。
3. 在既定状态坐标、门槛和两种 PI 参数调整顺序下，基准附加模态能够
   连续追踪至这 19 个端点。
4. 18 个端点的附加模态非负分组参与度以 LCL 状态组最大，调制时间常数
   ×2 工况则以调制器状态组最大；这是候选机制诊断，不是因果分解。

当前证据不能支持：

- “增大某个 PI 增益一般都能提高稳定性”；
- “LCL、某个 PI 或调制器是唯一失稳原因”；
- 端点之间具有单调趋势，或已经确定临界参数值；
- 参与度最高的状态组就是物理致因；
- 结论可直接推广到多机系统、其他控制器、PWM/EMT 模型或实物装置；
- 该结果构成论文充分条件的反例。

## 7. 方法来源与项目自定义部分

- 左右特征向量参与因子的基本思想见 G. C. Verghese、I. J.
  Pérez-Arriaga、F. C. Schweppe，*Measuring State Variable Participation
  for Selective Modal Analysis*，1982，
  [DOI 10.1016/S1474-6670(17)63395-0](https://doi.org/10.1016/S1474-6670(17)63395-0)。
- 用 MAC 关联相邻参数工况模态的思路见 M. J. Desforges、J. E. Cooper、
  J. R. Wright，*Mode Tracking During Flutter Testing Using the Modal
  Assurance Criterion*，1996，
  [DOI 10.1243/PIME_PROC_1996_210_342_02](https://doi.org/10.1243/PIME_PROC_1996_210_342_02)。
- 简单特征值条件数及非正规敏感性见 R. Alam，*On the Sensitivity
  Analysis of Eigenvalues*，2015，
  [DOI 10.13001/1081-3810.2973](https://doi.org/10.13001/1081-3810.2973)。
- 完整谱一对一指派使用 H. W. Kuhn 的线性指派方法，见 *The Hungarian
  Method for the Assignment Problem*，1955，
  [DOI 10.1002/nav.3800020109](https://doi.org/10.1002/nav.3800020109)。

文献支持上述方法思想，但不替本项目的评分权重、数值门槛、状态分组、
19 点设计或因果结论背书。项目实现位于
`backend/core/average_dq_ablation.py`，固定预设位于
`backend/core/average_dq_presets.py`，接口为
`POST /api/average-dq/ablation`。
