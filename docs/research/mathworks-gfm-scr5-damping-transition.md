# MathWorks GFM 模型 SCR=5 阻尼分类过渡区

## 1. 问题定义

固定 MathWorks GFM 模型的 `2×4` 因子实验表明：`SCR=5` 时，VSM 阻尼 `D=1.056 p.u.` 由供应商函数 `FindTestOutCome` 判为 `Unstable`，`D=2.0 p.u.` 判为 `Stable`。本实验只回答一个有限问题：能否在这两个已验证端点之间，把供应商时域分类的变化压缩到宽度不超过 `0.02 p.u.` 的阻尼区间。

## 2. 冻结契约

- 外部版本：MathWorks 发布 `23.2.1.4`、提交 `a65692b004637acb38b2f8c64db7dcf47efe24c7`；
- 前置因子实验 JSON SHA-256：`90173E9BA8F9E554FF7058AF2E004A741C37F4ED7340FEB78064D045F0033FEA`；
- 固定 `SCR=5`、VSM、虚拟阻抗、`X/R=5` 与 `0.6→0.8 p.u.` 有功阶跃；
- 初始区间：下端 `D=1.056` 为 `Unstable`，上端 `D=2.0` 为 `Stable`；
- 算法：算术中点二分，最多6次新仿真；
- 停止条件：区间宽度不超过 `0.02 p.u.`；
- 有效性门：全部已测分类按阻尼排序后必须先为 `Unstable`、后为 `Stable`；若出现反向交错，拒绝输出单一过渡区。

## 3. 结论名称

最终只能称为“供应商时域分类过渡区间”，不能称为临界阻尼、闭环特征根边界或稳定性定理边界。区间中点仅作描述，不冒充已求得的临界值。

供应商 `Stable` 标签还必须与项目跟踪性能门分开：项目另要求在8秒仿真窗内进入并保持 `|P-P*|≤0.01 p.u.`。若供应商判稳但未满足此门，只能说响应被供应商分类为稳定，不能说有功跟踪性能合格。

## 4. 线性化探测边界

MathWorks 固定仓库提供的是电压、电流控制器开环波特图线性化示例。项目尝试将 R2024b `linearize` 扩展到整机闭环：关闭状态约简时得到2573状态，并在已知时域稳定点出现无关正实部状态；开启状态约简、选择有功参考—频率分析点时又退化为零状态静态模型。两条路径均伴随无功支撑平方根警告，当前没有通过工作点、可控可观性和时域分类一致性核查。因此本实验不使用这些线性化结果，后续若要讨论外部模型模态，必须先建立经验证的工作点与分析点契约。

## 6. 实际结果

六次算术中点试验依次得到：

| 阻尼 / p.u. | 供应商分类 | 项目有功整定门 | 最大频率偏差 / Hz |
|---:|---|---|---:|
| 1.52800 | Stable | 通过 | 0.039345 |
| 1.29200 | Unstable | 不通过 | 0.054265 |
| 1.41000 | Stable | 通过 | 0.044743 |
| 1.35100 | Stable | 通过 | 0.072999 |
| 1.32150 | Stable | 不通过 | 0.078056 |
| 1.30675 | Unstable | 不通过 | 0.109203 |

按阻尼排序后，供应商分类保持“先失稳、后稳定”，因此得到供应商时域分类过渡区：

```text
D_vendor ∈ [1.30675, 1.32150] p.u.
区间宽度 = 0.01475 p.u.
```

区间中点 `1.314125 p.u.` 仅为描述值。它不是已证明的临界阻尼。

项目有功跟踪门出现得更晚：`D=1.3215` 虽由供应商判稳，但未在8秒内进入 `0.01 p.u.` 整定带，末值绝对误差约 `0.02683 p.u.`；`D=1.351` 则通过。因此现有点只把跟踪性能过渡夹在 `[1.3215,1.3510] p.u.`，宽度 `0.0295 p.u.`，没有达到预设 `0.02 p.u.` 目标。两类区间不得合并。
