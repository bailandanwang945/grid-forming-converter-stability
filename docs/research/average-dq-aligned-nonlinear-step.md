# 团队16状态模型三点对齐非线性有功阶跃研究

## 1. 研究问题与可推翻假设

MathWorks 固定模型与团队16状态平均值 `dq` 模型在八个对齐坐标中有七点分类一致，唯一分歧为 `SCR=5、D_MW=1.056 p.u./Hz`：外部供应商时域函数判为失稳，而团队模型在 `P*=0.6、0.8 p.u.` 两个工作点的局部闭环特征根均稳定。

本实验检验以下受限假设：

> 若该分歧主要来自团队模型的局部特征根未能反映 `0.6→0.8 p.u.` 有功大阶跃，则团队模型在分歧点的非线性响应应当不能在固定时域内收敛，或越出预先声明的诊断范围；同时，高阻尼稳定参照点应保持收敛。

若分歧点在团队非线性模型中仍收敛，则该假设在当前模型和阶跃下被否定，后续应优先核对两套模型的内环、滤波、虚拟阻抗、限幅、初始化和分类器差异。

## 2. 冻结实验契约

| 项目 | 固定值 |
|---|---|
| 电网强度 | `SCR=5`，`X/R=5`，`|Z_source|=1/SCR` |
| 阻尼坐标 | `D_MW={0.6,1.056,2.0} p.u./Hz` |
| 团队阻尼换算 | `D_team=50D_MW` |
| 有功阶跃 | `P*=0.6→0.8 p.u.`，阶跃发生于 `t=0` |
| 仿真时域 | `8 s`，结果采样间隔 `0.01 s` |
| 主/复核求解器 | `Radau`、`LSODA` |
| 积分容差 | `rtol=1e-7`、`atol=1e-9` |
| 收敛尾窗 | 最后 `0.5 s` |
| 收敛带 | 频率偏差 `1e-4 p.u.`、有功 `0.01 p.u.`、相角 `0.01 rad`、电网电流 `0.02 p.u.` |

诊断退出门包括预设电流和内部电压诊断限值、`0.2 p.u.` 频率偏差、`π rad` 相角偏移及绝对状态上限。触发诊断门只记为“越出团队模型声明的诊断范围”，不等同于物理失稳。

两种求解器只有在以下条件同时满足时才记为一致：离散状态轨迹最大绝对差不超过 `1e-4`，最大频率偏差之差不超过 `1e-5 Hz`，事件时刻之差不超过 `1e-5 s`，且结果类别与退出事件相同。

## 3. 结果

| `D_MW` / p.u./Hz | 外部供应商分类 | 团队局部极点 | 团队非线性阶跃 | 关键结果 |
|---:|---|---|---|---|
| 0.600 | 失稳 | 失稳 | 越出诊断范围 | 两求解器均在约 `1.470495 s` 触发电网侧电流诊断限值；最大频率偏差约 `0.886868 Hz` |
| 1.056 | 失稳 | 稳定 | **8秒内收敛** | 最大频率偏差约 `0.154922 Hz`；有功整定时间 `1.82 s`；频率整定时间 `2.11 s` |
| 2.000 | 稳定 | 稳定 | **8秒内收敛** | 最大频率偏差约 `0.092670 Hz`；有功整定时间 `0.75 s`；频率整定时间 `0.77 s` |

三点的 `Radau` 与 `LSODA` 结果全部通过一致性门。分歧点 `D_MW=1.056` 在团队非线性模型中仍然收敛，且末值有功误差小于 `3e-7 p.u.`。因此，当前证据不支持“该分歧只是团队局部特征根漏掉同一模型的大阶跃失稳”这一解释。

更符合现有证据的后续假设是：两套模型尚未对齐的控制器、滤波器、限幅、初始化或分类器造成了定量边界分离。这里仍只能说“更值得优先核对”，不能将分歧唯一归因于某一环节。

## 4. 求解器筛选记录

早期无事件门的 `DOP853` 八点尝试在首点长时间运行，未形成正式结果。本轮先试用 `BDF` 复核：它与 `Radau` 给出相同类别和数值，但稳定点单次耗时约 `19–29 s`。`LSODA` 同样通过轨迹一致性门，正式三点运行约为 `2.8–6.0 s/点`，因此最终采用 `Radau + LSODA`。该选择只影响数值积分路径，不改变模型方程、参数和判定门。

## 6. 结论边界

该实验属于团队平均值模型内部的非线性数值验证，不是 MathWorks 模型复现、可信 EMT、硬件在环或实物确认。团队模型未包含开关、电磁暂态、饱和与保护逻辑；`D=0.6` 的诊断域退出不能直接命名为物理失稳。实验也不评价论文的小增益—小相位稳定性充分条件。
