# Fig. 8 振荡频率差异核查

## 1. 核查结论

截至 2026-08-06，仓库能够核实以下两项彼此不一致的结果：

1. 论文 arXiv v1 与 v2 的正文均称，无限大母线失稳算例在 `D=0.05` 时出现
   **1.2 Hz 持续振荡**；
2. 由作者 `UserData_inf_bus_Fig_8.xlsm` 工作簿及作者版
   `GridFormingVSI.m` 生成并冻结于本仓库的闭环极点谱，其主导不稳定共轭极点为
   \[
   \frac{\lambda}{2\pi}
   =0.0211544371\pm \mathrm{j}\,0.5781132968,
   \]
   因而对应的小信号振荡频率为 **0.5781132968 Hz**。

所以，目前只能表述为：**Fig. 8 工况的定性失稳已经由闭环特征根复现，论文所述
1.2 Hz 振荡频率尚未完成定量复现。** 不能把 0.578 Hz 写成论文报告值，也不能在缺少
原始时域数据的情况下断言论文数值错误。

同学 AI 报告的“线性时域响应约 0.570--0.579 Hz”和“非线性 Simulink 模型近奇异”尚未
随脚本、模型、原始时序和完整日志进入本仓库。本报告将它们记作**外部复现者报告、待导入
原始产物**，不把它们提升为仓库已经验证的事实。

## 3. 可由本仓库核实的结果

### 3.1 论文原文确实报告 1.2 Hz

- v1：`references/source/arxiv-2510.20544v1/source/sec5b_Examples.tex` 第 46 行；
- v2：`references/source/arxiv-2510.20544v2/source/sec5b_Examples.tex` 第 48 行。

两版均将 `D` 从 `0.5` 降至 `0.05` 后的现象写为 `sustained oscillations at 1.2 Hz`。
v1 把 VSM 误写为 SVM，v2 已改正该缩写，但 **1.2 Hz 数值未变**。

### 3.2 极点频率 0.578 Hz 的单位换算没有遗漏 \(2\pi\)

`experiments/baseline/run_inf_bus_baseline.m` 使用

```matlab
polesHz = eig(GsysSs.A)/(2*pi);
```

将状态矩阵特征值由 `rad/s` 尺度换算为每秒周数；夹具导出器又以相同换算结果与旧基线
交叉核对。固定谱文件
`experiments/baseline/fixtures/author_fig8_spectrum.csv` 的前两行数据为

```text
real_Hz = 0.021154437103478328
imag_Hz = +/-0.57811329684031898
```

因此，0.578 Hz 不是由漏除或重复除以 \(2\pi\) 造成的表面差异。这里的振荡频率取共轭
极点虚部的绝对值；实部为正则说明该小信号模态发散。

### 3.3 单元测试与 Fig. 8 受控回归

在核查提交上重新运行 `experiments/run_unit_tests.m`，结果为：

同学 AI 报告的测试时间为 6.9286 s；运行时间受机器和会话状态影响，不作为数值回归指标，

随后运行 `experiments/baseline/run_author_fig8_mixed_regression.m`，由返回结构逐项统计得到：

|---|---:|---:|---:|---|
| `D=0.05` | 385 / 615 / 0 | 540 / 422 / 38 | 75 | `+0.0211544371 +/- j0.5781132968` |
| `D=0.5` | 337 / 663 / 0 | 1000 / 0 / 0 | 0 | `-0.2898913606 +/- j0.3996010276` |

这与同学 AI 转述的任务一、任务二数字一致。需要保留两个解释边界：

1. 这是固定 1000 点网格、显式相位种子及最近邻分支假设下的筛查；返回值明确写有
   `theoremStatus = not-evaluated-by-sampled-api`，不能称为论文定理的连续全频证明；
2. `D=0.5` 虽有 663 个小增益条件失败样点，但全部样点均由小相位条件覆盖，因而与

## 5. 关于 \(2\times0.578\approx1.2\) 的假设

两倍小信号模态频率为 `1.1562266 Hz`，与论文的 `1.2 Hz` 相差约 3.65%。非线性响应中
出现二次谐波在数学上并非不可能，但数值接近本身既不能说明论文报告的是二次谐波，也不能
说明 0.578 Hz 与 1.2 Hz 已经一致。要检验该假设，至少应同时保留原始波形并比较：

- `theta`、`omega`、有功和 PCC 电压等不同物理量的频谱；
- 基波峰值与二次谐波峰值的幅值及随时间的增长率；
- 线性极点预测、非线性时域频率和论文图中实际测量量的定义。

在取得这些证据前，该解释的状态为**未验证假设**。

## 7. Python 便携内核交叉审查（2026-08-06）

### 7.1 公式、顺序、索引与单位

对 `backend/core/fig8_kernel.py` 与 MATLAB 研究内核逐项核对，当前 Fig. 8 固定算例中的
对应关系如下。

| 核查项 | MATLAB | Python | 判断 |
|---|---|---|---|
| 功率—极坐标变换 | `E=[vd vq; vq -vd]`，`C=[id iq; -iq id]` | 同式构造 | 一致 |
| 静态 `F` | `[-vq, vd/V; vd, vq/V]` | 同式构造 | 一致 |
| 虚拟阻抗权重 | `[sL+R,-X;X,sL+R]/hypot(R,X)` | 同式；`s=j2*pi*f` | 一致 |
| 高频变换项 | MATLAB 的 `W/E`，即右乘 `E^-1` | `weighting @ e_inverse` | 乘法顺序一致 |
| 变流器整形 | `(E*Yc+C)*F` | `(E @ Yc + C) @ F` | 一致 |
| 网络整形 | `(E*Ynet-C)*F` | `(E @ Ynet - C) @ F` | 符号与顺序一致 |
| 小增益裕度 | `sigma_min(Ynet)-max sigma_max(Yc_i)` | 固定单机算例采用同式 | 一致 |
| 严格扇形相位 | 旋转 Hermitian 分离，再解 `(G,H)` 广义特征值 | 同一旋转、同一广义 Hermitian 特征值问题 | 一致 |
| 相位分支 | 显式种子后按最近邻 `2*pi` 平移；最大中心步长 `0.9*pi` | 同一规则 | 一致 |
| 相位裕度 | 上界、下界及变流器总体相位展宽三项同时判定 | 固定单机算例采用同三项 | 一致 |
| 状态合并 | 任一条件通过即覆盖；增益与相位同时失败才记作未覆盖 | 同一优先顺序 | 一致 |
| 频率与极点单位 | 扫频以 Hz 输入并使用 `s=j2*pi*f`；夹具极点已除以 `2*pi` | 扫频同样转换；极点 CSV 不再重复换算 | 一致 |

Python 返回的变流器相位种子索引为 38（从零计数），对应 MATLAB 第 39 个样点，并非
一位偏差。该点频率应精确写为 `0.0018461469463245475 Hz`；原 Python 测试中的末位参考值
有转录偏差，且过宽的默认小数位断言掩盖了它，现已改为固定夹具的精确值和 15 位小数断言。

### 7.3 仍须保留的证据边界

本次核查没有发现会改变 Fig. 8 双工况计数或稳定性参考结论的 Python 公式错误，但便携
内核尚未完整携带 MATLAB 研究内核的全部诊断信息：

1. 第三项“变流器相位展宽裕度”参与了 Python 状态判定，但尚未写入
   `frequency_scan`，外部使用者不能仅凭返回对象逐项复核三项相位约束；
2. MATLAB 会计算互联恒等式相对残差并据此形成 `transformationStatus`；Python 当前由
   跨语言矩阵快照测试保护乘法顺序，但运行结果尚未返回互联残差与变换状态；
3. MATLAB 显式列出七项论文定理前提并在该受控回归中全部置为 `false`；Python 返回了
   `theorem_status=not-evaluated-by-sampled-api` 和中文解释边界，但尚未逐项返回这些前提；
4. Python 内核只允许两个固定工作簿工况，不执行阻尼插值，也不提供连续全频证明。这是
   有意的适用范围，不是一般网络或任意参数的论文定理实现。

据此，Python 版本可称为**作者 Fig. 8 固定夹具的便携式有限网格复现内核**，可继续用于
软件演示和结果复核；在补齐定理前提、连续频率证据和完整诊断以前，不宜称为“完整实现
论文定理”。
