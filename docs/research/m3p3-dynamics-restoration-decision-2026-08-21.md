# M3.3 动态环节恢复：在线调研后的阶段决策

## 1. 决策摘要

下一项正式研究工作确定为：**在 M3.2 已闭合的两个功率测量端口中间模型上，加入双方共有、定义一致的一阶有功功率测量环节，执行低频同步支路与宽频 LCL—内环支路的双支路跟踪。**

其后依次研究：PLL/频率估计器及其测量点、调制与计算延迟、外部 RL 线路动态。暂不新增前端工作区，不先安装新的运行框架，也不把第三方 Simulink 模型直接并入便携式软件。

这一排序的依据不是实现难易，而是当前证据链的结构缺口：M3.2 已经把团队有功测量延迟和调制延迟取为理想极限，并同时关闭 PLL 阻尼；这三项正是尚未解释的原始模型差异。外部线路动态同样重要，但当前中间模型仍以固定 PCC 为边界，且约 112 Hz 的宽频支路已处于右半平面，因此还不能严谨地把后续结果称为“整机 Hopf 稳定裕度”。

## 4. M3.3a 预注册实验

### 4.1 研究问题

在功率测量端口固定且其余结构不变时，有功功率测量时间常数如何移动约 `3.4 Hz` 的同步支路和约 `112 Hz` 的宽频支路？这一变化在团队坐标方程与来源坐标方程之间能否保持数值同构？

### 4.2 模型与参数

1. 继承 M3.2 的两个端口约定：双方均在滤波电容端测量，或双方均在 PCC 测量；不得混用。
2. 在双方方程中加入同一状态 `p_m`，采用 `T_m * dp_m/dt = p - p_m`，VSM 摆动方程使用 `p_m`。
3. 13 状态理想测量模型只作为 `T_m -> 0` 的降阶极限，不与 14 状态模型强行做一一模态续接。
4. 14 状态扫描预先固定为 `T_m = 0.01、0.025、0.05、0.1、0.2 s`；其中 `0.1 s` 是团队当前输入值，其余点只用于连续化，不采用论文的稳定阈值。
5. 继续同时记录全谱最右极点、低频命名支路、宽频命名支路、新增测量极点、左右特征向量 MAC、条件数、残差与工作点残差。

### 4.3 主假设、替代解释与失败条件

主假设 H1：相同端口、相同 `T_m` 和相同状态换元下，两套 14 状态中间方程仍通过现有 `1e-5 s^-1` 有限差分矩阵门。

- 推翻条件：任一端口的矩阵差超过门槛，或工作点残差超限；此时先查功率符号、端口和状态缩放，不比较特征值。

候选机理 H2：有功测量延迟对低频同步支路的影响强于对宽频支路的影响。

- 推翻条件：宽频支路的归一化位移更大，或低频支路无法通过预定模态匹配门；否定结果照常保留。

独立校核 H3：在小功角、P/Q 近似解耦等假设成立的测试点，详细模型中同步支路随 `T_m` 的移动方向与 Mitsugi—Baba 三阶相量模型一致。

- 推翻条件：方向不一致。此时结论只能是简化模型在该工作点不适用，不能把差异归咎于求解器。

反例：把来源侧功率端口由当前端口故意改成另一端口，矩阵门必须拒绝；若仍通过，说明验收门失效。

### 4.4 输出措辞

本实验可以报告“在两个来源明确的共同中间模型内，功率测量延迟与两条命名模态移动的数值关联”。由于基准宽频支路已经失稳，除非另行建立并登记稳定参考点，否则不得写成“整机稳定裕度提高/降低”，也不得外推到论文小增益—小相位充分条件、EMT 模型或实物变流器。

## 5. 后续两项的最小方案

### M3.3b：PLL/频率估计器与测量点

复用 Sienna Test 08 已转写的 PLL 状态，但建立四个来源明确的共同算例：电容端/PCC 两种电压测量点乘以 PLL 阻尼关闭/开启两种状态。先固定 PLL 整定，再单独扫整定；不得把测量位置变化混进增益变化。主输出仍是双支路和全谱最右极点，结论限于所测结构。

本阶段固定 M3.3a 的共同 PCC 有功测量端口与 `T_m=0.1 s`，仅加入 Kaura PLL 的四个状态：PLL 坐标中的低通电压 `v_pll,dq`、积分状态 `ε_pll` 和相角 `θ_pll`。整定固定为 Test 08 的 `ω_lp=500 rad/s、k_p=0.084、k_i=4.69`；阻尼关闭取 `k_d=0`，开启取 `k_d=400`。PLL 电压输入分别取滤波电容电压或固定 PCC 电压。四个18状态算例均要求团队路径与来源路径在同一坐标下通过平衡点、向量场和状态矩阵门。

预注册假设如下：H1 为四个共同算例均通过方程门；H2 为阻尼关闭时，改变 PLL 电压测量位置不得改变原14状态变流器子系统的特征根，这一组作为结构负对照；H3 为阻尼开启后，测量位置可能改变低频同步支路，但不能预设改善或恶化方向。若 H2 失败，应先检查 PLL 状态是否意外反馈到 VSM；若任一命名支路不能通过既有左右 MAC、条件数、残差与距离门，则结果记为“模态待定”，不得强行续接。即使某一18状态算例分类改变，也只能报告该共同中间模型的数值关联，不能归因为真实硬件中的 PLL 唯一因果作用。

### M3.3c：调制与计算延迟

团队一阶调制状态与 VSC_Lib 的 `TransportDelay` 是两种不同实现。先将一阶状态公平地加入双方共同方程；随后把 VSC_Lib 纯时延作为独立替代模型，用 Padé 阶次敏感性或时域线性系统校核，不以某一阶 Padé 极点直接充当物理模态。

## 6. 复用决策

- **已复制并可立即使用**：Mitsugi—Baba 的三阶 Hurwitz 关系作为独立解析校核方法；VSC_Lib 固定提交中的 LCL、PLL、输出延迟与初始化结构作为只读参照。
- **已有且继续使用**：Sienna Test 08 固定源码、谱与工作点；PowerDynamics 可组合方程；团队现有双侧模态跟踪、条件数、残差和反例门。
- **暂不复制到生产内核**：VSC_Lib 的整套 Simulink 库、MATLAB 运行依赖、纯时延实现；原因是便携性目标和方程实现尚未对齐。
- **明确不采用**：仅因 stars 较高便替换当前模型，或把第三方仿真曲线当作团队模型验证结果。

## 7. M3.3a 执行结果

预注册扫描已经完成。团队局部坐标方程与来源全局坐标方程分别加入同一个有功功率测量状态，再经显式坐标换元比较；两种共同功率端口、五个时间常数共十个计算点均通过加载平衡点、向量场和有限差分状态矩阵门。故 H1 在已测范围内成立。故意混用两种功率端口时，状态矩阵最大绝对差约为 `500 s^-1`，反例门能够拒绝错误结构映射。

在滤波电容端约定下，低频命名支路实部由 `T_m=0.01 s` 时的 `-2.5547 s^-1` 移至 `T_m=0.05 s` 时的 `+1.4052 s^-1`；在 PCC 约定下，相应数值为 `-2.4877 s^-1` 与 `+1.4617 s^-1`。两种端口约定均在已测 `0.025–0.05 s` 区间发生低频支路过零。与此同时，约 `112 Hz` 的宽频支路已经位于右半平面，其端点归一化位移仅约 `4.3×10^-5–4.5×10^-5`，而低频支路约为 `0.522`。因此 H2 获得“已测范围内支持”，但不能据此宣称唯一机理或连续临界值。

低频支路随 `T_m` 增大向右半平面移动，与 Mitsugi—Baba 三阶相量模型给出的定性趋势一致，故 H3 未被本轮结果否定；这只是方向校核，不是对其论文参数阈值的复现。全谱最右极点始终来自既有宽频失稳支路，故本实验仍不是整机 Hopf 稳定裕度研究。

## 8. M3.3b 执行结果

四个18状态共同算例均通过平衡点、向量场与状态矩阵方程门，H1 成立。关闭 `k_d` 时，PLL 到原14状态变流器子系统的反馈矩阵严格为零，且原子系统矩阵与 M3.3a 基线一致，故 H2 的负对照通过。这里区分了“实验执行与方程核验通过”和“某条模态身份仍待定”，没有把数值待定改写成失败或强行分类。

开启 `k_d=400` 后，滤波电容端测量的低频支路经自适应阻尼步长加密追踪至 `-4.8994±j4.6707 s^-1`（`0.7434 Hz`）；PCC 测量的候选低频根在接近实轴时触发实轴过渡、距离与候选歧义门。达到预注册的自适应加密深度后仍未建立跨越实轴的单模态身份，因此 H3 的“测量位置效应”结论保留为“模态待定”，不报告两个端点实部之差。两种开启阻尼算例的全谱最右极点仍来自约 `112 Hz` 宽频失稳支路，故不能宣称整机稳定化。

可重复入口为 `experiments/average-dq/run_sienna_team_common_pll_measurement.py`。JSON 与 CSV 的 SHA-256 分别为 `91E1629FB8940AC57A902CACBD940251C0964B74F4790333FF50612F1DF6EF6F` 与 `1208A5D4686702AC7E8888CB3C0DF88770A2F1FADA3B82AB9DD01F3335CFF192`。结果接入原 Sienna 审计 API 和同一前端研究工作区；界面明确显示“模态待定”，而不是以最接近端点特征根替代连续模态身份。

## 9. M3.3c1 共同局部 dq 一阶调制滞后的确认性运行登记

### 9.1 阶段取舍

本阶段先回答团队现有局部 `dq` 一阶调制状态本身的影响，再另设 M3.3c2 比较坐标落点、纯时延与 Padé 近似。局部逐轴一阶滞后、物理 `αβ` 侧一阶环节、纯时延和 Padé 有理近似的幅相特性与状态实现均不相同，不以时间常数数值相同为由宣称方程等价。

共同模型继承 M3.3a 已闭合的 14 状态、PCC 有功测量端口和 `T_p=0.1 s`，关闭 PLL 阻尼并保持固定 PCC 边界；随后在电流控制器电压指令与 LCL 对象之间加入两个控制 `dq` 坐标下的调制电压状态，形成 16 状态模型。M3.3b 的 18 状态 PLL 模型不作为父模型，因为其中 PCC 测量点的低频支路跨越实轴后仍为“模态待定”，且团队原 16 状态模型本身不含 PLL。若从该模型继续加状态，会把两个结构变量混入同一实验。

Han Deng、Jingyang Fang 的详细 GFM 状态空间模型把计算和 PWM 延时合计为 `1.5T_s` 并采用一阶 Padé 近似；VSC_Lib 则在平均模型中使用 `TransportDelay(Output_Delay)`。Dokus、Mertens 的式(53)进一步表明：若一阶PWM/采样环节先定义在物理 `αβ` 侧，再变换到同步 `dq`，方程会出现 `-jω_0v_m` 交叉耦合项。三项来源共同说明数字延时值得进入详细模型，却都不证明团队逐轴局部 `dq` 一阶滞后等价于物理侧延时。因此，本阶段只恢复并如实命名团队已声明的局部 `dq` 环节；M3.3c2 才把坐标落点、纯时延和 Padé 作为替代结构单独比较。

He 等人的 2025 年实验论文又从受控电压源内部稳定性和输出阻抗外部稳定性两方面说明，PWM 控制延时主要关联高频电压控制问题，并把常规采样延时写为 `T_d=1.5T_sw/N`。这为 H2 的“优先观察宽频支路”提供外部依据，但不保证团队参数下必然同向，故仍保留可推翻条件。

### 9.2 方程、参数与对照

1. 团队路径采用局部控制坐标中的 `T_m d(v_m,dq)/dt = v_i*,dq - v_m,dq`，LCL 的变流器侧电压输入由代数指令 `v_i*,dq` 改为状态 `v_m,dq`；该式不冒充物理 `αβ` 延时变换后的方程。
2. 来源路径独立保留控制 `dq` 下的同一调制状态，再以 `R(theta)v_m,dq` 驱动全局坐标 LCL 方程；调制状态不误写成静止坐标系的一阶滞后。
3. 双方状态换元的最后两维为恒等映射；其余 14 维沿用 M3.3a 已核验的积分增益缩放与电气量旋转。
4. 正式扫描固定为 `T_m = 0.1、0.25、0.5、1、2、5 ms`。`1 ms` 是团队当前输入值；其余点只用于有界灵敏度与连续模态跟踪。它们不冒充某一开关频率，也不与 VSC_Lib 的 `Output_Delay` 或文献 `1.5T_s` 建立未经证明的数值映射。
5. `T_m -> 0` 的 14 状态模型只作理想调制的降阶极限，不强行与 16 状态谱逐根对应。

为避免隐瞒先验，本登记不是完全盲法预注册：在正式实现前已经做过一次不落盘的结构可行性试算，用于确认平衡点能够求解、两个方程路径可对齐以及扫描不会无界耗时；试算也提示宽频支路可能比低频支路移动更明显。正式结论仍只取版本化实现、自动测试和落盘结果。

### 9.3 假设、反例与失败条件

H1（方程同构）：在双方都明确采用“局部 `dq` 一阶滞后”的相同 `T_m` 下，团队局部坐标路径与来源全局 LCL 路径经过显式换元后，非平衡点向量场和有限差分状态矩阵均通过 `1e-5 s^-1` 门。

- 推翻条件：任一点平衡残差超限、向量场差或矩阵差超过门。此时先检查调制状态所在坐标系、旋转方向和 LCL 电压端口，不比较特征根。

H2（支路选择性）：在固定扫描范围内，调制一阶环节对约 `112 Hz` 宽频 LCL—内环支路的归一化端点位移大于低频同步支路。

- 推翻条件：低频支路位移不小于宽频支路，或任一命名支路触发左右 MAC、距离、条件数、残差、近重根或实轴过渡门。后者记为“模态待定”，不得用每点最右极点替代连续支路。

结构反例：团队侧保留一阶调制状态，而来源侧故意让电压指令直接驱动 LCL。矩阵门必须拒绝；若仍通过，说明验收门或端口接线无效。

### 9.4 可报告范围

本阶段至多报告：“在固定 PCC、共同有功测量动态和共同级联内环的 16 状态中间模型内，局部 `dq` 一阶调制时间常数与两条命名模态移动存在何种数值关联。”由于约 `112 Hz` 支路在基准中已经位于右半平面，本实验仍不能称为整机 Hopf 稳定裕度研究，也不能外推为物理PWM延时、EMT、实物、多机系统或 Cifelli—Anta 小增益—小相位充分判据的结论。

## 11. M3.3c2a 物理固定坐标系一阶环节

### 11.1 方程边界

依据 Dokus—Mertens 式(53)，将物理固定坐标系中的一阶电压环节变换至变流器局部 `dq` 坐标系后，调制电压状态应写为

`dv_m,dq/dt = (v_i*,dq-v_m,dq)/T_m - omega_b*omega_pu*J*v_m,dq`。

独立来源路径则在公共全局旋转坐标中采用系统同步角频率项，再通过动态相角换元返回团队局部 `dq` 坐标。该模型仍是平均意义下的一阶环节，不是精确纯时延，也不包含开关波形。

### 11.2 核验结果

六个固定时间常数下，两种坐标实现的非平衡向量场最大无穷范数差为 `8.60201×10^-13`，状态矩阵最大绝对差为 `1.48665×10^-6 s^-1`，均通过 `1×10^-5 s^-1` 方程门。若删去旋转交叉耦合项、以逐轴局部 `dq` 一阶惯性环节替代，状态矩阵差至少为 `381.499 s^-1`，故“二者只是不同写法”的解释被反例门拒绝。

六点谱横坐标均为正，且从约 `206.57 s^-1` 非单调变化至最高约 `242.62 s^-1`；该结果只建立坐标实现的方程等价性及两类一阶环节的结构非等价性，不构成 PWM 纯时延、闭环稳定裕度或控制参数优劣结论。JSON 与 CSV 的 SHA-256 分别为 `9FFC879D8124F76AC3201E33E9DB8BE9F2D88BAC20F473F04CA7950A2F9DDAE1` 与 `8DE5C0B53D5B4877A34901A784BC51E8E10463D417A86273AA485B68A5228FE6`。

## 12. M3.3c2b 纯时延与 Padé 有理近似的频率响应核验

Kong 等人的 APEC 2025 模型先定义纯时延 `G_d=exp(-sT_d)`，再以一阶惯性环节近似；Deng—Fang 则对纯时延采用一阶 Padé 近似。这些文献共同支持“分别命名原模型与近似模型”，不支持把逐轴一阶惯性环节直接称为纯时延。

本项目固定 `T_d=1 ms`，在 `0–200 Hz` 的 `2001` 个频点比较精确纯时延、逐轴局部 `dq` 一阶惯性环节以及一至三阶 `[n/n]` Padé 近似。Padé 系数递推由 `python-control 0.10.2` 的 BSD-3-Clause 实现小范围改写，并以其一至三阶参考向量作独立回归；发行包将同时携带固定上游许可证。

在 M3.3c1 的 `2.2205 Hz` 低频命名支路处，各近似与纯时延近似重合；在 `95.5769 Hz` 宽频命名支路处，局部 `dq` 一阶惯性环节幅值为 `0.8573`，相对纯时延额外产生约 `14.27%` 衰减，相位误差约 `3.4217°`。一、二、三阶 Padé 的相位误差分别约为 `0.9815°、0.00608°、1.58×10^-5°`，幅值均保持为一。全频带最大相位误差随阶次由 `7.716°` 降至 `0.226°` 和 `0.00264°`，且各 Padé 极点均位于左半平面。

该核验只比较频率响应。精确纯时延对应无限维系统；Padé 近似引入的附加极点不得解释为变流器物理模态。本阶段尚未完成含精确纯时延的闭环特征根或时域稳定性比较。JSON 与 CSV 的 SHA-256 分别为 `F0F738865162B318B22D0EE2241D9D6014B7EF05165CDB7E35802D6EF98BFA10` 与 `0B62581E53BB832C4D1085E5ED5BB579CC0316F3FCD7B98B85481A078FDC69C8`。
