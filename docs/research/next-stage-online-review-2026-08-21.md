# 下一阶段在线调研与研究决策（2026-08-21）

## 1. 调研问题

本轮不预设“继续补外环”必然是下一项工作，而是核查三个问题：

1. 当前共有内环约 `100 Hz` 的右半平面模态是否值得先做机理定位；
2. VSM 与 Q–V 外环、LCL 内环及电网动态应按什么次序加入；
3. 哪些公开模型适合作为外部参照，哪些只适合提供方法线索。

完成标准是：另一名研究者能够依据在线原始来源、项目冻结结果和预先写明的失败条件，复核下一阶段排序，而不是只接受“功能容易实现”的判断。

## 2. 在线原始来源

### 2.1 论文

| 来源 | 与本项目有关的结果 | 采用边界 |
|---|---|---|
| Zhao, Wang, Jin, *Exploring Damping Effect of Inner Control Loops for Grid-Forming VSCs*, arXiv:2310.09660v1 | 以阻抗和复转矩系数分析表明，系统净阻尼由外环、内环和电网共同贡献；内环会同时影响同步振荡与次同步振荡 | 控制结构和参数不等同于团队模型，只作为机理与实验设计依据 |
| Benedetti, Preece, Papadopoulos, *Bifurcation Analysis of Sub-Synchronous Oscillations Related to Grid-Forming Converter Inner Controllers*, arXiv:2607.18894v1 | 在级联电压—电流内环的构网变流器中，强网 Hopf 分岔与内环相关振荡有关；电压、电流内环时间尺度分离直接影响稳定边界 | 采用连续化与非线性分岔分析，不能由本项目线性特征根直接复称其结论 |
| Chatterjee, Geng, *Effects of Line Dynamics on Stability Margin to Hopf Bifurcation in Grid-Forming Inverters*, arXiv:2412.15449v1 | 该算例中加入线路动态会系统性降低 Hopf 稳定裕度，Q–V 下垂参数的差异较显著 | 只说明静态线路近似可能偏乐观，不证明团队动态 RL 线路一定是现有差异来源 |
| Chen et al., *LCL Resonance Analysis and Damping in Single-Loop Grid-Forming Wind Turbines*, arXiv:2504.06981v2 | 对单环 droop-I 构网控制，LCL 高频稳定性与低频功率环并非必然解耦；有源阻尼效果依赖反馈位置及开环非最小相位性质 | 论文对象是单环 droop-I，不可直接套用于团队双 PI 级联内环；用于反驳“高低频必然解耦”和“任意有源阻尼都有效”两种先验假设 |

### 2.2 官方软件与模型

- `PowerSimulationsDynamics.jl` 在线核查时最新正式版本为 `v0.16.2`。官方文档明确把 VSM/Q-droop 外环、虚拟阻抗与双 PI 内环、LCL、频率估计器和网络作为可组合组件，并以 DAE 工作点、约化雅可比和特征值执行小信号分析。这仍是本项目最合适的第三方方程与固定谱参照。
- `PowerDynamics.jl` 在线核查时最新正式版本为 `v5.0.0`，适合核对透明的可组合方程；不因框架存在就把其中每个新构网组件称为已经独立实验确认。
- `l2ep-epmlab/VSC_Lib` 约 50 stars，MIT 许可，2025 年仍有提交，公开 L/LCL、单机和多节点 SimPowerSystem 构网模型。它适合作为后续 MATLAB/Simulink 结构参照，但暂不引入为运行依赖。
- `ATayebi/GridFormingConverters` 约 138 stars，提供 IEEE 9 节点 droop、VSM、matching 与 dVOC 基准，但最后代码推送停留在 2020 年且仓库未声明 SPDX 许可；适合作为论文算例线索，不作为当前软件依赖。
- `CURENT/andes` 社区规模较大，但在线仓库树未检出明确的构网型变流器实现，因此不因 stars 较高而把它选作本阶段 GFM 交叉验证基准。
- `PowerImpedance.jl` 面向阻抗扫描和广义奈奎斯特分析，方向与本项目相关但仍属较新的小型项目；可列入后续频域工具观察清单，不取代当前作者基线和 Sienna 固定参照。

GitHub stars 只用于判断社区规模，不能作为模型正确性证据；研究引用继续固定 tag、commit、方程和算例。

## 3. 与项目现有证据的交叉判断

当前两个10状态共有内环的最右特征值分别约为
`117.14 ± j652.58 s^-1` 与 `119.22 ± j654.09 s^-1`，对应约
`104 Hz`。加入相同 Test 08 有源阻尼后，最右模态仍在约 `100 Hz`，谱横坐标反而增加到约 `122–124 s^-1`。这不是原论文的 `0.578/1.2 Hz` 低频分歧，也不是团队16状态模型的同步主导模态，而是当前固定输入中间模型的内环/LCL宽频模态。

在线文献表明：

1. 这类模态不能在没有参与度、带宽和参数灵敏度证据时归因于外环缺失；
2. 也不能把外环、内环和电网完全割裂，因为它们可能共同形成净阻尼；
3. 有源阻尼不是与结构无关的通用开关，反馈位置、开环极点和LCL参数都可能改变效果；
4. 静态PCC或静态线路只能作为分层中间模型，不能替代最终网络动态核查。

因此，原计划“直接加入共有 VSM/Q–V 外环”仍有价值，但排序需要后移一层。

## 4. 下一阶段排序

### M3.1：共有内环/LCL模态指纹（已完成）

目标：判断约 `100 Hz` 右半平面模态在当前共有模型中主要由哪些状态和参数参与，并检验它是否随内环带宽、LCL参数及电网等效阻抗连续移动。

最小实验包括：

1. 对10状态与12状态两条结构路径计算左右特征向量、参与因子、特征值条件数和残差；
2. 只对文献与方程直接指向的参数做单因素变化：电压/电流 PI 联合增益、`X1/Bc/X2`，以及12状态模型的有源阻尼增益与截止频率；外部电网强度留到网络闭环后分析；
3. 跟踪“约100 Hz分支”和“全谱最右模态”两列，发生身份不确定时标记待定，不强行连线；
4. 保存一个错误映射反例，确保算法能够拒绝参数或状态换元错误。

主假设：当前固定输入共有模型的最右模态是由级联内环与LCL电磁动态主导的宽频模态。

可推翻条件：该模态的主要参与状态并非内环/LCL状态，或在合理的内环/LCL单因素变化下不呈连续、可辨识响应。

### M3.2：共有 VSM/Q–V 外环与全局PCC坐标（随后）

在 M3.1 已识别模态后，再加入双方共有的相角—频率与无功—电压状态。先关闭PLL阻尼，把团队有功测量和调制延迟置为理想极限。此阶段同时跟踪低频同步分支与M3.1的宽频分支，回答外环究竟新增、移动还是耦合了哪些模态。

固定全局PCC电压只能检验坐标与功率反馈，不能称为完整网络闭环。

### M3.3：线路动态与剩余结构差异

只有共有外环闭合后，才按单因素顺序加入有功测量、调制、PLL阻尼和外部线路动态。静态线路与动态RL线路须形成明确对照，不能直接把两者的特征值差命名为实现误差。

### M3.4：第三方运行确认

方程、工作点和状态维数对齐后，再决定安装Julia并运行 Sienna Test 08；PSCAD固定轨迹仍作为上游证据，不在没有相应环境时声称已重跑。

| 维度 | 结论 |

## 6. M3.1 执行结果

四个固定输入中间模型的命名支路均可由左右特征向量门连续追踪。10状态两条路径的基准频率为 `103.861 Hz` 与 `104.102 Hz`，12状态两条路径为 `99.949 Hz` 与 `100.151 Hz`。在冻结的团队坐标基下，网侧滤波电流状态的归一化参与度约为 `65.4%–65.9%`，电压 PI 状态约为 `14.8%–16.1%`，变流器侧电流状态约为 `14.8%–16.3%`；电流 PI 与有源阻尼滤波器状态的参与度均较小。

在预先固定的 `0.8/1.2` 单因素端点中，`X2` 对命名支路实部的局部影响最大，四个变体的最大绝对实部位移约为 `29.48–32.89 s^-1`。这里的 `X2` 仅表示 LCL 网侧滤波电抗，不是外部电网电抗，也不能换名为 SCR。直接把 `X2` 从1倍跳到5倍时，模态匹配门拒绝该跳变；插入几何中点后才能恢复支路，说明追踪程序不会仅凭频率相近强行连线。

结果在所列模型、坐标基和端点内支持“该宽频支路具有 LCL—电压控制相互作用特征”这一候选解释，但不建立唯一因果归因、连续稳定边界或全参数域结论。参与度随任意状态缩放并不保持不变；当前只在冻结团队坐标基下解释。可重复产物为 `results/sienna-team-isomorphism/common_inner_loop_modal_fingerprint.json` 与同名 CSV。
