构网型变流器稳定性分析平台（Windows 免开发环境版）

一、运行方法
双击 GFM-Stability-Platform.exe。程序就绪后会自动打开本机浏览器。
程序仅监听 127.0.0.1，不对局域网或互联网开放服务。

二、退出方法
关闭网页后，在程序窗口按 Enter；也可在程序窗口按 Ctrl+C。
正常退出会停止本地服务并释放端口。

三、运行条件
- Windows 10 或 Windows 11，64 位；
- 无需安装 Python、Node.js 或 MATLAB；
- 首次启动可能被 Windows 安全检查延迟，请等待片刻；
- 软件不需要联网，浏览器仅访问程序窗口显示的 127.0.0.1 本机地址；默认从 8000 端口开始选择可用端口。

四、在另一台电脑上试用
先完成实际使用流程：启动程序，进入“设备与控制”，导入或编辑案例，运行分析，保存案例或导出结果，最后正常退出。
CASE_WORKFLOW.md 说明完整案例的保存、导入、基准—当前方案对照及结果与报告的区别。
需要详细自动诊断时可双击 VERIFY_THIS_PC.cmd。脚本会校验包内文件，并复算既有研究模块；部分试验较耗时，不是普通启动或协同开发的前置步骤。
GFM_CROSS_MACHINE_FUNCTIONAL_OK 表示该自动功能链通过。脚本仍保留旧 M5 资格字段，未满足异机、断网、无开发环境等旧条件不等于软件不能使用。
若另有正式断网运行要求，应按实际情况测试，不能以本机测试代替异机证据；脚本也无法独立证明物理网络已经断开。

五、常见问题
1. 若 8000 端口已占用，程序会有界选择后续空闲端口；请以窗口打印的 Ready 地址为准。
2. 若浏览器没有自动打开，可手动访问窗口打印的本机地址。
3. release-manifest.json 记录版本、源代码提交和包内文件 SHA-256，可用于核对交付物完整性。

六、证据边界
论文 Fig. 8 页面基于版本固定的作者数据夹具与便携式 Python 数值内核。
有限频率网格筛查不等同于论文定理的全频验证；判据未覆盖也不等同于闭环必然失稳。
低频模型页面属于相角—频率—有功功率降阶模型，不代表完整平均值 dq 模型或电磁暂态模型。
平均值 dq 页面属于团队定义的16状态正序平均值单机模型；工作点、功率平衡、线性化、端口重组和非线性小扰动响应属于同一模型内部验证，不等同于可信 EMT、硬件在环或实物确认。
三频点端口辨识在同一稳定闭环中施加小幅源电压正弦扰动，用于核对非线性响应与局部线性端口实现；它不构成真实硬件或可信 EMT 确认，也不评价论文稳定性充分条件。
页面中的 D–X 层级扫描逐点比较16状态模型与工作点匹配三状态近似；分类失配用于标示低频近似边界，不是论文定理反例。线路 X 是该外部支路的标幺电抗，不自动等同于普遍 SCR。
Sienna Test 08 页面复核固定19状态来源方程，并展示团队模型与来源模型的分层同构化中间算例。当前只允许复跑上游固定基线；原始16状态与19状态整机仍不具备逐根特征值比较条件，页面中的“未就绪”不是软件运行失败。
