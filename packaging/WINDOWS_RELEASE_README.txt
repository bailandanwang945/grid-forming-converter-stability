构网型变流器稳定性分析平台（Windows 免开发环境版）

一、运行方法
双击 GFM-Stability-Platform.exe。程序就绪后会自动打开本机浏览器。
程序仅监听 127.0.0.1，不对局域网或互联网开放服务。

二、退出方法
关闭网页后，在程序窗口按 Enter；也可在程序窗口按 Ctrl+C。
正常退出会停止本地服务并释放端口。

三、运行条件
- Windows 10 或 Windows 11，64 位；
- 无需安装 Python、Node.js 或 MATLAB；
- 首次启动可能被 Windows 安全检查延迟，请等待片刻；
- 软件不需要联网，浏览器仅访问本机地址 http://127.0.0.1:8000。

四、常见问题
1. 若提示 8000 端口已占用，请关闭先前启动的平台或其他占用该端口的软件，再重新启动。
2. 若浏览器没有自动打开，可手动访问 http://127.0.0.1:8000。
3. release-manifest.json 记录版本、源代码提交和包内文件 SHA-256，可用于核对交付物完整性。

五、证据边界
论文 Fig. 8 页面基于版本固定的作者数据夹具与便携式 Python 数值内核。
有限频率网格筛查不等同于论文定理的全频验证；判据未覆盖也不等同于闭环必然失稳。
独立模型页面属于低频相角—频率—有功功率降阶模型，不代表完整平均值 dq 模型或电磁暂态模型。
