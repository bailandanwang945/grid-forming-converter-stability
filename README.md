# 构网型变流器稳定性分析平台

面向构网型变流器（Grid-Forming Converter, GFM）小信号稳定性研究的本地可视化分析软件，也是天津市大学生创新训练项目的主要软件成果。

项目以 Cifelli–Anta 分散式小增益—小相位稳定条件为论文基线，同时建立与论文夹具相互隔离的团队自建低频模型。软件把版本固定的论文算例复算、可编辑网络、闭环特征根、线性响应、参数扫描和可追溯报告组织为一套可重复演示的工作流。

> 当前源码版本为研究开发版 `v0.5.0-dev`，最近一份冻结的 Windows 异机候选仍为 `v0.4.0-rc2`。平台含论文 Fig. 8 便携复算、同域充分判据—闭环参考对照、三状态低频模型和16状态平均值 dq 模型四个工作区；平均值 dq 工作区新增固定 19 点模态消融、连续追踪与四条单因素临界边界。Fig. 8 内核仍评价固定 1000 点频率网格，`theorem_status` 保持为 `not-evaluated-by-sampled-api`；有限网格筛查结果不能冒充论文连续全频定理的完整验证。

## 一键启动

### Windows 开发态

双击项目根目录中的：

```text
启动平台.bat
```

启动器会检查 Python、Node.js 和项目依赖，启动 FastAPI 后端与 React 前端，等待健康检查通过后打开浏览器，并在退出时清理本次启动的服务。默认访问地址为 <http://127.0.0.1:5173>；若 `8000` 或 `5173` 已被其他程序占用，启动器会自动选择后续空闲端口并在窗口中显示实际地址，不会终止或复用其他项目的服务。

开发态要求：

- Windows 10/11；
- Python 3.10 或更高版本；
- Node.js 20 或更高版本；
- 运行网页与 Python 分析不要求安装 MATLAB。

首次启动可能需要联网安装依赖。Windows `v0.4.0-rc2` `onedir` 候选包已从干净提交 `11eebeb` 构建，ZIP SHA-256 为 `55c58253336f8e1a7b4132a097908e45ae2a26281f00ea2c5fb1e133468d2c3f`。该包是历史冻结证据，早于 `v0.5.0-dev` 的现代科研画布界面、响应式布局、19 点模态消融和临界边界功能；日常协同开发与当前演示应使用 GitHub 最新源码，不应把旧包界面误认为当前版本。下一次功能冻结后再构建新的自包含 Windows 包。

当前网页主要参考 MIT 许可的 [AutoFigure-Edit](https://github.com/ResearAI/AutoFigure-Edit) 科研画布：细网格背景、米灰—薄荷渐变、圆角功能卡、紧凑任务工具条和清晰的主次操作。平均值 dq 工作区只在左栏保留参数与主分析入口，把42点层级扫描、19点模态消融和四条临界边界组织为独立研究任务卡；不再使用水墨、山景或长按钮瀑布。模型结构、中文术语、数值结果和科研边界仍由本项目独立维护，未复制 AutoFigure 的品牌标志或业务素材。设计调研与取舍见 [`docs/design/frontend-reference-study.md`](docs/design/frontend-reference-study.md)。

## 软件展示内容

网页包含四个边界清晰、数据来源可追溯的工作区。

### 论文复现

- 仅提供作者 Fig. 8 的两个固定工况 `D=0.05` 与 `D=0.5`，不在两者之间进行阻尼插值；
- Python 内核从受版本约束的作者频响与闭环谱夹具重新计算 1000 个频点，不使用人工预览公式；
- 展示小增益、小相位和混合覆盖结果、频率裕度曲线及闭环主导极点；
- 两个工况分别重现 75 个和 0 个未覆盖频点；
- 提供固定夹具上的采样敏感性实验：失稳工况缩减到 9 个回顾性子网格频点时会漏掉完整网格中的全部 75 个未覆盖样点；测试范围内最终判定容差与公共矩阵尺度变化未改变逐点分类；
- 可导出结果 JSON，并生成包含输入、结果、来源与学术边界的打印式 HTML 报告。

工作簿闭环谱对应的失稳主导振荡频率约为 `0.578 Hz`，论文正文报告约为 `1.2 Hz`。该定量差异尚未闭合，界面与报告均保留提示；现阶段只能确认失稳极点实部符号和有限网格判据回归，不宣称振荡频率已经定量复现。

### 同域对照

- 沿用作者 Fig. 8 的同一模型、端口约定和工作簿，在 11 个线路阻抗缩放系数与 16 个 VSM 阻尼值组成的 176 点参数域内重算；
- 每个参数点同时保存闭环特征根参考结果，以及 121 个固定频率样本上的混合小增益—小相位筛查结果；
- 得到 45 个“判据覆盖且参考稳定”点、96 个“参考稳定但判据未覆盖”点、35 个“参考失稳且判据未覆盖”点，数值待定与一致性违例均为 0；
- `κ=1、D=0.05/0.5` 两个锚点重新生成的频率响应和主导极点与冻结 Fig. 8 夹具交叉核对，变流器响应最大绝对误差小于 `4e-13`，主导极点实部误差为 0；
- 网页提供可点击的 D–SCR 分类热图、参数点详情、CSV 导出和自包含打印式报告；便携软件只读加载冻结证据，运行时不要求 MATLAB。

这一区域比较展示的是当前固定模型与离散网格下可观察到的充分条件保守性。有限网格覆盖不是论文连续全频定理的证明；“稳定但未覆盖”也不意味着定理错误，闭环特征根仅作为冻结模型上的有限精度参考。

### 独立模型

- 采用团队自建的低频相角—标幺频率—有功功率测量降阶 VSM 模型，并显式使用基频关系 `δ̇=ω_bΔω_pu`；
- 通过 `NetworkTopology/1.0` 契约编辑母线、交流线路、构网型变流器、无限大母线、基值和控制参数；
- 提供稳定、Routh–Hurwitz 临界和低阻尼失稳三个解析预设；
- 从同一输入计算网络同步刚度、Kron 消元后的状态矩阵、全部闭环极点、主导模态和零输入初始条件线性响应；
- 支持带版本号的案例 JSON 导出—导入—重算往返，以及结果 JSON、极点 CSV、时域响应 CSV；
- 提供以选定 VSM 阻尼 `D` 和选定线路标幺电抗 `X` 为坐标的显式网格扫描、稳定性热图和 CSV 导出；
- 生成独立模型打印式 HTML 报告，与 Fig. 8 报告共用可追溯的后端计算路径。

这里的 `X` 仅表示选定线路在算例基准值下的标幺电抗，不自动换算或命名为普遍意义的短路比（SCR）。独立模型也不是完整平均值 `dq` 模型：目前不包含无功—电压耦合、变流器内环、限幅、负荷动态和电磁暂态，线路电阻亦未进入有功同步刚度。

### 16状态平均值 dq 模型

- 采用功率不变 Park 变换，保留 VSM 有功—频率环、Q–V 下垂、dq 电压与电流 PI 双闭环、平均调制延迟、LCL 电磁动态及外部串联 RL 线路；
- 外部线路与网侧滤波电感共享支路电流，但显式重构线路近端 PCC 电压，避免把功率测量点错误移动到无限大母线；
- 先求解两个标量组成的工作点方程，再回代16个状态；工作点残差、有功平衡、电流和内部电压诊断不通过时拒绝输出稳定性结论；
- 同时计算直接闭合状态矩阵、全局同步 dq 端口导纳、非线性平均值响应和局部线性响应；
- 在稳定闭环中从无限大母线沿全局 `d、q` 轴逐频注入小幅正弦扰动，以非线性 PCC 电压和端口电流相量反演设备导纳；`0.2、2、20 Hz` 三点的最大幅值与相位误差约为 `0.0171% / 0.0231°`，并保留相量条件数、残差及幅值减半核查；
- 由变流器端口状态空间与外部线路方程独立重组闭环矩阵，并与直接闭合矩阵逐元素核对；
- 在同一带载工作点保持 Q–V 准稳态关系，计算实际同步刚度 `Kδ=∂p/∂δ`，再与三状态外环近似比较主导模态；冻结预设的振荡频率与衰减率误差均小于 5%；
- 提供7个阻尼值与6个外部线路电抗值组成的42点逐点重算扫描；当前冻结网格中39点稳定性分类一致，3点出现“三状态稳定、16状态失稳”的层级失配，用于界定低频近似的适用范围；
- 针对 `D=60、X=0.1 p.u.` 的层级失配锚点，提供固定19点控制与 LCL 参数消融；完整16阶谱使用左右特征向量 MAC、特征值距离、条件数、残差和一对一指派进行相邻参数点模态追踪，步长过大时自动加密，两项 PI 同时变化时按两条参数顺序复核；
- 19个端点中5点稳定、14点失稳，两个命名模态均通过默认追踪门槛；该结果只用于固定模型下的候选机制诊断，不把参与度、MAC 或稳定化端点解释为唯一因果证明；
- 沿电压环 PI、电流环 PI、变流器侧滤波电抗和电网侧滤波电抗四条冻结单因素路径，分别求解被追踪附加模态实部过零与完整16状态谱横坐标过零；四条边界均收敛且两类边界一致，临界倍率依次为 `1.629746`、`1.601645`、`0.693169` 和 `1.994560`；
- 网页可编辑 P/Q/V 设定、阻尼、线路 R/X、LCL 参数和 Q–V 下垂，展示极点、非线性—线性相角偏差、端口导纳范数；固定三频点端口辨识可从独立任务卡运行，并导出 JSON 和打印式 HTML 报告；
- 在与 MathWorks 八点比较一致的阻尼与网络换算下，补充 `D_MW=0.6、1.056、2.0 p.u./Hz` 三点团队模型大扰动阶跃。Radau 与 LSODA 的结论逐点一致：低阻尼点越出预先声明的电流诊断范围，唯一分类分歧点与高阻尼点均在 8 秒窗内收敛。该结果说明团队模型自身的同一阶跃不能解释分歧点的供应商失稳分类；低阻尼越界也不被写成物理失稳。

该模型已经完成软件内部验证，但尚未与实物、硬件在环或可信 EMT 模型完成外部确认。它不是论文 Fig. 8 模型，也不包含 PWM、限流、故障穿越、不平衡、负荷 DAE 或多机非线性网络。

## 研究与证据分层

项目将下列内容严格区分：

1. **论文基线**：论文 v2、官方 TeX、作者仓库固定版本及 Fig. 8 输入夹具；
2. **团队数值实现**：MATLAB 数值域与相位算法，以及 Python 有限网格便携内核；
3. **团队独立模型**：低频 VSM 降阶模型与16状态平均值 dq 模型；前者用于解释同步模态，后者用于检查保留内环、Q–V 与电磁动态后结论如何变化；
4. **同域研究对照**：在作者同一模型和同一参数域内并列计算闭环参考稳定区与有限网格判据覆盖区；
5. **软件展示与报告**：只展示后端实际计算或已核验冻结证据，不把界面变化当作科研证据。

充分条件未覆盖不等于系统必然失稳。论文有限网格筛查、闭环特征根参考结果和独立降阶模型结论均须按各自假设解释，不得跨模型外推。

## 开发与验证

在项目根目录运行统一验收：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify_all.ps1
```

验收依次覆盖当前 Python 测试集、前端生产构建、开发态启动器、受控浏览器端到端流程，以及可选的 MATLAB 测试。MATLAB 不在默认安装路径时，可先设置其安装根目录，例如：

```powershell
$env:MATLAB_ROOT = "D:\matlab"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify_all.ps1
```

路径仅为示例，应改为本机实际 MATLAB 安装目录。没有 MATLAB 时可使用 `-SkipMatlab`；验收结果会明确记为 `SKIP`，不会误报为通过。详细规则见 [`docs/software/VERIFICATION.md`](docs/software/VERIFICATION.md)。

开发过程与遗留问题见 [`notes/PROJECT_LOG.md`](notes/PROJECT_LOG.md)，算法说明见 [`docs/specs/algorithms/`](docs/specs/algorithms/)，研究方法和阶段性结论见 [`docs/research/`](docs/research/)。
