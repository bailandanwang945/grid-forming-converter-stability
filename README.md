# 构网型变流器稳定性分析平台

面向构网型变流器（Grid-Forming Converter, GFM）小信号稳定性研究的可视化分析原型，也是天津市大学生创新训练项目的主要软件成果。

本项目以 Cifelli 与 Anta 关于分散式小增益—小相位稳定条件的研究为理论基线，尝试把论文判据、闭环特征根参考验证和参数扫描整合到一个可交互、可复现、可扩展的工作台中。

> 当前版本为研究原型 `v0.1`。网页端使用受控的论文算例预览数据，尚不能宣称已经完整实现论文全部定理。MATLAB 研究代码、数值结果和测试证据与网页演示层分别保存。

## 一键启动

### Windows

双击项目根目录中的：

```text
启动平台.bat
```

启动器会自动：

1. 检查 Python、Node.js 和项目依赖；
2. 在首次运行时安装缺少的依赖；
3. 启动 FastAPI 后端和 React 前端；
4. 等待服务就绪后打开浏览器；
5. 在启动窗口按回车时关闭前后端服务。

默认访问地址：<http://127.0.0.1:5173>

首次启动需要联网安装依赖，可能耗时数分钟。后续启动通常只需数秒。

### 环境要求

- Windows 10/11；
- Python 3.10 或更高版本；
- Node.js 20 或更高版本；
- 仅运行网页演示不要求安装 MATLAB。

## 软件展示内容

当前网页围绕论文 Fig. 8 单机构网型变流器—无穷大母线算例，提供：

- VSM 阻尼系数和短路比（SCR）交互调节；
- 变流器、线路与无限大电网的拓扑示意；
- 闭环主导特征根参考结果；
- 分散式充分判据在离散频率网格上的覆盖情况；
- 频率域混合增益—相位裕度曲线；
- “充分判据未覆盖不等于系统必然失稳”的结果解释。

建议答辩演示时依次选择较小和较大的阻尼系数，比较主导极点、判据覆盖点数及裕度曲线的变化，从而说明参数变化、充分判据与闭环稳定性参考结果之间的关系。

## 研究内容

项目目前形成了三层相互区分的工作内容：

1. **论文复现基线**：保留论文、官方 TeX 源码和作者代码的固定版本，复查单机无穷大母线稳定与失稳算例。
2. **自主数值方法**：研究复数矩阵数值域、严格扇形相位区间、混合增益—相位判据、频率网格细化及边界连续追踪。
3. **软件展示层**：通过前后端分离的本地网页，把参数输入、拓扑、判据结果和闭环参考验证组织成可操作的演示流程。

稳定性结论不依赖单一指标。项目原则上将充分判据结果与闭环特征根、数值域几何或时域仿真交叉核对；证据不足的样本应标记为“数值待定”，不强行归入稳定或失稳区域。

## 目录结构

```text
grid-forming-converter-stability/
├─ apps/web/          React 前端
├─ backend/           FastAPI 后端及接口测试
├─ src/               自主 MATLAB 稳定性分析函数
├─ tests/             MATLAB 单元测试
├─ experiments/       可重复运行的数值实验入口
├─ results/           精选结果和测试报告
├─ references/        论文、TeX 源码及来源登记
├─ external/          固定版本的第三方/作者代码
├─ docs/              项目规划、算法规范与研究说明
├─ notes/             开发日志和证据台账
├─ scripts/           启动与辅助脚本
└─ 启动平台.bat       Windows 一键启动入口
```

`apps/web/node_modules` 是前端依赖目录，首次启动后约占 170 MB，已被 Git 忽略，不会上传到 GitHub。需要释放空间时可以删除；再次启动平台会自动安装。

## 开发与验证

前端生产构建：

```powershell
cd apps/web
npm run build
```

启动器自动冒烟测试：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start_dev.ps1 -SmokeTest
```

MATLAB 测试入口：

```matlab
run("experiments/run_unit_tests.m")
```

开发过程、验证条件和遗留问题记录在 [`notes/PROJECT_LOG.md`](notes/PROJECT_LOG.md)，算法说明位于 [`docs/specs/algorithms/`](docs/specs/algorithms/)，研究方法与阶段性创新位于 [`docs/research/`](docs/research/)。

## 参考基线与学术边界

核心论文、版本、来源链接和校验信息统一登记在 [`references/SOURCES.md`](references/SOURCES.md)。作者仓库的固定快照保存在 `external/cifelli-small-gain-phase`，第三方原始代码不直接修改。

本仓库中的网页结果在没有接入正式数值内核之前，只用于交互展示和接口验证。任何对论文定理“完整复现”或对新模型“普遍适用”的表述，都必须以模型假设、算法实现、回归测试和独立数值验证全部完成为前提。
