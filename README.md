# 构网型变流器稳定性分析平台

面向构网型变流器（Grid-Forming Converter, GFM）小信号稳定性研究的本地可视化分析软件，也是天津市大学生创新训练项目的主要软件成果。

项目以 Cifelli–Anta 分散式小增益—小相位稳定条件为论文基线，同时建立与论文夹具相互隔离的团队自建低频模型。软件把版本固定的论文算例复算、可编辑网络、闭环特征根、线性响应、参数扫描和可追溯报告组织为一套可重复演示的工作流。

> 当前软件版本为结项候选 `v0.3.0-rc1`。Fig. 8 页面已经接入便携式 Python 数值内核，但该内核评价的是固定 1000 点频率网格，`theorem_status` 保持为 `not-evaluated-by-sampled-api`；有限网格筛查结果不能冒充论文连续全频定理的完整验证。

## 一键启动

### Windows 开发态

双击项目根目录中的：

```text
启动平台.bat
```

启动器会检查 Python、Node.js 和项目依赖，启动 FastAPI 后端与 React 前端，等待健康检查通过后打开浏览器，并在退出时清理本次启动的服务。默认访问地址为 <http://127.0.0.1:5173>。

开发态要求：

- Windows 10/11；
- Python 3.10 或更高版本；
- Node.js 20 或更高版本；
- 运行网页与 Python 分析不要求安装 MATLAB。

首次启动可能需要联网安装依赖。Windows `v0.3.0-rc1` `onedir` 候选包已从干净代码提交 `e00a825` 构建，并通过同一进程静态前端/API、Fig. 8 固定 1000 点复算（75 个未覆盖点）及退出后端口释放冒烟。ZIP SHA-256 为 `B118C2CCD1D97A38DA5F9BD7B56C6D54816ECA775FFE0B004030CEA861AD9EF0`；另一台无 Python、Node.js、MATLAB 的 Windows 电脑仍须完成断网验收。

## 软件展示内容

网页包含两个彼此隔离的工作区。

### 论文复现

- 仅提供作者 Fig. 8 的两个固定工况 `D=0.05` 与 `D=0.5`，不在两者之间进行阻尼插值；
- Python 内核从受版本约束的作者频响与闭环谱夹具重新计算 1000 个频点，不使用人工预览公式；
- 展示小增益、小相位和混合覆盖结果、频率裕度曲线及闭环主导极点；
- 两个工况分别重现 75 个和 0 个未覆盖频点；
- 可导出结果 JSON，并生成包含输入、结果、来源与学术边界的打印式 HTML 报告。

工作簿闭环谱对应的失稳主导振荡频率约为 `0.578 Hz`，论文正文报告约为 `1.2 Hz`。该定量差异尚未闭合，界面与报告均保留提示；现阶段只能确认失稳极点实部符号和有限网格判据回归，不宣称振荡频率已经定量复现。

### 独立模型

- 采用团队自建的低频相角—标幺频率—有功功率测量降阶 VSM 模型，并显式使用基频关系 `δ̇=ω_bΔω_pu`；
- 通过 `NetworkTopology/1.0` 契约编辑母线、交流线路、构网型变流器、无限大母线、基值和控制参数；
- 提供稳定、Routh–Hurwitz 临界和低阻尼失稳三个解析预设；
- 从同一输入计算网络同步刚度、Kron 消元后的状态矩阵、全部闭环极点、主导模态和零输入初始条件线性响应；
- 支持带版本号的案例 JSON 导出—导入—重算往返，以及结果 JSON、极点 CSV、时域响应 CSV；
- 提供以选定 VSM 阻尼 `D` 和选定线路标幺电抗 `X` 为坐标的显式网格扫描、稳定性热图和 CSV 导出；
- 生成独立模型打印式 HTML 报告，与 Fig. 8 报告共用可追溯的后端计算路径。

这里的 `X` 仅表示选定线路在算例基准值下的标幺电抗，不自动换算或命名为普遍意义的短路比（SCR）。独立模型也不是完整平均值 `dq` 模型：目前不包含无功—电压耦合、变流器内环、限幅、负荷动态和电磁暂态，线路电阻亦未进入有功同步刚度。

## 研究与证据分层

项目将下列内容严格区分：

1. **论文基线**：论文 v2、官方 TeX、作者仓库固定版本及 Fig. 8 输入夹具；
2. **团队数值实现**：MATLAB 数值域与相位算法，以及 Python 有限网格便携内核；
3. **团队独立模型**：低频 VSM 降阶模型、闭环极点、线性响应与 D–X 参数平面；
4. **软件展示与报告**：只展示后端实际计算结果，不把界面变化当作科研证据。

充分条件未覆盖不等于系统必然失稳。论文有限网格筛查、闭环特征根参考结果和独立降阶模型结论均须按各自假设解释，不得跨模型外推。

## 开发与验证

在项目根目录运行统一验收：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify_all.ps1
```

验收依次覆盖 Python 52 项测试、前端生产构建、开发态启动器、受控浏览器端到端流程，以及可选的 MATLAB 测试。MATLAB 不在默认安装路径时，可先设置其安装根目录，例如：

```powershell
$env:MATLAB_ROOT = "D:\matlab"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify_all.ps1
```

路径仅为示例，应改为本机实际 MATLAB 安装目录。没有 MATLAB 时可使用 `-SkipMatlab`；验收结果会明确记为 `SKIP`，不会误报为通过。详细规则见 [`docs/software/VERIFICATION.md`](docs/software/VERIFICATION.md)。

开发过程与遗留问题见 [`notes/PROJECT_LOG.md`](notes/PROJECT_LOG.md)，算法说明见 [`docs/specs/algorithms/`](docs/specs/algorithms/)，研究方法和阶段性结论见 [`docs/research/`](docs/research/)。

- 闭合工作簿主导极点 `0.578 Hz` 与论文正文 `1.2 Hz` 的差异；
